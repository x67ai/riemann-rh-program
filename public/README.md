# What this folder is

The two papers, as served at https://x67.ai.

This folder is the Cloudflare Pages output directory. Cloudflare settings:

    Framework preset    None
    Build command       (leave empty)
    Output directory    public
    Root directory      (leave empty)

Nothing is built. The files here are served as-is, so a push to `main` on
GitHub redeploys the site within a minute or two.

## Keeping the PDFs current

These are copies. The papers themselves live at
`rh-program/results/arxiv/{a4-no-go,seed-no-go}/main.pdf`. After rebuilding a
paper, refresh the copies with:

    bash public/sync.sh
