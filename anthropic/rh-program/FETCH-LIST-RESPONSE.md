## 3. B3 — which Suzuki paper the Hamiltonian-locality dichotomy needs

**Verdict: `y-12` — Suzuki, *Hamiltonians arising from L-functions in the Selberg class*, J. Funct. It is the only one of the seven Suzuki papers stating **both halves about a Hamiltonian**:

- **Local (unconditional).** For `E_L^{ω,ν}(z) = ξ_L(½+ω−iz)^ν` with `νω·d_L > 1`: `H(t) = diag(1/γ, γ)`, `γ = (det(1+K[t])/det(1−K[t]))²`, exists on some `[0,τ)` and solves the canonical system uniquely back to `E`.

  > p. 22 §8(6): "we need information of all q_L^{ω,ν}(n)'s to understand it differ from the situation that we need only finitely many q_L^{ω,ν}(n)'s to understand K_L^{ω,ν}[t] for a finite range of t"

### The severe novelty finding

```
E_ξ(z)·conj(E_ξ(w)) − E_ξ^♯(z)·conj(E_ξ^♯(w)) = 2[ B(z)conj(A(w)) + A(z)conj(B(w)) ]
```

> **Theorem 1.** *For each primitive Dirichlet character χ including the trivial character χ₀, set* **E_χ(z) = A_χ(z) − i B_χ(z)** *with* **A_χ(z) = ξ_χ(½ − iz), B_χ(z) = i ξ′_χ(½ − iz).** *Then these functions are real on the real axis, and the following holds.* *(i) E_χ(z) is a de Branges function if and only if the Riemann hypothesis holds for L(s, χ).* *(ii) E_χ(z) is a strict de Branges function if and only if the Riemann hypothesis holds for L(s, χ) and all its nontrivial zeros are simple zeros.*

and in the proof: **B_χ(z) = −(d/dz) A_χ(z)** (via Laguerre, [16, Thm 5.7]).

Both checked: `A − iB = ξ_χ(½−iz) + ξ′_χ(½−iz)` ✓; `−dA/dz = i ξ′_χ(½−iz) = B_χ` ✓. So the de Branges pair for `E_ξ` is `(A, −A′)` — a kernel built from a function and its own derivative **is** the ξ·ξ′ mixed object.
