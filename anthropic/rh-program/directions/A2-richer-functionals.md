# A2:richer-functionals: Breaking the pair ceiling from inside: unconditional mixed-window triple-correlation traces and a cubic rank-trace certificate

## Proposal (Phase 3, immutable)

### Thesis
Escape the formalized bandwidth-one pair ceiling without extending pair bandwidth, by proving the unconditional vanishing of the connected TRIPLE-correlation form factor of zeta zeros on the total-support-< 2 simplex (mixed-window trace tr(G_a G_b G_c), Rudnick-Sarnak range, de-conditionalized a la BGSTB) and consuming it through a cubic-integrality rank-trace certificate whose exact worth is computed first by adding triple rows to the 256-law extremal LP.

### Mechanism
OBJECTS. Fix the common critical-density Gabor grid tau_k = T + 2pi k/l, l = log(T/2pi), d = floor(lT/2pi) = N(T,2T)(1+o(1)). For three C^3 tapers phi_a, phi_b, phi_c with supports lambda_w * l, lambda_w <= 1, form the three Gram matrices G^{(w)}_{kl} = W(phi_w e^{-i tau_k u}, phi_w e^{-i tau_l u}) on the SAME grid (sub-critical sampling keeps the Poisson identity exact per window: sum_k phihat_w(g - tau_k) phihat_w(g' - tau_k) = l * Phi_w(g - g'), Phi_w = (phi_w^2)^hat). The new functional is the mixed third moment tr(G_a G_b G_c). Zero side, by three Poisson resummations: tr(G_a G_b G_c) = l^3 * sum_{rho1,rho2,rho3} m1 m2 m3 Phi_a(g1-g2) Phi_b(g2-g3) Phi_c(g3-g1) + tail — a TRIPLE-correlation functional whose kernel has Fourier support in the simplex {xi1+xi2+xi3 = 0, |xi_w| <= lambda_w} of total width sigma = lambda_a+lambda_b+lambda_c. Because the windows may be UNEQUAL, sigma < 2 allows one factor at pair-bandwidth ~1 (e.g. (0.98, 0.5, 0.5)) — a corner the paper's equal-window analysis (3*lambda < 2 forces lambda < 2/3) never touched. // THE NEW INVARIANT. For CUE, Diaconis-Shahshahani exactness gives E[Tr U^{j1} Tr U^{j2} Tr U^{-(j1+j2)}] = 0 whenever j1 + j2 <= N_matrix: the CONNECTED 3-level form factor vanishes identically on the closed simplex sum|xi_i| <= 2 (repulsion exactly cancels all diagonal terms). T1 proves the zeta analogue unconditionally for sigma < 2: the triple sum equals its explicit pairing/diagonal value (computable from mu and Lambda^2-diagonals, NO Hardy-Littlewood input) + o(main). This 'connected-triple vanishing' is a constraint on the zero configuration that is (i) a theorem-target with proven-technology inputs, (ii) multilinear of degree 3, hence OUTSIDE the pair form factor, and (iii) generically violated by adversarial marked laws such as the 256-periodic law, which was optimized only against pair rows. // WHY UNCONDITIONAL (prime side). Expanding each G by the explicit-formula density nu_X = mu + Pi_X + P_X gives 27 pieces; all with <= 2 prime factors are the paper's Prop 5.5-5.7 machinery. The genuinely new piece P_a P_b P_c contains exact relations n1 n2 = n3 (same-prime-power sums, O(1)) and near-relations, bounded by composite-frequency Montgomery-Vaughan (coefficients (Lambda*Lambda)(m)/sqrt(m), m <= X_a X_b, spacing >= 1/2m): << l^2 T^{sigma/2} = o(T l^3) iff sigma < 2. The Rudnick-Sarnak boundary thus falls out of the SAME MV lemma already formalized in Zeta23/MV/. No pair-correlation support beyond [-1,1], no shifted-convolution Lambda-correlations, no fourth moment are needed anywhere. // THE CERTIFICATE (Lemma C target). Validity polynomial psi(m) = c1 m + c2 m^2 + c3 m^3 + c4 1_{m=1} with psi(m) <= 1 for all m >= 1 (forcing c3 <= 0, so the route OBEYS the odd-moment LP-dual no-go instead of fighting it: mass escaping to large eigenvalues only hurts the adversary). Zero side: A = P + Q as in Prop 4.1. tr A^3 = tr P^3 + 3 tr(P^2 Q) + 3 tr(P Q^2) + tr Q^3. Structural asset: an isolated hyperbolic pair block has eigenvalues ~ +/- mu, so its ODD traces nearly cancel — the X^{3y} depth explosion that makes the zero-side second moment unreadable termwise is absent at leading order in odd traces; Q enters the cubic row only through interactions and through its trace-asymmetry, both priced against epsilon * tr A^2 (globally prime-bounded) and n_+(Q) <= p by von Neumann-type bounds. On-line atoms are handled by the already-formalized Schur-Jensen + spectrum-transfer pair (valid for arbitrary g with g(0)=0), giving tr g(P) vs sum_j g(m_j ||v_j||^2) comparisons for cubic g. Section 7.5(g) — Schur-Horn majorization for f(x) = -x^2/9 + x^3/18 with window cos(8s/5), yielding N_d >= 0.85082 under RH — is the proof-of-concept that cubic accounting survives interactions WHEN the third trace exists; Lemma C is its unconditional extension with Q nonempty and mixed kernels, the single genuinely new piece of linear algebra. // PRICING BEFORE PROVING (the LP). Extend the 256-law exact-rational LP: columns = marked periodic configurations c (weights w_c >= 0, positions, marks in {1,2,3}); pair rows as before (near-CUE + free edge); NEW triple rows: the observables A3^c(j1,j2) = Re[F_c(j1) F_c(j2) conj(F_c(j1+j2))]/N (and Im), F_c(j) = sum_i m_i e^{2pi i j x_i/N}, constrained to their T1 values (= 0 in the open simplex j1 + j2 <= N, edges free) within tolerance tau3. Each row is LINEAR in w_c, so this remains an exact LP; its value p0^(3)(N) is the exact ceiling of the enlarged certificate class, and its DUAL solution is the candidate optimal (c0, r, rho3) certificate whose validity Lemma C must prove. The route thus computes the exact worth of the triple-correlation upgrade BEFORE the analytic work — and as a free by-product, the pair-only dual at the same N is the explicit candidate certificate closing the 0.6725 -> 0.6818 gap inside the old class.

### Novelty
(1) First unconditional correlation theorem for zeta zeros beyond order 2: BGSTB24 (arXiv:2306.04799) de-conditionalized Montgomery's PAIR theorem; T1 does this at order 3, in the Hejhal 1994 / Rudnick-Sarnak 1996 restricted range — which for zeta at n = 3 exists in print only under RH — and with MIXED windows, so one direction carries full pair bandwidth (the paper's own equal-window framing, 3*lambda < 2, hid this corner). (2) First certificate consuming an invariant outside the exhausted list {tr, Frobenius, n_+, integer atoms} of lemmaR_tight: the Zeta23 paper asserts tr G^k in the RS range (Section 7.5(e)) but dismisses k = 3 via the odd-moment/Christoffel no-go for n_+ and never evaluates mixed windows nor uses cubic integrality weights unconditionally; Section 7.5(g)'s cubic-weight result (N_d >= 0.85082) is RH-conditional with Q empty — Lemma C is its unconditional extension, which no one has attempted. (3) First extension of the extremal-law LP methodology (Zeta23/PairCeiling) to 3-level rows: the artifact's own scope notes list k >= 3 data as outside the 256-law's design and name the triple-row LP 'the most informative next computation' — it has not been done. (4) The connected-triple-vanishing constraint on the simplex sum|xi| <= 2 (Diaconis-Shahshahani exactness transported to zeta) has never been used as a certificate row anywhere in the Levinson/pair-correlation literature (CGdL 2020 use pair data + F >= 0 under RH; GLSS 2025, arXiv:2503.15449 and 2507.06823, are pair-only). (5) Adjacent novelty: the M1 LP doubles as the first test of the Alternative Hypothesis against 3-level restricted data, going beyond the pair-only AH analysis of arXiv:2507.06823. Flagged for verification: the exact unconditional status/remarks in Hejhal 1994 and Rudnick-Sarnak 1996, and the precise Diaconis-Shahshahani exactness range.

### Obstruction evasion

- **DH/Epstein filter (functional equation + explicit formula + L2 means hold, RH false)** — This route claims only improved unconditional proportions (N0^s, N_d), never full RH — stated honestly. It consumes no input that DH/Epstein violate in a way we exploit toward RH; indeed for Davenport–Heilbronn the prime-side mean values already fail (coefficient growth), so the certificate is empty there, which is the correct control behavior. No RH-completeness claim is made anywhere on the milestone ladder.
- **Alternative Hypothesis (bandwidth-1 pair data cannot distinguish GUE from half-integer-spacing worlds)** — The new data is the 3-level (triple-correlation) form factor on the simplex |xi1|+|xi2|+|xi3| < 2, which is strictly outside the pair-correlation data class in which AH lives. Whether AH-type laws survive the triple-vanishing rows is itself decidable by the M1 LP: if AH configurations violate connected-triple vanishing on the simplex (their rigid arithmetic spacings generate triple resonances j1+j2=j3 in-band), this route yields the first provable-range data class that refutes AH — an obstruction converted into a target.
- **Formalized bandwidth-one certificate ceiling 0.6818287 (PairCeiling)** — The ceiling's formal scope (Signed.lean:94) covers certificates LINEAR in the pair form factor with C^1 weights, valid configuration-by-configuration; its own limitations section states that k>=3 correlation inputs are outside scope because the 256-law 'was not built to match' them. Our certificate is degree-3 multilinear in the configuration (rows A3(j1,j2)); the adversarial 256-law generically violates connected-triple vanishing on the simplex, so it no longer bounds us. M1 computes the new, higher ceiling p0^(3) exactly.
- **lemmaR_tight (two-moment rank-trace certificate exhausted over {tr, Frobenius, n_+, integer atoms})** — We consume tr(G_a G_b G_c), an invariant outside the exhausted list. We do NOT claim to separate an on-line double from a depth->0 off-line pair (they are matrix-identical in the limit; no continuous functional can). The gain comes from re-weighting the whole multiplicity distribution with a cubic validity polynomial psi(m)=c1 m+c2 m^2+c3 m^3+c4 1_{m=1}, exactly as the paper's own RH-conditional Section 7.5(g) demonstrates is possible once a third trace exists (0.85082 vs 0.83625 for N_d).
- **Dimension cap d = lambda*N (nothing below lambda=1/2, 100% only at lambda=1)** — The common Gabor grid is run at lambda_0 = 1 (d = N + O(1)); only the auxiliary windows inside the triple trace have smaller support. The cap is therefore 100% and non-binding for our targets (<= 0.73 simple, <= 0.87 distinct).
- **kappa(lambda) = 1/lambda + lambda/3 >= 2/sqrt(3): trace+Frobenius certificates cap at 0.8453 at any bandwidth** — That cap is proved for certificates consuming exactly two moments. The three-trace certificate is outside its hypothesis; independently, all our numerical targets sit below 0.8453, so we never need to contradict it.
- **Bombieri small-support Weil positivity is unconditional (small cones prove nothing)** — No step argues positivity of a small-support Weil cone. All positivity used is finite-dimensional matrix positivity of compressions (Sylvester inertia, Schur-Jensen, von Neumann), fed by unconditional mean-value evaluations — the same architecture as the parent paper, which passes this filter by being a proportion result.
- **Bombieri-Garrett ~94% pseudo-Laplacian spectral cap** — Out of scope: no self-adjoint operator realization of zeros is invoked; the Gram matrices are non-orthonormal compressions read only through traces and inertia.
- **Parity problem (sieve-only routes)** — No sieve weights appear; the arithmetic input is mean values of Dirichlet polynomials in Lambda (Chebyshev-Mertens + Montgomery-Vaughan + composite-frequency MV), which are not parity-limited sieve objects.
- **Conrey-Li counterexamples to de Branges positivity** — No de Branges space or positivity condition is used anywhere.
- **Rodgers-Tao Lambda >= 0 (no sub-critical margin)** — No heat-flow/de Bruijn-Newman deformation is used; the route makes no appeal to any margin below criticality.
- **Campaign residue: per-pair quadratic integrality pricing is FALSE (G1-G4); (m-1)(m-2) spectral level destroyed by interactions** — Lemma C keeps the surviving mass-LINEAR rank-trace backbone and the regrouping device; the cubic row is consumed globally via majorization (Schur-Jensen + spectrum transfer, both already formalized for arbitrary g), never as per-pair quadratic pricing. The known killer — interaction terms — is measured FIRST (numerics (b)) and priced into the LP before any proof is attempted; Section 7.5(g) is the existence proof that cubic-level accounting survives interactions when a third trace is available.
- **Pontryagin negative-index counting route structurally empty** — Not used; we stay entirely on the positive-index/count side, as the paper does.
- **'Every route's first substantive step was Weil positivity in disguise'** — Our first substantive step (T1) is an unconditional asymptotic EVALUATION of a mixed triple trace — the same genus as BGSTB24's unconditional pair theorem, not a positivity postulate. The new leverage over all ~30 refuted routes: (a) genuinely new unconditional data (connected 3-level form factor vanishing on the simplex), (b) a certificate degree (multilinear-3) provably outside both formalized ceilings, (c) exact pricing of the payoff by LP before the analytic spend.

### First theorem
THEOREM T1 (unconditional mixed triple trace at total bandwidth < 2). Let l = log(T/2pi), and let lambda_a, lambda_b, lambda_c in (0,1] satisfy sigma := lambda_a+lambda_b+lambda_c < 2. Let phi_w (w = a,b,c) be C^3 tapers supported in [-lambda_w l/2, lambda_w l/2] (the paper's TaperProfile class), and put G^{(w)}_{kl} = W(phi_w e^{-i tau_k u}, phi_w e^{-i tau_l u}) on the common grid tau_k = T + 2pi k/l, k < d = floor(lT/2pi). Then, with NO hypothesis, tr(G^{(a)} G^{(b)} G^{(c)}) = M3(phi_a,phi_b,phi_c) * (T/2pi) * l^3 * (1+o(1)), where M3 is the explicit pairing functional (mu^3 smooth term, three Lambda(n)^2-diagonal cross terms with kernels (phi_w^2 * phi_{w'}^2)-hat, and an O(1/l) same-prime-power triple diagonal sum_p (log p)^3 sum_{alpha,beta} p^{-alpha-beta}). Equivalently, for the true zeta multiset with complex ordinates gamma_rho = (rho-1/2)/i: sum over triples of zeros in (T,2T] of m1 m2 m3 Phi_a(g1-g2) Phi_b(g2-g3) Phi_c(g3-g1) equals its pairing/diagonal value + o(N l^3-normalized) — i.e. the CONNECTED triple form factor of zeta zeros is o(1) on the closed simplex of total Fourier support sigma < 2. // STATUS OF INPUTS: the explicit formula for C_c^2 tests, the Gabor-Poisson identity (window- and grid-generic), the tail bound, Chebyshev-Mertens, and the MV weighted Hilbert inequality are all proved and FORMALIZED in Zeta23 (WeilEF/, Poisson.lean, Tail/, MV/ including the unexploited spacing_four and two_point lemmas). The paper itself asserts (Section 7.5(e)) the equal-window case tr G^k in the Rudnick-Sarnak range k*lambda < 2 by 'the diagonal method' but neither proves it with errors nor uses it; Hejhal 1994 / Rudnick-Sarnak 1996 prove the triple/n-level asymptotics under RH (flag: their unconditional complex-ordinate remarks need verification against the originals). T1 is the BGSTB24 move — de-conditionalize by working with complex ordinates and MV — executed one correlation order up, with mixed windows. // ATTACK SKETCH: (1) Fubini + tail absorption reduces tr(G_aG_bG_c) to the triple integral of nu_X against L^3 Phi_a Phi_b Phi_c (each factor's Poisson identity is exact at sub-critical sampling). (2) Expand nu^3 into 27 pieces; every piece with <= 2 prime factors is Prop 5.5-5.7 technology verbatim (integration by parts against the cosine; bilinear MV). (3) The new piece P_a P_b P_c: exact relations n1 n2 = n3 give a convergent same-prime-power sum (subleading); near-relations are bounded by COMPOSITE-FREQUENCY MV: frequencies y = log(n1 n2) with coefficients (Lambda*Lambda)(m) m^{-1/2}, m <= Y = X_a X_b, spacing delta_m >= 1/(2m), against z = log n3, n3 <= X_c; MV gives << (sum_{m<=Y}(Lambda*Lambda)(m)^2)^{1/2} (sum_{n<=X_c} Lambda(n)^2)^{1/2} << (Y l^3)^{1/2}(X_c l)^{1/2} = l^2 T^{sigma/2}, which is o(T l^3) precisely when sigma < 2 — the Rudnick-Sarnak boundary re-derived from the already-formalized MV lemma. Ratio-type frequencies log(n1/n2) have Farey spacing >= 1/(2 n1 n2) and are handled identically; sum_{m<=Y}(Lambda*Lambda)(m)^2 ~ c Y l^3 is an unconditional Mertens-type computation. Referee-evaluable, unconditional, and strictly stronger than anything in print at correlation order 3.

M3: breaks the lemmaR_tight invariant list — the first certificate format escape since the paper — with a formalizable matrix lemma contributed to RHLinalg. M4: new unconditional constants: any delta_d > 0 beats 5/6 (first improvement of Theorem C); delta_s > 0.0094 gives a certified simple-on-line proportion above the formalized bandwidth-one pair ceiling — a machine-checkable demonstration that the 0.6818287 wall is a property of the LINEAR class, not of bandwidth one; even a failed stretch goal yields the exact multilinear optimum. M5: two-sided (floor + ceiling) characterization of correlation order 3, the template for pricing every future correlation input before proving it. M6: potential refutation of the Alternative Hypothesis from provable-range data — which would be the most significant pair-correlation-adjacent result since Montgomery — and a quantified bridge toward 0.7222 without HL*(4).

### Failure modes

- Triple rows fail to bind: adversarial marked laws might decorrelate triples nearly for free while keeping the pair data and the double/edge-atom structure, so p0^(3) ≈ p0^(2) = 0.6818. Then the route collapses to a (still publishable) formalized no-go — 'restricted 3-level data is worthless below total bandwidth 2' — plus the AH-at-3-level analysis. This is decided in months by M1 before major analytic spend.
- Interaction terms defeat Lemma C: the cross terms 3tr(P^2Q)+3tr(PQ^2) and the trace-asymmetry of deep hyperbolic blocks may cost more than the cubic row buys (the G1-G4 ghost one level up). Mitigation: odd-power near-blindness of hyperbolic blocks is checked and quantified by Monte Carlo (numerics (b)) before proving; the LP can be re-run with the measured interaction penalty as an extra row.
- T1 range erosion: the composite-frequency MV bound needs Sum_{m<=Y}(Lambda*Lambda)(m)^2 << Y l^3 and Farey-spacing control for ratio frequencies log(n1/n2); polylog losses near sigma = 2 could force sigma <= 3/2 or an l-power-off endpoint, shrinking the accessible simplex and the LP value. Fallback constants remain new but smaller.
- Ratio-frequency off-diagonals may need genuine Rudnick-Sarnak-style cancellation beyond absolute-value MV — the hardest analytic risk inside T1.
- Endpoint degradation: lambda_a -> 1 losses (loglog/log) could swallow a small certified gain if p0^(3) - 0.6725 turns out to be only ~0.01.
- LP optimality gap: column generation over marked configurations is nonconvex pricing; we may not certify the adversarial law is optimal. Honest mitigation: any feasible law gives a rigorous ceiling and any Lemma-C-valid dual gives a rigorous floor — the program reports the two-sided gap, in the Lean RowCert pattern.
- Bridge formality: the 'certificate valid at the law' bridge must be restated for multilinear certificates (a paper-level remark in the pair case); sloppy scoping here would invalidate the ceiling comparison, so M5 formalizes it.
