## Proposal (Phase 3, immutable)

### Thesis
Put the Levinson/Conrey mollifier inside the evaluation vectors of the Zeta23 Gram matrix — G^B_kl = W(b⋆f_k, b⋆f_l) with b a Möbius-derived Dirichlet-polynomial weight — so that the same formalized inertia/rank-trace certificate consumes twisted (multiplicative) moments instead of bare bandwidth-one L² data, producing an unconditional certificate family that provably cannot exist for Davenport-Heilbronn/Epstein (their log-derivative and inverse coefficients grow polynomially) and whose quantified target is to beat the Montgomery-Taylor optimum 0.6725 and the formalized 0.6818287 bandwidth-one ceiling.

### Mechanism
OBJECT. For a real sequence b = (b_m), b_1 = 1, supp b ⊆ [1, M], M = (T/2π)^θ, define the multiplicative convolution (b⋆f)(u) = Σ_m (b_m/√m) f(u − log m), so that (b⋆f)^(τ) = B(1/2+iτ) f̂(τ) with B(s) = Σ_m b_m m^{−s}. The mollified Weil form is W_B(f,g) := W(b⋆f, b⋆g), and the mollified Gram matrix is G^B_kl = W_B(f_k, f_l) on the SAME critical-density Gabor family f_k = φ(u)e^{−iτ_k u} (τ_k = T + 2πk/L, d = ⌊LT/2π⌋, L = λ log(T/2π)) as the two-thirds paper. Spectral-density form: W_B(f,g) = ∫ f̂(τ) conj(ĝ(τ)) |B(1/2+iτ)|² ν_{X'}(τ) dτ with X' = e^L M² — the arithmetic weight sits in the density, the taper and grid are untouched.

ZERO SIDE (σ-equivariance — why the block machinery survives verbatim). Expanding as in Prop 4.1: c*G^B c = Σ_ρ m_ρ B(ρ)conj(B(1−ρ̄)) ℓ_{γρ}(c) conj(ℓ_{γ_{1−ρ̄}}(c)). An on-line zero ρ = 1/2+iγ contributes a rank-one PSD atom with EFFECTIVE MASS m_ρ β_ρ, β_ρ = |B(1/2+iγ)|² ≥ 0. An off-line pair {ρ, 1−ρ̄} contributes the 2×2 block [[0, w_ρ],[conj(w_ρ), 0]], w_ρ = m_ρ B(ρ)conj(B(1−ρ̄)) ∈ C, of signature (1,1) if w_ρ ≠ 0 and (0,0) if w_ρ = 0 — never more than one positive square. Because the weight attached to the pair is a single scalar respecting the ρ ↦ 1−ρ̄ symmetry, Lemma 3.1 (pull-back inertia, needing no independence) gives exactly as before: Ĝ^B = P_B + Q_B + E_B with P_B ⪰ 0, rank P_B ≤ s₁+s₂, n₊(Q_B) ≤ p, and tail ‖E_B‖ ≪ l³ T^{(λ+2θ)/2−1} (Prop 4.2 with X → XM²; the C³ taper suffices since |B(ρ)| ≤ M^{|β−1/2|}·Σ|b_m|/√m off the line). The Lean lemma rank_trace_mult_k (RankTraceMult.lean:369) is already stated for ARBITRARY real weights m_j ≥ 0 — the paper's own hook for exactly these non-integer effective multiplicities.

PRIME SIDE (where the Euler product enters). With normalization n(b) := Σ_m b_m²/m = 1, the two moments become mollified/twisted mean values, evaluable unconditionally for λ + 2θ ≤ 1 by the paper's own Montgomery-Vaughan step (Lemma 5.2 applies to arbitrary coefficients):
(1) tr Ĝ^B = (m₁(b,λ) + o(1))N, m₁ = 1 − 2𝒞(b)/λ·(explicit window factor), where 𝒞(b) = Σ_{n≥2} (Λ(n)/n) Σ_m b_{mn} b_m/m is the mollifier-prime correlation. Via Landau-Gonek this equals the weighted zero count Σ_ρ m_ρ B(ρ)conj(B(1−ρ̄))/N. For b = μ(m)ψ(log(M/m)/log M): b_{mp}b_m = −μ²(m)ψψ ≤ 0, giving m₁ = 1 + 2θ·Ã(ψ) + O(θ²), Ã(ψ) = ∫₀¹ (∫ψ(u)ψ(u+v)du/∫ψ²) dv > 0 — an ORDER-θ gain in the trace with no log T loss, the analytic shadow of Λ⋆μ = −μ·log (differentiated Euler product).
(2) ‖Ĝ^B‖²_F = L²∫∫Φ(τ−τ')² ν_B(τ)ν_B(τ')dτdτ' = (m₂(b,λ) + o(1))N, ν_B = |B|²ν. Main terms: (a) window-Plancherel ⟨|B|²⟩²-part ↦ (1/λ₁)·⟨|B|⁴⟩-corrected — here Möbius does real work: for the μ-mollifier ⟨|B|⁴⟩/⟨|B|²⟩² stays O(1) (mollifier fourth moments), whereas a generic coefficient sequence of that length is log-divergent; (b) the mollified prime diagonal (Λ·b-correlation)² ↦ deformed λ/3-term; (c) a NEW cross-diagonal μ̄·d(p)·Λ(p)-term (mollifier oscillation × prime oscillation at matched frequency log p) carrying the Fejér triangle weight — absent at b = δ₁, where the μP_X cross term integrates to zero by oscillation.

CERTIFICATES. Two branches, both weight-agnostic in the linear algebra:

FIRST-VARIATION FORMULA (the decision instrument). Perturbing b = δ₁ + (mollifier direction) yields d/dθ [m₁²/m₂] = Σ_p (log p/p)·G(α_p)·(profile weights) + o(1), α_p = log p/log(T/2π), with G(α) an explicit elementary function assembled from: +4Ã-type trace gain (flat window weight) versus the cross-diagonal cost in m₂ (triangle weight (λ−α)); both terms trace to the SAME correlation 𝒞(b) integrated against different kernels, so G is a purely archimedean, computable function. Its sign profile on (0, θ] decides whether short Möbius weights (or, with opposite sign, short Euler-product resonators) improve the certificate — and the finite-T numerics measure it directly.

TWO REGIMES. Regime I (first theorem): λ + 2θ ≤ 1 — every mean value inside Montgomery-Vaughan; fully unconditional with the paper's error budget. Regime II (milestone 3): λ = 1 with θ > 0 — the off-diagonals become exactly the shifted-convolution sums of the TWISTED second moment ∫|ζ|²|B|⁴-type, i.e. Deshouillers-Iwaniec/Balasubramanian-Conrey-Heath-Brown/Bettin-Chandee-Radziwiłł Kloosterman technology (twisted second moment known to mollifier length T^{17/33}) — proven multiplicative input STRICTLY beyond bandwidth-one pair-correlation data, entering exactly at the hook the paper names (Prop 5.6's off-diagonal).

DH/EPSTEIN SEPARATION (design principle, provable). For f with a zero at σ₀ > 1 (Davenport-Heilbronn; Epstein with h > 1), (i) the log-derivative coefficients Λ_f(n) are Ω(n^{σ₀−1−ε}) along a sequence (abscissa of −f'/f is ≥ σ₀), so the prime-side second-moment evaluation fails at every window — the paper already notes Prop 5.6 dies; and (ii) the inverse 1/f has coefficient partial sums Ω(x^{σ₀−ε}), so NO bounded-coefficient mollifier exists: 𝒞(b) and ⟨|B|⁴⟩ cannot be simultaneously controlled. Both facts are short abscissa-theory lemmas. The certificate family is provably EMPTY for these RH-false objects at the level of inputs, not outputs — the first positivity statement in this program whose engine, not merely whose conclusion, requires the Euler product.

### Novelty
(1) Nobody has put arithmetic weights inside the evaluation vectors of an unconditional Weil-form Gram certificate. The Zeta23 paper (2026) explores only the scalar taper and unweighted higher moments (§7.5 d-f) and explicitly lists 'mollifiers/Levinson-Conrey machinery, amplification' as outside its formalized ceiling's scope without constructing anything there. (2) Conrey-Ghosh-Gonek 1998 / Bui-Heath-Brown 2013 compute mollified discrete moments over zeros and reach 19/27 simple — but ONLY under RH (zeros on the line are needed for their Cauchy-Schwarz over zeros and their Gonek-lemma evaluations); this proposal is precisely 'CGG made unconditional' by the same inertia move with which the paper made Montgomery unconditional — the natural but unclaimed next rung. (3) BGSTB 2306.04799 and Goldston-Suriajaya remove RH from pair correlation but stay strictly in unweighted L² data (bandwidth-one); the mollified moments m₁, m₂ are twisted data outside that class. (4) Bombieri 2000 studies the Weil functional's small-support positivity and its negative index, without mollified compressions; Connes-Consani 2006.13771 / CCM 2310.18423 prove archimedean/semilocal positivity with no proportion certificates and no mollifier; Suzuki 2301.00421 identifies the Weil-form space as a de Branges space under RH — used here only as structural language (W_B = Weil form composed with multiplication by B). (5) Conrey-Farmer-Kwan-Lin-Turnage-Butterbaugh 2508.11108 (short mollifiers) is Levinson-side, not explicit-formula-side. (6) The DH-separation theorem — a certificate family provably empty for explicit RH-false objects because its INPUTS need bounded-coefficient invertibility — has no antecedent; it converts the campaign's barrier-checker philosophy into a theorem. ### Obstruction evasion

- **DH/Epstein filter (RH-false objects satisfy FE + explicit formula + L2 means)** — Honest scope: the near-term deliverables are proportion/margin theorems, not full RH, and are declared as such. But the route is built AROUND the filter: its engine consumes (a) polynomial-boundedness of Lambda_f(n) for the second-moment evaluation and (b) existence of a bounded-coefficient Dirichlet inverse (Moebius) with small fourth moment for the mollifier gain — both provably FALSE for Davenport-Heilbronn and class-number>1 Epstein (their -f'/f and 1/f have abscissa >= sigma_0 > 1, coefficients Omega(n^{sigma_0-1})). Milestone 4 makes this a theorem: the certificate family is empty for these objects at the level of inputs. The horizon statements (V(1,theta) -> 1, margin laws with mollifier coupled to support) are Euler-product-consuming by construction.
- **Alternative Hypothesis (bandwidth-1 pair data cannot distinguish GUE from half-integer worlds)** — The mollified moments m1, m2 are zero-prime correlation data (Landau-Gonek sums, twisted second moments), not pair-correlation form-factor data; AH constrains only the latter. We do not claim to refute AH — we claim the certificate reads data on which the AH degeneracy is silent, which is exactly why the ceiling derived from AH-compatible configuration laws does not bind.
- **Formalized bandwidth-one certificate ceiling 0.6818287** — The ceiling covers certificates (c0, r) reading only the form-factor measure on [0,1] + mean density + integrality, configuration-by-configuration. The full-map itself lists mollifiers/amplification as outside its scope. The 256-periodic extremal law was built to match only bandwidth-one rows; it does not (and cannot, being a pure point-configuration law with no arithmetic) reproduce the twisted moments m1(b), m2(b). Milestone 3's explicit target — V(1,theta) > 0.68183 — treats the ceiling as the falsifiable wall to beat, with the LP template available to compute the NEW ceiling of the enlarged class (milestone 6).
- **lemmaR_tight (two-moment rank-trace certificate exhausted)** — Tightness is relative to the FIXED invariants (tr, Frobenius, n_+, integer atoms) of the FIXED form. - **Dimension cap d = lambda*N (nothing below lambda=1/2, 100% only at lambda=1)** — Fully respected: all certificates remain <= lambda_1*N. - **Parity problem (sieve-only routes)** — Not a sieve route: inputs are explicit-formula compressions plus mean-value theorems for Dirichlet polynomials (MV, Deshouillers-Iwaniec). ### First theorem
THEOREM (Mollified inertia certificate, Regime I). Fix lambda in (1/2, 1), theta in [0, (1-lambda)/2], delta > 0 with lambda + 2*theta <= 1 - delta. Let L = lambda*log(T/2pi), M = (T/2pi)^theta, and let phi, f_k, d be exactly as in the two-thirds paper. Let b_m = mu(m)*psi(log(M/m)/log M) for a fixed C^2 profile psi >= 0, psi(0)=0 — or, in the general form, any real b with b_1 = 1, |b_m| <= 1, supp b in [1,M] — normalized by n(b) = sum b_m^2/m. Define G^B_kl = W(b*f_k, b*f_l) (multiplicative convolution). Then, unconditionally:
(i) [Structure] G^B/(aL^2) = P_B + Q_B + E_B with P_B PSD, rank P_B <= s1+s2, n_+(Q_B) <= p, and ||E_B|| <= C(phi) l^3 T^{(lambda+2theta)/2 - 1};
(ii) [Moments] tr G^B/(aL^2) = (m1(b,lambda) + O(E_T)) N(T,2T) and ||G^B/(aL^2)||_F^2 = (m2(b,lambda) + O(E_T)) N(T,2T), where m1 = n(b) + 2*C(b)-correlation term and m2 = [window-Plancherel <|B|^4>-term/lambda_1] + [mollified prime diagonal] + [mollifier-prime cross-diagonal with triangle weight] — each an explicit finite multiplicative sum, with all off-diagonal contributions << L^2 * X M^2 * (log)^2 via Montgomery-Vaughan (Lemma 5.2 verbatim), and E_T the paper's error budget with X -> XM^2;
(iii) [Certificate] N_0^dist(T,2T) >= (2*m1(b,lambda)^2/m2(b,lambda) - 1 - o(1)) N(T,2T), via n_+(H) >= (tr H)_+^2/||H||_F^2, inertia pull-back, and N >= N_on + 2p;
(iv) [First variation] d/d(eps)[m1^2/m2] at b = delta_1 in the direction of the normalized Moebius profile equals sum_p (log p/p) G(alpha_p) psi-weights + o(1), with G an explicit elementary function of alpha = log p/log(T/2pi) determined by phi (flat window weight on the trace gain vs Fejer triangle weight on the cross-diagonal cost).
STATUS OF INPUTS: (i) is the paper's Prop 4.1/4.2 with two new 20-line lemmas (signature of [[0,w],[conj w,0]] for complex w; tail with the M-factor) — inputs fully proven. ### Failure modes

- The first-variation function G(alpha) could be <= 0 throughout (the cross-diagonal cost in m2 dominating the trace gain 4*theta*A-tilde): mollification would then never help at any bandwidth — the route degrades to the M2 no-go theorem (publishable, formalizable, but no constant improvement).
- The fluctuation of beta_rho = |B(rho)|^2 over zeros (log-normal-type) could inflate the zero-side diagonal of m2 enough to eat the trace gain even when G > 0 in the mean — visible early in Experiment A.
- Landau-Gonek uniformity in mollifier length M <= T^theta may carry worse error terms than assumed (flagged); would shrink the admissible theta range in M1 but not kill it.
