## Proposal (Phase 3, immutable)

### Thesis
The Lindelöf lock does not need pointwise lambda_max = O(1): a Schatten-3 tail bound Sum_{|lambda_i| >= V0} |lambda_i|^3 = o(N) with V0 = polylog(T), provable NOW at bandwidth lambda = 1/2 + O(loglog T/log T) from classical mean values (Montgomery–Vaughan + a free unique-factorization fourth moment + Huxley large values), converts the unconditionally computable third trace tr G~^3 (Rudnick–Sarnak range, v5 §7.2(e)) into a sign-sensitive constraint that separates on-line doubles (cubic charge +8) from off-line pairs (cubic charge 0), breaking the lemmaR_tight degeneracy in a joint two-bandwidth LP whose counting still runs at lambda = 1.

### Mechanism
OBJECTS. P_X(tau) = Sum_{n<=X} Lambda(n) n^{-1/2-i tau}, X = T^lambda; equivalently A(tau) = Sum_{n<=X} Lambda(n) n^{-1/2 - i tau} with mean square Sum Lambda(n)^2/n ~ L^2/2, L = lambda*l, l = log(T/2pi). G-hat = normalized Weil–Gabor matrix (units (4.4): isolated on-line zero -> eigenvalue m_rho, window-independent), d = lambda*N windows of width 2pi/L, eigenvalues lambda_i. Known unconditionally: tr G-hat = N(1+o(1)), tr G-hat^2 = (1/lambda + lambda/3)N, and — decisive, v5 §7.2(e) — tr G-hat^3 is evaluable by the §5 diagonal method exactly when X^3 <= T^{2-eps}, i.e. lambda < 2/3. The full lock lambda_max = O(1) is Lindelöf-strength (it is a pointwise bound on window-smoothed |P_X|, i.e. on ζ'/ζ near the line). Two structural no-gos frame the design: (a) §7.5(e): "an odd moment does not lower Lambda_1(0)" — because with UNBOUNDED spectral support, eigenvalue mass at height h -> infinity feeds m_3 freely (LP-dual: cubic certificate coefficients must have c_3 <= 0); (b) lemmaR_tight: from (tr, Frobenius, n_+, integer atoms) an on-line double (eigenvalue +2) and a tight off-line pair (eigenvalues ±2) both charge 4 and are indistinguishable. Both no-gos are evaded by the same object: a TAIL bound on the spectrum plus the SIGN of the third moment. A hyperbolic pair block contributes (+a)^3 + (-a)^3 = 0 to tr G-hat^3 while a double contributes +8: the odd moment is exactly the sign-sensitive datum the quadratic certificate lacks — but it is usable only if the spectral support is effectively bounded, which is the tail theorem.

STEP 1 — BRIDGE LEMMA (pure linear algebra, formalizable). Take phi in C^5 so the entries decay |G-hat_{kl}| <= C (1+|k-l|)^{-5} x (local smoothed |nu_X| mass), nu_X = mu + P_X. Schur test: any eigenvalue with |lambda_i| >= V forces a window where the |phi-hat|-smoothed |nu_X| exceeds c V l; conversely, writing G-hat = G_good + G_bad (G_bad = columns of windows where smoothed |nu_X| >= cVl), Weyl gives #{i: |lambda_i| >= 2C'V} <= rank G_bad <= #bad windows + polynomial-tail bookkeeping (a spike of height V' at distance J elevates <= (V'/V)^{1/5} windows — convergent dyadic accounting). So eigenvalue counting above level V is equivalent, up to absolute constants, to counting 1/L-spaced points where |A| >= c'Vl. Windows are 1/L-separated: discrete counts cost one factor L relative to measure (Gallagher), which is exactly the windows-per-unit-interval density; all conversions are elementary.

STEP 2 — LARGE-VALUE LEDGER for A (all inputs classical). Let n(V) = #{i : |lambda_i| >= V}. (i) MV mean value: n(V) << N V^{-2} (this is just Frobenius/Chebyshev). (ii) FREE FOURTH MOMENT: A^2 = Sum_{m<=X^2} c_m m^{-i tau}, c_m = (Lambda*Lambda)(m)/sqrt m; by unique factorization ab = cd with a,b,c,d prime powers forces {a,b} = {c,d} up to prime-power coincidences, so Sum |c_m|^2 = 2(Sum Lambda^2/n)^2 (1+o(1)) = L^4/2 (1+o(1)) — an UNCONDITIONAL diagonal, no Hardy–Littlewood needed. MV then gives Int_T^{2T} |A|^4 <= (T + O(X^2)) L^4/2, hence n(V) << N T^{2lambda-1} V^{-4} for lambda > 1/2 (and << N V^{-4} for lambda <= 1/2). The T^{2lambda-1} loss is the ONLY thing separating this from the full lock — sharpening it to o(T^{2lambda-1}) is HL*(4), which we do not assume. (iii) HUXLEY LARGE VALUES (1972; R << (G N V_B^{-2} + G^3 N T V_B^{-6}) log^C with G = Sum|a_n|^2 — exact form to be checked against Iwaniec–Kowalski Thm 9.15/ANTEDB): with G = XL and V_B = X^{1/2}Vl this yields n(V) << N T^eps X V^{-6}, which beats the needed V^{-3} exactly for V >= X^{1/3}. Assembling: the Schatten-3 tail T_3(V0) := Sum_{|lambda_i|>=V0} |lambda_i|^3 << N T^eps (T^{2lambda-1} V0^{-1} + X V0^{-3}); for fixed lambda < 3/5 and V0 = T^{2lambda-1} this is o(N) since 2lambda-1-lambda/3 < 0 — an unconditional effective spectral cutoff at T^{2lambda-1+eps}.

STEP 3 — NEAR-CRITICAL REFINEMENT (the actual operating point). Take X = T^{1/2} (log T)^theta, theta >= 0 fixed — bandwidth lambda' = 1/2 + theta*loglog T/log T, still strictly inside the k=3 Rudnick–Sarnak range (X^3 = T^{3/2} polylog << T^{2-eps}). Split A = A_0 + A_1 at X_0 = T^{1/2} (log T)^{-theta}. A_0: X_0^2 <= T, so the free fourth moment has NO loss: n_0(V) << N V^{-4}, cubic tail << N/V0. A_1 (the thin top slice): variance v_1 = (log X)^2/2 - (log X_0)^2/2 = theta*l*loglog T — logarithmically small; its fourth moment loses only X^2/T = (log T)^{2theta}: Int |A_1|^4 <= (T + X^2) * 2 v_1^2, so n_1(V) << N theta^2 (log T)^{2theta-2} (loglog T)^2 V^{-4}. Total: T_3(V0) = o(N) for V0 = (loglog T)^3 when theta <= 1, and V0 = (log T)^{2theta-2+eps} for theta > 1. THE SCHATTEN-3 LINDELOF LOCK HOLDS AT NEAR-CRITICAL BANDWIDTH WITH POLYLOG (even polyloglog) CUTOFF, FROM 1970s INPUTS. The trick is that just above bandwidth 1/2, the polynomial is (bulk with free fourth moment) + (slice with tiny variance), and V^{-4} bulk tails plus tiny-variance slice tails close the moderate-deviation window that is genuinely open at fixed lambda > 1/2.

STEP 4 — WHAT THE TAIL BUYS: THE SIGN-SPLIT CUBIC CONSTRAINT. At lambda', the prime side computes tr G-hat'^3 = c_3(lambda') N exactly (diagonal resonances n_1 n_2 = n_3 are prime-power triples p^a p^b = p^{a+b}, plus mu-cross-terms — the paper's §5 machinery; MV absorbs off-resonance since X^{3/2} <= T^{1-eps}). Zero side: tr G-hat'^3 = Sum_+ lambda_i^3 - Sum_- |lambda_i|^3. By Prop 4.1 inertia, negative eigenvalues come only from off-line pairs (n_- <= p), and each pair of depth u has |eigenvalue| ~ m X^u >= c m: THE NEGATIVE SPECTRUM COUNTS PAIRS, and the tail theorem caps both sums' high ends at V0 = polylog. New inequality system (all unconditional at lambda'): kappa(lambda')N = Sum_+ lambda^2 + Sum_- lambda^2 (Frobenius split), c_3(lambda')N = Sum_+ lambda^3 - Sum_- |lambda|^3, Sum_- |lambda|^3 <= V0 Sum_- lambda^2, Sum_-|lambda|^3 >= (Sum_- lambda^2)^{3/2}/n_-^{1/2} (power mean), n_- <= p. A double contributes +8 to the cubic and zero negative mass; a tight pair contributes 0 to the cubic and 4 to negative Frobenius mass: the two-moment-degenerate configurations now sit at DIFFERENT corners of the constraint polytope.

STEP 5 — JOINT TWO-BANDWIDTH CERTIFICATE (dimension-cap safe). The counting certificate (inertia, rank-trace, Lemma R with k_c weights) runs UNCHANGED at lambda = 1 (d = N, cap 100%), yielding the existing 2/3 and 5/6. The lambda'-matrix contributes NO inertia counting — only the moment rows above, which constrain the SAME configuration (multiplicities and positions are window-independent; the paper's real-weight rank_trace_mult_k already accommodates the lambda'-resolution effective multiplicities from coarser sampling). The configuration LP: at lambda = 1 the N_d-extremal configuration is 2/3 simple + 1/6 doubles (N_d = 5/6), spectrally identical to 2/3 simple + deep pairs. The cubic row prices these differently: doubles demand Sum m^3 = 2/3 + 8/6 = 2 per unit density (which at lambda = 1 exactly matches the sine value m_3(1) = 2 — the conditional §7.3 gain comes from the window-optimized combination (2m_2 - m_3)/18 > 0, value 2*(4/3) - 2 = 2/3 at lambda = 1); at lambda' = 1/2+ the analogous computable margin 2m_2(lambda') - m_3(lambda') enters through the v5 omega(m)-template with the Schur–Horn step applied to the positive part and the pair contamination priced by the sign-split rows instead of PSD-ness. Whether and by how much the joint LP exceeds 5/6 (and whether the 256-law LP with a cubic row still achieves 0.6818) is a FINITE, runnable computation — milestone 2 — before any hard analysis is invested. The horizon version: every improvement of the moderate-deviation large-value estimate MD(lambda, delta): n(V) << N V^{-(3+delta)} on V in [l^C, T^{2lambda-1}] raises the usable lambda' from 1/2 + o(1) toward 3/5 and 2/3, monotonically strengthening c_3-leverage; the limit lambda -> 2/3 with full MD is the complete "third-moment certificate", and the same template consumes any future fourth-moment progress (HL*(4) partial ranges) as a quartic row. GM/ANTEDB enter exactly at MD: at fixed lambda > 1/2 and V = T^{small}, current technology gives exponent 2 (MVT) against needed 3+delta — an honest one-full-exponent gap in a regime (thresholds barely above root-mean-square, prime support) where Guth–Maynard's additive-energy method is the only known tool type that beats Hölder interpolation between moments; that is why Theorems 1–3 are designed NOT to need it, and why it is quarantined to milestone 5.

### Novelty
(1) First unconditional operator-norm/Schatten-type control of the Weil–Gabor matrix in any regime: BGSTB24 (arXiv:2306.04799) and the parent paper stop at the Frobenius (second) moment; the paper explicitly lists orthonormalization and the third moment as blocked by "Lindelöf-type information" (Remark 7.1(ii), §7.5(e)) and the campaign never attacked it. Theorem 1 shows the lock is NOT Lindelöf-hard in the Schatten-3 sense at near-critical bandwidth — the obstruction dissolves at lambda = 1/2 + O(loglog/log) using only Montgomery–Vaughan 1974, Gallagher, unique factorization, and Huxley 1972. (2) The observation that the moderate-deviation gap [C, T^{2lambda-1}] shrinks to polylog as lambda -> 1/2+, and that the top-slice/bulk splitting closes it there, is new; it converts the brief's "fallback partial lambda_max bounds" into a sharp, provable statement with an explicit theta-dependent cutoff (loglog T)^3 vs (log T)^{2theta-2}. (3) First route that makes the third trace USABLE unconditionally: v5 §7.2(e) computes tr G~^3 for lambda < 2/3 but §7.5(e)'s LP-dual no-go (c_3 <= 0 on unbounded support) made it worthless; the tail bound + the sign-split of the spectrum (negative eigenvalues = pairs, Prop 4.1) evades that no-go's hypothesis rather than fighting its conclusion. This goes beyond v5 §7.3, which needed RH both for tr G~^3 at lambda near 1 (Hejhal 94/RS 96) and for PSD-ness in the Schur–Horn step. (4) The joint two-bandwidth certificate (inertia counting at lambda = 1, moment rows at lambda' near 1/2, shared configuration) is a new certificate class: it is outside the formalized bandwidth-one ceiling's scope (the ceiling covers certificates reading only two trace moments of support-[-1,1] tests, v5 §7.2), and it is NOT A2's refuted mixed-window kernel (no cross-window bilinear forms — separate Gram matrices, constraints intersected at the configuration level; the A2 adjudication is untouched). (5) A concrete, finite ceiling-breaking experiment: rerun the exact-rational 256-law LP with one added cubic row — the first test of whether ANY third-order datum moves the 0.6818287 wall. Relative to Guth–Maynard (arXiv:2405.20552) and Tao–Trudgian–Yang/ANTEDB (arXiv:2501.16779): those target large values V = N^{sigma}, sigma >= 7/10 for zero-density; our program isolates a DIFFERENT large-value regime (prime support, thresholds polylog x RMS, length T^{1/2+o(1)}) as the exact analytic content of the Lindelöf lock, states it as MD(lambda, delta), and quantifies the gap (exponent 2 available vs 3+delta needed) — a new, well-posed target for that community.

### Evades obstructions
- **DH/Epstein filter**: Out of scope, stated honestly: the route improves distinct/simple-zero proportions and builds spectral-tail infrastructure; it does not claim full RH. (Its inputs do lean on multiplicativity beyond L2: the free fourth moment uses unique factorization of prime products, and Davenport–Heilbronn coefficients break the mean-value steps — but no RH-completeness claim is made.)
- **Alternative Hypothesis / bandwidth-one data**: The certificate consumes triple-correlation data at combined Fourier support 3*lambda' ~ 3/2 > 1, exactly the data class that distinguishes worlds bandwidth-one pair correlation cannot; AH-consistency of bandwidth-1 data is irrelevant to a certificate holding a genuine third-moment row.
- **Bandwidth-one certificate ceiling 0.6818287**: The Lean ceiling covers certificates depending on the configuration only through two trace moments against support-[-1,1] tests (v5 §7.2 definition). The cubic row at bandwidth lambda' is outside this class; the map's extension hooks state such certificates are 'explicitly OUTSIDE the ceiling's scope'. Milestone 2 tests directly whether the 256-law violates the cubic row.
- **lemmaR_tight (two-moment certificate exhausted)**: Tightness is proved for the quantities (tr, Frobenius, n_+, integer atoms). The design adds two new quantities — the signed third moment and the Schatten-3 tail cutoff — and the degenerate pair (on-line double: cubic +8, negative mass 0) vs (tight pair: cubic 0, negative mass 4) is separated by exactly these.
- **Dimension cap d = lambda*N**: All counting/inertia runs at lambda = 1 (d = N, cap 100%). The lambda'-matrix supplies only scalar moment constraints on the shared configuration; no rank or index count is taken at lambda', so Prop 7.4 is never triggered at reduced bandwidth.
- **kappa(lambda) >= 2/sqrt(3) (0.8453 cap for trace+Frobenius certificates)**: That cap binds certificates using only two moments; the third-moment row leaves the class. (The near-term target N_d >= 5/6 + delta_0 is anyway below 0.8453; the cap is not the binding constraint here.)
- **Bombieri small-support Weil positivity (unconditional cones prove nothing)**: No positivity cone is asserted anywhere: the mechanism consumes upper bounds (large-value estimates, tails) and equalities (trace evaluations), not positivity of a restricted Weil form.
- **Bombieri–Garrett ~94% pseudo-Laplacian cap**: No self-adjoint operator whose spectrum is claimed to contain zeros is constructed; the Gram matrix is a compression of a signed measure and off-line zeros are counted, not excluded, via inertia.
- **Parity problem**: Not a sieve-only route: the explicit formula, mean values of Dirichlet polynomials, and Huxley large values are all beyond the parity-limited axiom set.
- **Conrey–Li (de Branges positivity fails)**: No de Branges space or positivity condition is used.
- **Lambda >= 0 (no sub-critical margin)**: No heat-flow/smoothing deformation is used; nothing requires a margin below criticality.
- **Campaign residue: 'first substantive step = Weil positivity in disguise'; refuted per-pair quadratic pricing; A2 fatals**: The first substantive step is a large-value/tail UPPER bound for a prime Dirichlet polynomial — an estimate, not a positivity statement; its new leverage is the sign-split usability of an odd moment. Pair pricing here is mass-linear/inertia-based plus the new negative-spectrum rows — not the refuted per-pair quadratic integrality. No mixed-window kernels and no rank_trace_cubic identity (both A2 fatals avoided by construction: separate Gram matrices, Schur–Horn only on the positive part with pair contamination priced by tail+sign rows).

### First theorem
THEOREM 1 (Unconditional Schatten-3 tail for the Weil–Gabor matrix; the partial Lindelöf lock). Let T -> infinity, l = log(T/2pi), phi a fixed C^5 taper as in the parent paper (Prop 4.2 hypotheses), and for a bandwidth parameter lambda in (1/2, 3/5] let G-hat be the Weil–Gabor matrix at bandwidth lambda in the units (4.4) (isolated on-line zero -> eigenvalue m_rho), with eigenvalues lambda_1, ..., lambda_d, d = floor(LT/2pi), L = lambda*l, X = e^L. Then, unconditionally:

(0) [Bridge] There are absolute constants c, C (depending on phi only) such that for all V >= C: #{i: |lambda_i| >= CV} <= C * L * |{tau in [T-1, 2T+1] : (|phi-hat|-smoothed |mu + P_X|)(tau) >= c V l}| + O(T^{1/2} l), and conversely every such tau lies within O(1/L) of a window supporting an eigenvalue >= cV/C. [Proof: Schur test on the C^5-banded entries, Weyl perturbation after good/bad column splitting, polynomial-tail dyadic bookkeeping; pure matrix analysis plus the paper's Prop 4.2 tail control.]

(i) [Fixed-lambda tail] For every eps > 0 and V >= C: #{i: |lambda_i| >= V} <<_eps N T^eps ( min(1, T^{2lambda-1} V^{-2}) V^{-2} + X V^{-6} ), and consequently Sum_{|lambda_i| >= V0} |lambda_i|^3 <<_eps N T^eps (T^{2lambda-1} V0^{-1} + X V0^{-3}). In particular, for fixed lambda in (1/2, 3/5) and V0 = T^{2lambda-1}: Sum_{|lambda_i| >= T^{2lambda-1+eps}} |lambda_i|^3 << N T^{-delta(lambda,eps)} — an effective spectral cutoff at T^{2lambda-1+eps}.

(ii) [Near-critical regime — the operating point] Let X = T^{1/2} (log T)^theta with fixed theta in (0, 1]. Then Sum_{i: |lambda_i| >= (loglog T)^3} |lambda_i|^3 = o(N), and for theta > 1 the same holds with cutoff (log T)^{2theta-2+eps}. Moreover the count obeys #{i: |lambda_i| >= V} << N [ V^{-4} + theta^2 (log T)^{2theta-2} (loglog T)^2 V^{-4} ] for all V >= (loglog T)^3.

STATUS OF INPUTS — all proven, none conjectural: (a) Montgomery–Vaughan mean value theorem (1974) and Gallagher's lemma for 1/L-spaced discretization; (b) the fourth-moment diagonal Sum_m (Lambda*Lambda)(m)^2/m = (1+o(1)) (log X)^4/2, which is UNCONDITIONAL by unique factorization (ab = cd with prime-power entries forces {a,b} = {c,d} up to prime-power coincidences of density zero) — this is emphatically NOT Hardy–Littlewood: the MVT is applied as an upper bound (T + O(X^2)) and the T^{2lambda-1} (resp. (log T)^{2theta}) off-diagonal loss is kept, not removed; (c) Huxley's large-values theorem (1972) for part (i)'s X V^{-6} term [exact constant/form to be verified against Iwaniec–Kowalski Thm 9.15 and the ANTEDB — flagged]; (d) the parent paper's Prop 4.2 tail estimate and Poisson sampling identity for the bridge constants. 

ATTACK SKETCH. Bridge: row sums of |G-hat| are dominated by the |phi-hat|-smoothed local mass of |nu_X| (Schur), giving the forward direction; for the count, split columns at the bad set, note rank(G_bad) <= #bad windows, and apply Weyl to G-hat = G_good + G_bad with ||G_good|| <= cV. Ledger: apply Chebyshev to the discrete second and fourth moments of A at one point per bad window (Gallagher converts to integrals at cost L, matching the window density); in regime (ii) split A = A_0 + A_1 at X_0 = T^{1/2}(log T)^{-theta}; A_0's fourth moment is loss-free (X_0^2 <= T), A_1's fourth moment loses (log T)^{2theta} but carries variance v_1 = theta l loglog T, so its tail count is << N (log T)^{2theta-2} (loglog)^2 V^{-4}; sum dyadically. Every step is a finite computation with explicit constants; the only delicate points are the smoothed-vs-pointwise conversions in the bridge and uniformity of the fourth-moment diagonal in the slice — both routine at referee level.

WHY THIS IS THE RIGHT FIRST THEOREM: it is exactly the brief's requested fallback ("partial lambda_max bounds and their quantitative payoffs"), it is well-posed and checkable with 1970s inputs, it is the first unconditional statement of its kind about this matrix, and it is the sole analytic input (beyond the paper's own §5 machinery) that milestones 2–4 consume. A referee can evaluate it without opinion on any conjecture. COROLLARY WORTH STATING (free): for fixed lambda in (1/2, 3/5), at most N T^{-delta} zeros in (T, 2T] have |beta - 1/2| >= (2lambda-1+eps) log T / L modulo the visibility lemma of milestone 3 — flagged as conditional on that lemma, since cluster interference must be excluded before eigenvalue lower bounds per deep pair are legitimate; the unconditional content of Theorem 1 itself is the upper-bound direction only.
