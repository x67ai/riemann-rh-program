**THEOREM M2 (Gevrey-localized single-defect separation; α = 2).** There are explicit constants c₀ = ½, λ₀ = 25, C₀ and R₀ (chain below) such that for all t ≥ 3, 0 < δ ≤ ½, and L ≥ max(λ₀/δ, C₀δ⁻¹(log log(3 + t) + 2log(1/δ) + log(2b₁C₁))), with R := R₀L:
1. **(Orbit clause.)** The orbit {±t ± iδ} contributes −2δ²c(δL)² + E₋ to W_Z(f), |E₋| ≤ 2δ²c(δL)²·e^{−L} (the reflected pair; B̂_L(−2t ∓ iδ) is Gevrey-small in Lt), where c(λ) := ∫B(v)cosh(λv)dv.
2. **(Edge-law clause, two-sided.)** For λ ≥ λ₀: e^{λ/2}exp(−√λ − (3/4)log λ + κ₋) ≤ c(λ) ≤ e^{λ/2}exp(−√λ − (3/4)log λ + κ₊) with explicit κ± (computed 1.515 ± 0.002; the note PROVES a two-sided Laplace bound, it does not fit).
3. **(Slack clause.)** c(λ)² ≥ e^{(1−c₀)λ} for all λ ≥ λ₀ = 25 at c₀ = ½ (computed for the tabulated λ; the note proves it from clause 2).
4. **(In-window on-line noise.)** If all points of Z in |Re γ − t| ≤ R other than the orbit are real, then 0 ≤ Σ_{those}|h_f(γ)|² ≤ b₁C₁log(3 + t + R)/L² + T₁, with b₁ = sup_η|ηB̂(η)|² = 8.646 and T₁ the Gevrey tail over 1 < |x| ≤ R, T₁ ≤ C₁log(3 + t + R)·C_B²·Σ_{k≥1}(k+1)²exp(−2c_B√(Lk)) ≤ b₁C₁log(3+t+R)/L² for L ≥ L₁(c_B) (explicit).
5. **(Out-window contamination.)** For every point γ = x − iy of Z with |x − t| ≥ R and |y| ≤ ½: |h_f(γ)conj(h_f(γ̄))| ≤ (|x−t| + ½)²·e^{L/2}·C_B²exp(−2c_B√(L|x − t|)); summed against the density of 𝒞(C₁) this is ≤ e^{−L} for R = R₀L with R₀ := (3/(4c_B))²·(1 + o(1)) (c_B = 0.20 from the Lean derivative constants gives R₀ ≈ 14; the numerical c_B ≈ 0.8 would give R₀ ≈ 0.9).
6. **(Separation.)** Let Z, Z′ ∈ 𝒞(C₁) be such that within |Re γ − t| ≤ R all points of Z′ are real while Z contains the orbit {±t ± iδ} and is otherwise real; outside the window both are arbitrary. Then |W_Z(f_{t,L}) − W_{Z′}(f_{t,L})| ≥ 2δ²c(δL)² − 2[b₁C₁log(3+t+R)/L² + T₁] − 2e^{−L} ≥ δ²e^{(1−c₀)δL}, and this is ≥ 1 as soon as also (1 − c₀)δL ≥ 2log(1/δ). **Bandwidth-L first-order data separate the two classes.**
