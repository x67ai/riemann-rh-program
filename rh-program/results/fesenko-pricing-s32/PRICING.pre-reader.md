## §0 The test a first rung must pass to be "decidable" (the s22 §0, reused verbatim; then one paragraph on its application to a corner whose objects are BUILT)

A rung is **decidable** when all of the following hold, and it is priced OPEN-NAMED or NO-GO when any fails.

1. **A factual observation settles it.** One of: a number computed; a source read at the page; a construction that exists or fails at bounded degree; a model-world instance that satisfies or violates the input. Never an impression, never "promising".
2. **The return is one of YES / NO / OPEN-NAMED** (the missing datum named), each carried by a theorem-shaped sentence (KICKSTART 10(c): "proof class X cannot yield Y because Z" or "Y holds").
3. **Both closes are writable in advance.** Before the pair runs, the pricing states what YES and NO each do to the branch's grade (dead-end restored on internal grounds / instrument / grossmann-candidate re-opened) and the refutation-shaped sentence banked in each case. A rung whose NO teaches nothing is not a rung.
4. **It sits on the ladder** (10(b)): the lowest rung where the answer is KNOWN comes first — function fields (RH true), then Epstein/Davenport–Heilbronn (RH false), then Dirichlet L, then ζ. A rung that starts above a rung the branch has not run is returned.
5. **It is not a design choice in disguise.** If the observation can only be made after the scout picks a free parameter the interface leaves open (a coefficient rule, a coupling map, a coefficient ring), the rung is not decidable; what is decidable is whether the interface *has* such a parameter, and 10(h) then prices the design, not the scout. This is the test that separates the "(R-a) smallest concrete instance" candidates from the "(R-b) function-field" candidates below.
6. **Its sources are reachable.** A rung needing a source not on disk is decidable only if the source is fetchable in-session (arXiv / open access) or the rung can be phrased around it; otherwise a FETCH line (§4(ii)) and OPEN-NAMED.
7. **It is priced in slots.** One slot = one agent, one session. The price of the pair (two scouts, one per model, blind; one adjudicator only on disagreement) is stated separately from the price of the rung itself.
8. **Absence is never evidence** (zoo V.5; STATUS line 34): no rung may return NO on a null literature search. "The branch does not contain the object" (V.5, THE DISTINCTION) is admissible and is the form every NO below takes.

### 2.1 I.1 (the axiom-level Davenport–Heilbronn / Epstein filter)

**Is there an axiom-level input DH/Epstein violate?** Two layers must be separated, because the sources have both.

*(a) The scheme layer.* The adelic spaces, the measure, T and the zeta integral as an integral are defined from the arithmetic surface E → B (s-15a §24–29, §36–39); ζ_S(χ) is the Euler product over closed points of the scheme (p. 47, §38). DH is not the zeta function of any scheme — I.1's Euler-product clause — so the zeta INTEGRAL has no DH instance. This is I.1 (c)'s form of a pass ("consumes an Euler product over closed points; DH has none") — but it is the same pass every scheme-theoretic construction gets, and I.1's CCM case study says the test must be run on the input that carries the RH content, not on the wrapper: "The filter must ask which *axiom* fails for DH — and for CCM the only failing step is the unproven convergence conjecture itself."

*(b) The analytic layer — where the RH content lives.* Every RH-facing statement of the corpus is about h, H, Z_E and Hypothesis (∗) (§1.2 rows §46–§54). By p. 70 ("h(n) = l(n)n² − l(n^{−1}) where the function l(n) is the inverse transform of ζ(f, \|·\|₂ˢ)") and Theorem 40 (ζ(f, \|·\|₂ˢ) = c_E^{1−s}ζ_E(s)² × the horizontal factor, a product of Γ(s/4)-, Γ(s/2)- and ζ_{k(y)}(s/2)-type factors, p. 54), h is a functional of the completed zeta function's ANALYTIC data (Dirichlet coefficients + gamma factors + conductor); pp. 74–75, 79 write it so explicitly: h(n) = −e Σ c(n²)V_{n²}(n) with V built from the theta function of k. And the sign object is defined by the source for any coefficient set: p. 80, "Definition of Z({c(n)}). For a set of coefficients c(n²), n runs through a subset I = cN, define the function Z({c(n)}) = Σ c(n²)Z_{n²}(x)"; with the author's own remark (p. 85) that "It might be true that the function Z({c(n)})(x) defined in 52 keeps its sign for a larger class of coefficients c(n) than those which come from the zeta function of E." **So the central object of the RH-facing part of the corpus is defined from the completed L-function's analytic data and DH has an instance** (take for c(n²) the Dirichlet coefficients of a DH-shaped square — e.g. f_DH(s − ½)² rescaled to the s ↔ 2 − s symmetry of Theorem 40, or any Dirichlet series in the class the p. 80 definition admits; the choice of dressing is a scout's, not this pricing's, and it is not needed to decide the entry).

**Does the condition hold or fail for DH?** Theorem 54's mechanism is substrate-blind: it consumes (∗) (monotonicity of r(t), built from H′′′′ and Proposition 50's cubic) and returns "R(s) has a real singular point x₀ on its line of convergence" by "classical properties of the Laplace–Stieltjes transform of monotone functions, see e.g. [63], Th. 5a,5b of Ch.II §5" (p. 84) — a theorem about Laplace transforms, not about schemes. For a DH-dressed h whose Laplace transform has DH's off-line pole (ρ = 0.808517… + 85.699…i, I.1 STATEMENT) inside the strip, the theorem's conclusion is false, so its hypothesis (∗) must fail for the DH dressing — I infer this from the theorem as stated; the dressing's side conditions (Proposition 50's pole structure at the edge of the strip) are where a scout would have to check that the inference is a theorem. Conversely, Lemma 53 (characteristic p) and Suzuki's results cited at p. 85 (characteristic 0) derive (∗) FROM RH plus side conditions. **Hence (∗) is, up to side conditions, equivalent to RH for the function it is evaluated on: it fails for DH exactly because DH fails RH. That is I.1's excluded case in the form the brief names: "if the condition is equivalent to RH for the function in question, it is a reparametrization (IV.1) and not a generator."** I.1 therefore returns, for the analytic layer: no consumed input fails for DH at the axiom level — the only DH-failing item is the conclusion itself in disguise. For the scheme layer it returns a pass that carries no RH content (the zeta integral's DH-exclusion is the wrapper's, and the wrapper is discarded at p. 70 when h is identified with an inverse Mellin transform).
