## §0 The test a first rung must pass to be "decidable" (stated once, applied in §1–§3a)

A rung is **decidable** when all of the following hold, and it is priced OPEN-NAMED or NO-GO when any fails.

1. **A factual observation settles it.** One of: a number computed; a source read at the page; a construction that exists or fails at bounded degree; a model-world instance that satisfies or violates the input. Never an impression, never "promising".
2. **The return is one of YES / NO / OPEN-NAMED** (the missing datum named), each carried by a theorem-shaped sentence (KICKSTART 10(c): "proof class X cannot yield Y because Z" or "Y holds").
3. **Both closes are writable in advance.** Before the pair runs, the pricing states what YES and NO each do to the branch's grade (dead-end restored on internal grounds / instrument / grossmann-candidate re-opened) and the refutation-shaped sentence banked in each case. A rung whose NO teaches nothing is not a rung.
4. **It sits on the ladder** (10(b)): the lowest rung where the answer is KNOWN comes first — function fields (RH true), then Epstein/Davenport–Heilbronn (RH false), then Dirichlet L, then ζ. A rung that starts above a rung the branch has not run is returned.
5. **It is not a design choice in disguise.** If the observation can only be made after the scout picks a free parameter the interface leaves open (a coefficient rule, a coupling map, a coefficient ring), the rung is not decidable; what is decidable is whether the interface *has* such a parameter, and 10(h) then prices the design, not the scout. This is the test that separates the "(R-a) smallest concrete instance" candidates from the "(R-b) function-field" candidates below.
6. **Its sources are reachable.** A rung needing a source not on disk is decidable only if the source is fetchable in-session (arXiv / open access) or the rung can be phrased around it; otherwise a FETCH line (§4(ii)) and OPEN-NAMED.
7. **It is priced in slots.** One slot = one agent, one session. The price of the pair (two scouts, one per model, blind; one adjudicator only on disagreement) is stated separately from the price of the rung itself.
8. **Absence is never evidence** (zoo V.5; STATUS line 34): no rung may return NO on a null literature search. "The branch does not contain the object" (V.5, THE DISTINCTION) is admissible and is the form every NO below takes.
