## Definitions the digest must use (write them in §0 and apply them uniformly)
- **Mechanism:** a statement S, on the record, such that (S ⟹ RH) or (S ⟹ ¬RH) is proved or is a named theorem-shaped gap, together with a FIRST STEP toward S that an agent could take in one slot. Anything else is an **instrument** (a tool that measures, bounds, formalizes or excludes) or a **barrier** (a theorem that a proof class cannot decide RH).
- **Outcome shapes:** (P) proof; (D-c) disproof by an exhibited counterexample (a certified off-line zero); (D-Λ) disproof by a certified Λ > 0 (Rodgers–Tao: RH ⟺ Λ = 0 with Λ ≥ 0; STATUS "Findings log" 2026-08-11); (I) independence — record that RH is Π⁰₁ (a Turing machine that halts iff RH fails; cite the source you open — e.g. the Davis–Matiyasevich–Robinson formulation or Lagarias's elementary equivalent — never from memory), so unprovability in PA would imply RH; state whether any lane is shaped for (I) (expected: none) and why the program does not pursue it.
- **Beyond the zoo:** for a proposed route, the list of zoo entries whose proof class it would fall into if it used the named ingredient, and the ingredient that takes it outside each — or "none: this route is inside entry X" (which kills it).
