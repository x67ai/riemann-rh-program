## §5 Two elementary theorems that decide the rung (`F/ferro_shapes.py` header lines 1–22 and the LEMMA block; sanity check `F/ferro_shapes.log` line 2)

**5.1 The root-at-(−1) structure theorem.** Let J_e ≥ 0 on the N sites and G = {e : J_e > 0} its support graph. Since (−1)^{#up(σ)} = (−1)^N Π_i σ_i, Z_J(−1) = (−1)^N Z_J(0)·⟨σ₁⋯σ_N⟩₀ (zero-field correlation). The high-temperature expansion e^{Jσσ′} = cosh J·(1 + σσ′ tanh J) gives, for any A ⊂ V, ⟨σ_A⟩₀ = Σ_{F ⊂ G, ∂F = A} Π_{e∈F} tanh J_e / Σ_{F ⊂ G, ∂F = ∅} Π_{e∈F} tanh J_e (∂F = the set of odd-degree vertices of F), every term positive; such an F exists iff |A ∩ C| is even for every connected component C of G. Since Z_J = Π_C Z_C over components: an EVEN-size component has Z_C(−1) ≠ 0 (take A = C); an ODD-size component has Z_C(−1) = 0 (spin-flip symmetry) and Z_C′(−1) = −(−1)^{|C|}Z_C(0)/2·Σ_{i∈C}⟨σ_{C∖i}⟩₀ ≠ 0 (|C ∖ i| even), a simple root. **Hence the multiplicity of the root z = −1 of Z_J equals the number of odd-size components of G** (an isolated site counts: Z = 1 + z). Checked on 300 random ferromagnets with random supports, N = 3..7: multiplicity = number of odd components in every trial (`F/ferro_shapes.log` line 2).

**5.2 Corollary (the five shapes; m_max = 2).** If Z_J(z) = c·P̃(z)(1+z)^m with deg P̃ = 4 and P̃(−1) ≠ 0 (P̃(−1) = 2 − 2b₁ + b₂ = 0 forces a₁ = 0, a₂ = −2p, the classes of §4.4, unrealizable anyway), then G has exactly m odd components and Π_C [Z_C/(1+z)^{[|C| odd]}] = c·P̃, the reduced factors having degrees |C| − [|C| odd] that sum to 4. Components of size ≥ 6 have reduced degree ≥ 6; so the non-isolated part of G is one of **{4}, {5}, {2,2}, {2,3}, {3,3}** and everything else is isolated sites. Therefore **P̃(z)(1+z)^m is a ferromagnet partition function for some m iff it is for some m ≤ 2, and m_max = 2** — a proved bound, not a search cutoff; adjoining decoupled spins beyond the shape's own odd blocks changes nothing, so the pricing's "regularization by (1+z)^m" (PRICING §2(b)(vii), line 116: positivity at m = 7 for (3, 0, −2)) is not a repair: at m = 7, N = 11, the free-J solver reaches residual 0.42 (`F/ferro_shapes.log`, Part C), as the theorem predicts. The shapes {2,2}, {2,3}, {3,3} are products of one block per zero pair: P̃ = (1 + c₁z + z²)(1 + c₂z + z²) with c_j = −2cos θ_j (the roots x_j = 2cos θ_j solve x² + b₁x + (b₂ − 2) = 0); a 2-site block needs c > 0 (J = −½ log(c/2)); a 3-site block's reduced factor is 1 + cz + z² with 1 + c = Σ_i e^{−2(row sum)_i} ∈ (0, 3], so c ∈ (−1, 2]. The shapes {4} (m = 0) and {5} (m = 1) are the CONNECTED realizations and are decided by the free-J solver.

**5.3 The r₂-versus-r₁ lemma (excludes the connected shapes where positivity does not).** With s_i := Π_{j≠i} w_ij ∈ (0, 1] (w = e^{−2J}, finite J), r₁ = Σ_i s_i and the 2-subset weight W({i, j}) = Π_{k∉{i,j}} w_ik w_jk = s_i s_j / w_ij² ≥ s_i s_j, so r₂ ≥ e₂(s) = (r₁² − Σ s_i²)/2 ≥ (r₁² − n − f²)/2 = C(n, 2) + n·f =: L(r₁), n = ⌊r₁⌋, f = r₁ − n (Σ s_i² is convex on the polytope {0 ≤ s_i ≤ 1, Σ s_i = r₁} and is maximized at the vertex (1, …, 1, f, 0, …, 0)); the inequality is STRICT at finite J whenever r₁ ∉ ℤ (the vertex has zero entries).
