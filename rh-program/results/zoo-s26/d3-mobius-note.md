## §2 Clause (2) — the reweighting: the lemma, IV.1's test in writing, and IV.4 read whole

### §2.1 Lemma (information equivalence of the μ-band and the Λ-band) `[derivation]`

Fix X ≥ 2 and write P_X := {p prime : p ≤ X}. For n ≤ X every prime factor of n is ≤ n ≤ X, so the prime factorization of n is a computation inside P_X — the sieve of Eratosthenes on [2, X] is the explicit map — and therefore:

- μ(n) for n ≤ X is a function of P_X: μ(n) = (−1)^k if n is a product of k distinct elements of P_X, and 0 if p² | n for some p ∈ P_X (the definition, Odlyzko–te Riele p. 138 as printed).
- Λ(n) for n ≤ X is a function of P_X: Λ(n) = log p if n = p^k with p ∈ P_X, k ≥ 1, and 0 otherwise.
- Conversely, P_X = {n ≤ X : Λ(n) = log n} (a prime p has Λ(p) = log p; a proper power p^k, k ≥ 2, has Λ(p^k) = log p < log p^k; a non-prime-power has Λ = 0 < log n for n ≥ 2). So (Λ(n))_{n≤X} determines P_X, hence (μ(n))_{n≤X}.
- And directly, Λ(n) = Σ_{d|n} μ(d) log(n/d) for every n ≥ 1 (Möbius inversion of log n = Σ_{d|n} Λ(d)); the divisors d of n ≤ X satisfy d ≤ X, so (μ(n))_{n≤X} determines (Λ(n))_{n≤X} by a formula that never leaves the band.

Hence the two vectors (μ(n))_{n≤X} and (Λ(n))_{n≤X} are mutually determined by explicit maps, and any bandwidth-L observable Σ_{n≤X} μ(n)n^{−1/2}g(log n), X = e^L, supp g ⊂ [−L, L], is a (nonlinear) function of the bandwidth-L Λ-data. "Bandwidth-L Λ-data" means the family of prime sides Σ_{n≤X} Λ(n)n^{−1/2}g(log n) over all admissible g supported in [−L, L]; the atoms log n, n ≤ X, are distinct points with spacing log(1 + 1/n) ≥ 1/(2X) > 0, so the family determines each Λ(n) separately (a bump at log n narrower than the spacing), and the lemma applies. ∎

## §3 Clause (3) — the residue signs: the derivation, the computation, and the paper at the page

### §3.1 The derivation, written in full `[derivation]`

Write ξ(s) = H(s)ζ(s), H(s) = ½s(s − 1)π^{−s/2}Γ(s/2), and Ξ(z) := ξ(½ + iz). ξ satisfies ξ(s) = ξ(1 − s) and ξ(conj s) = conj ξ(s) (real on the real axis; Schwarz reflection). For real z: conj Ξ(z) = ξ(conj(½ + iz)) = ξ(½ − iz) = ξ(1 − (½ + iz)) = Ξ(z), so **Ξ is real on the real axis**, and Ξ(−z) = ξ(½ − iz) = ξ(½ + iz) = Ξ(z), so **Ξ is even**. Differentiating, Ξ′(z) = iξ′(½ + iz); at an on-line zero ρ = ½ + iγ this reads **ξ′(ρ) = −iΞ′(γ)**, with Ξ′(γ) real. If ρ is simple then Ξ′(γ) ≠ 0, and **between consecutive simple real zeros γ_n < γ_{n+1} of Ξ the signs of Ξ′ alternate**: if Ξ′(γ_n) > 0 then Ξ > 0 immediately to the right of γ_n, Ξ has no zero in (γ_n, γ_{n+1}), so Ξ > 0 on that interval and Ξ′(γ_{n+1}) ≤ 0, hence < 0 by simplicity. Therefore:

- **Res_{s=ρ} 1/ξ = 1/ξ′(ρ) = i/Ξ′(γ)** — purely imaginary, with alternating sign along the on-line zeros.
- **Res_{s=ρ} 1/ζ = 1/ζ′(ρ) = H(ρ)/ξ′(ρ)** (at a zero of ζ, ξ′ = H′ζ + Hζ′ = Hζ′) — the same alternation rotated by the archimedean phase arg H(½ + iγ); and the Mertens weight 1/(ρζ′(ρ)) = H(ρ)/(ρξ′(ρ)) is rotated further by arg(1/ρ) → −π/2 as γ → ∞, which is why Re[1/(ρζ′(ρ))] tracks Im[1/ζ′(ρ)]/γ and nearly, but not strictly, alternates (§3.2: 108 sign changes in 199 steps).
- **The FE symmetry** ξ′(s) = −ξ′(1 − s) (differentiate ξ(s) = ξ(1 − s)) and ξ′(conj s) = conj ξ′(s) give **ξ′(1 − conj ρ) = −conj ξ′(ρ)** for every ρ. On the line, 1 − conj ρ = ρ and this says ξ′(ρ) is purely imaginary — the statement above. For an off-line pair {ρ, 1 − conj ρ} (both zeros, by FE and reality), the residues of 1/ξ are c := 1/ξ′(ρ) and −1/conj ξ′(ρ) = −conj c, whose sum at equal test weights is c − conj c = 2i·Im c: purely imaginary too.
