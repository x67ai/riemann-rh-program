### §3.1 r5-02 (Tôhoku 1988) — the printed definition of a Markov LMS, with every hypothesis

**Standing hypotheses (Introduction, p. 165, first sentence) [vision]:** "Let (M, 𝓕) be a closed, transversely orientable, C²-foliated manifold of codimension one." — So: **M closed** (compact, no boundary); **𝓕 transversely orientable**; **C²**; **codimension one**. Orientability of M itself is NOT assumed here (contrast r5-01, §3.2). Dimension of M arbitrary.

**Local minimal set (p. 165) [vision]:** "Let O(𝓕) denote the family of open, 𝓕-saturated subsets of M. Let U ∈ O(𝓕), and let L be a leaf of 𝓕|U. Smoothness of class C² implies that there exists a compact, transverse one-manifold R ⊂ U such that every leaf of L̄ ∩ U meets int(R) [C-C 1, (3.7)]. Consequently, L̄ ∩ U contains a minimal set of 𝓕|U [C-C 1, (3.0)].
DEFINITION. An 𝓕-saturated subset X ⊆ M is a local minimal set (LMS) of 𝓕 if there exists U ∈ O(𝓕) such that X is a minimal set of 𝓕|U.
Every proper leaf is a LMS, with U = M ∖ (L̄ ∖ L). If U ∈ O(𝓕) and each leaf of 𝓕|U is dense in U, then U itself is a LMS. Finally, an exceptional LMS is one of neither of these types. If X is exceptional, then the transverse manifold R ⊂ U can be chosen so that C = X ∩ R is a Cantor set and misses ∂R." ([C-C 1] here = the TAMS 1981 Poincaré–Bendixson paper, row 3.)

**The informal definition of Markov LMS (pp. 165–166) [vision]:** "Let X be an exceptional LMS, with U, R, and C as above. The holonomy of 𝓕|U induces a C² pseudogroup Γ on R for which C is a Γ-minimal set. Let Γ|C denote the induced pseudogroup on C. It frequently happens that the choice of R can be made so that Γ|C is generated by the local restrictions of a single transformation τ: C → C which, in a sense to be made precise in §1, is essentially a one-sided subshift of finite type (also known as a topological Markov chain [Wa, p. 119]).
DEFINITION. If there exists τ: C → C as above, then C is a Markov Γ-minimal set and X is called a Markov LMS."
Immediately after (p. 166): "While there exist examples of exceptional LMS that are not Markov LMS (see §7), it is likely that the Markov ones are the fundamental 'building blocks' for the general case (in a sense that we cannot presently make precise). At any rate, examples of Markov minimal sets abound in the literature (cf. [Sa 1], [Ra], [He], [G-S], [In], [Ma])."

**The precise definition — §1 "Markov pseudogroups" (p. 167) [vision]:** "Let 𝒮 = ({I₁, ⋯, I_m}, {h₁, ⋯, h_m}, P), where each I_j ⊂ **R** is a compact, nondegenerate interval, each h_j is a C² diffeomorphism with range R(h_j) and domain D(h_j), both being open, bounded intervals, and P = (p_ij) is an m × m matrix with entries p_ij ∈ {0, 1}. Assume that m ≥ 2.
DEFINITION. If the following properties hold, then 𝒮 is called a Markov system and the pseudogroup Γ = Γ_𝒮, generated by (h_j)_{j=1}^m, is called a Markov pseudogroup.
(1) R(h_i) ∩ R(h_j) = ∅, i ≠ j.
(2) I_j ⊂ R(h_j), for all j. Set X_j = h_j^{−1}(I_j).
(3) p_ij = 1 implies that I_j ⊆ X_i.
(4) p_ij = 0 implies that I_j ∩ D(h_i) = ∅."
Then (p. 167): for a P-admissible word w = h_{i₁} ∘ ⋯ ∘ h_{i_n} (defined at a point of X_{i_n} iff p_{i_k i_{k+1}} = 1 for 1 ≤ k ≤ n−1), I_w = w(X_{i_n}); "Z = ∩_{n=1}^∞ (∪_{|w|=n} I_w), Z₀ = Z ∖ int(Z)." "DEFINITION. If 𝒮 is a Markov system and x ∈ R(h_i), set T(x) = h_i^{−1}(x) ∈ D(h_i). This well defines T: ∪ R(h_i) → ∪ D(h_i), locally a C² diffeomorphism, such that T(Z₀) ⊆ Z₀. Set τ = T|Z₀: Z₀ → Z₀, a continuous map that is locally a homeomorphism. DEFINITION. A sequence (i_n)_{n=1}^∞ such that p_{i_n i_{n+1}} = 1, for all n ≥ 1, is called P-admissible. The set of all such sequences is denoted by 𝒦_P."
(p. 168) [vision]: "We formalize this as a surjection, h: Z₀ → 𝒦_P, h(x_ι) = ι, that is two to one on at most a countable subset of Z₀ and, elsewhere, is one to one. … Then 𝒦 is a Cantor set and, in the more interesting cases, so is 𝒦_P. In any case, the surjection h: Z₀ → 𝒦_P is continuous. DEFINITION. The (one-sided) shift σ: 𝒦 → 𝒦 is defined by σ(j₁, j₂, j₃, ⋯) = (j₂, j₃, ⋯) and σ = σ|𝒦_P: 𝒦_P → 𝒦_P is called a subshift of finite type or a topological Markov chain. Evidently, σ ∘ h = h ∘ τ, so τ is semiconjugate to σ."

**(1.1) LEMMA (p. 168) [vision]:** "The set 𝒦_P is a Cantor set and Γ_σ-minimal if and only if there exists an exceptional Γ-minimal set C ⊆ Z₀ such that h(C) = 𝒦_P. In this case, Z₀ ∖ C is a union of at most countably many Γ-orbits, each of which accumulates exactly on C." REMARK (p. 169): "A condition that guarantees the hypotheses in (1.1) is that, for all (i, j) ∈ {1, ⋯, m}², there exists k ≥ 1 such that the (i, j)-th entry of P^k (the k-th power of the matrix) is ≥ 2."

**The abstract definition — "essentially conjugate" and "Markov Γ-minimal set" (p. 169) [vision]:** "DEFINITION. Let Γ be a pseudogroup on an open subset of **R**, Y ⊂ **R** a compact, totally disconnected, Γ-invariant set. Let τ: Y → Y be a transformation belonging locally to Γ|Y and generating that pseudogroup. Let σ: 𝒦_P → 𝒦_P be a subshift of finite type and h: Y → 𝒦_P a continuous surjection such that h ∘ τ = σ ∘ h. Suppose that, for all y ∈ Y, h^{−1}(h(y)) is either a singleton or is the pair of endpoints of the closure of a bounded component of **R** ∖ Y. Then τ is said to be essentially conjugate to the subshift σ (and, less precisely, τ is said to be an essential subshift). If there exists an exceptional Γ-minimal set C ⊆ Y such that h(C) = 𝒦_P, then C is called a Markov Γ-minimal set."

**(1.2) LEMMA (p. 169) [vision]** — the converse, which is what makes the definition usable: "Let Γ̃ be a C² pseudogroup on an open subset of **R**, C̃ a Markov Γ̃-minimal set. Then there exists an open neighborhood W of C̃, a smooth imbedding ι: W → **R**, and a C² Markov pseudogroup Γ on a neighborhood of C = ι(C̃) in **R**, such that ι ∘ (Γ̃|C̃) ∘ ι^{−1} = Γ|C, Γ defines the essential subshift τ: Z₀ → Z₀, and C ⊆ Z₀ is a Markov Γ-minimal set."
(p. 170) [vision]: "The precise meaning of the definition of Markov LMS for a foliated manifold, as indicated in the introduction, should now be clear. By (1.2), it will be sufficient to prove our theorems under the assumption that the holonomy pseudogroup Γ on a neighborhood of C in int(R) is a Markov pseudogroup and that C ⊆ Z₀ is a Markov Γ-minimal set."

**Assembled (the source says, pieces joined; nothing added):** X ⊆ M is a **Markov LMS** of 𝓕 iff (a) X is an exceptional LMS: X is a minimal set of 𝓕|U for some open saturated U, X is neither a proper leaf nor an open saturated set with all leaves dense; (b) a compact transverse one-manifold R ⊂ U can be chosen with C = X ∩ R a Cantor set missing ∂R, such that (c) the holonomy pseudogroup Γ|C of 𝓕|U on C is generated by the local one-one restrictions of a single map τ: C → C which is essentially conjugate to a one-sided subshift of finite type σ: 𝒦_P → 𝒦_P — i.e. there is a continuous surjection h: C → 𝒦_P with h ∘ τ = σ ∘ h whose fibers are singletons except for at most the two endpoints of a gap of C. **Hurder's gloss "generated by a (1-sided) subshift of finite type" is therefore a compression of "generated by a map essentially conjugate (semiconjugate, ≤ 2-to-1 on gap endpoints) to a one-sided subshift of finite type"; the printed condition is a condition on the holonomy pseudogroup restricted to a transversal Cantor set C = X ∩ R, for a suitably chosen R.**

**Realization remarks (p. 170) [vision]:** "(1) Given a Markov pseudogroup Γ as in (1.1), one can realize Γ as the holonomy in a neighborhood of an exceptional minimal set X in a suitable C²-foliated manifold. One method, that of 'branched staircases', is due to Takamura [Ta] and Inaba [In]. Another produces X in the nonsingular part of a singular foliation and then removes the singularities. Sometime Γ can be 'completed' to a subgroup of Diff²(S¹) [Sa 1], [G-S] and X can then be realized in a suitable foliated S¹-bundle. (2) Having realized Γ as the holonomy of a Markov minimal set X, one can turbulize along a closed transversal meeting X to produce a Markov LMS at level one. Indeed, it is possible to realize Γ as the holonomy of a Markov LMS at any desired finite level." — **This is the only mention of "level" in the paper. Nothing is said about infinite level.**

### §3.2 r5-01 (Publ. Mat. 1989) — the theorem under which semiproperness is dropped

**Standing hypotheses (Introduction, p. 461) [vision]:** "Let M be a compact, orientable manifold, 𝓕 a transversely orientable C² foliation of M of codimension one. Each component of ∂M, if there are any, is to be a leaf. Let X be a local minimal set (LMS) of 𝓕. That is, there is an open, connected, 𝓕-saturated subset U ⊆ M and X is a minimal set of 𝓕|U. A special class of such sets, called Markov LMS, was introduced in [C-C 1]. These are exceptional LMS such that the holonomy pseudogroup of the foliated set (X, 𝓕|X) is, in a certain sense, generated by a subshift of finite type (see §1). We will see, in §6, that every such subshift can occur for suitable Markov minimal sets in suitable C^∞-foliated 3-manifolds." [The promised §6 is in fact "Geometry of leaves", four conjectures; no realization is carried out in the paper — see §4.]
"Let ℰ(L) denote the set of ends of a leaf L ⊂ X, a compact, totally disconnected metrizable space of ideal points of L at infinity. Let ℰ*(L) denote the closed subspace of ends that are asymptotic to L. In case X is a minimal set of 𝓕 (i.e., we take U = M), it is clear that ℰ(L) = ℰ*(L)." **THE THEOREM (p. 462) [vision], verbatim:**

**Exact hypotheses of Theorem 1, as printed (nothing else is assumed anywhere in the proof):**

**Theorem 3 (p. 471) [vision — this page is absent from the text layer], verbatim:**
> "**Theorem 3.** Let 𝓕 be of class C² and let X be a Markov LMS of 𝓕, minimal for 𝓕|U, where U is an open, connected, 𝓕-saturated set. Let F be a component of ∂Û on which X accumulates in Û and let x ∈ F. Then the relative holonomy group ℋ_x(F, X) is infinite cyclic, generated at x of a unique contraction f̂ = f|(X ∩ [x, b]) to x, where [x, b] is an arc transverse to 𝓕̂, b ∈ X, and f ∈ Γ_𝓕̂. Finally, for a suitable choice of the decomposition of Û, the total holonomy group ℋ(V_i, X) is trivial, 1 ≤ i ≤ r."
Here Û = K ∪ V₁ ∪ ⋯ ∪ V_r is Dippolito's completion of U with nucleus K and arms V_i (p. 466–467, 471), and (p. 471) "As a component of ∂Û, F is a leaf of 𝓕̂. If X accumulates on F in Û, then the relative holonomy group ℋ_x(F, X) is taken to be the group of germs at x of elements γ|(X ∩ D(γ)), where γ ∈ Γ_𝓕̂ fixes x ∈ F". Remark (p. 471): "In particular, f̂ is a compactly supported, relative holonomy element on F. As usual, this implies that there is a handle H ⊂ F such that each loop σ in F at x, with homological intersection number σ ∗ H = 0, has holonomy h_σ fixing every point of X ∩ [x, b] at which it is defined."

**Theorem 2 (p. 462) [vision], verbatim** (the "other topological results"): "Definition. A leaf L is resilient if it has a holonomy contraction and if L itself is captured by this contraction. Definition. A handle in L is a compact, connected, nonseparating submanifold H of codimension one, ∂H = ∅. The genus of L is the maximal number of pairwise disjoint handles in L that are linearly independent in H_∗(L; **R**). **Theorem 2.** Let X ⊂ M be a Markov LMS of 𝓕. Then X contains exactly a countable infinity of resilient leaves. Furthermore, either genus(L) = 1, for each resilient leaf L ⊂ X, the remaining leaves of 𝓕|X having genus 0, or every leaf L ⊂ X has infinite genus and every end ε ∈ ℰ*(L) is a cluster point of handles." "It was shown in [C-C 1] that each semiproper leaf in X is resilient, but that there are only finitely many such leaves."

**The definition of Markov LMS as used in r5-01 (§1, pp. 462–463) [vision], verbatim:**
(p. 462) "Let m ≥ 2 be an integer and let 𝒦 denote the Cantor set {1, 2, …, m}^**N** with typical element ι = (i₁, i₂, …). Let P = (p_ij) be an m × m matrix with entries from the set {0, 1}. For many choices of P, the set 𝒦_P = {ι ∈ 𝒦 | p_{i_j i_{j+1}} = 1, 1 ≤ j < ∞} is also a Cantor set. In any case, the map σ: 𝒦_P → 𝒦_P, defined by σ(i₁, i₂, i₃, …) = (i₂, i₃, …) is called a subshift of finite type, or a topological Markov chain [Wa]. A subshift of finite type is locally a homeomorphism. The pseudogroup Γ_σ on 𝒦_P, generated by the local one-one restrictions of σ, is said to be generated by the subshift σ.
If X ⊂ M is an exceptional LMS for 𝓕, fix T ⊂ **R**, a finite union of open, bounded intervals, let T̄ denote the closure of T, a compact one manifold, and fix an imbedding ρ: T̄ → U, transverse to 𝓕 and such that C = X ∩ ρ(T) is a Cantor set. Here, of course, U is an open, connected, 𝓕-saturated subset of M such that X is a minimal set for 𝓕|U. Let Γ denote the pseudogroup on T induced by the holonomy of the foliation 𝓕 and let Γ|C be the induced pseudogroup on C. By an abuse, we suppress all mention of ρ hereafter."
(p. 463) "**Definition.** Suppose that the above choices can be made so that there is a subshift of finite type σ: 𝒦_P → 𝒦_P and maps τ: C → C and η: C → 𝒦_P having the following properties:
(1) τ is locally a homeomorphism and Γ|C is generated by the local one-one restrictions of τ;
(2) η is a continuous surjection;
(3) η^{−1}(η(x)) is either a singleton or the pair of endpoints of a gap of C, for every x ∈ C;
(4) η ∘ τ = σ ∘ η.
Then τ is said to be essentially a subshift of finite type generating Γ|C, C is called a Markov Γ-minimal set, and X is called a Markov LMS of 𝓕."
"The constructions of Sacksteder [Sa 1], Raymond [Ra], Hector [He], Ghys and Sergiescu [G-S], Inaba [In], and others provide examples of Markov minimal sets of a foliation 𝓕. It is not hard to modify these to produce Markov LMS that are not minimal sets of 𝓕."
Markov system (p. 463) [vision]: "Let 𝒮 = ({I₁, …, I_m}, {h₁, …, h_m}, P), where P is an m × m matrix of 0's and 1's, I_j ⊂ **R** is a compact, nondegenerate interval, h_j: D(h_j) → R(h_j) is an orientation preserving homeomorphism between open, bounded intervals, and I_j ⊂ R(h_j), 1 ≤ j ≤ m. Set X_j = h_j^{−1}(I_j). Let Γ_𝒮 denote the pseudogroup generated by {h_j}_{j=1}^m. If the following properties hold, then 𝒮 is a Markov system and Γ_𝒮 is a Markov pseudogroup: (1) R(h_i) ∩ R(h_j) = ∅, i ≠ j; (2) p_ij = 1 implies that I_j ⊆ X_i; (3) p_ij = 0 implies that I_j ∩ D(h_i) = ∅."
Lemma 1.2 (p. 464) [text]: "Let X be a Markov LMS of 𝓕 and let C, τ, P, 𝒦_P, T, and η be as in the definition of such a set. Then this data can be chosen so that there exists a Markov sub-pseudogroup Γ_𝒮 ⊆ Γ, defined relative to the matrix P, such that C ⊆ Z₀, η_𝒮|C = η: C → 𝒦_P, τ_𝒮|C = τ, and Γ_𝒮|C = Γ|C." Lemma 1.6 (p. 465) [text]: "If 𝓕 is of class C² and X ⊂ M is a Markov LMS, then the Markov system 𝒮 of (1.2) can be chosen so that I_ι is a singleton, for each ι ∈ 𝒦_P. In particular, η: C → 𝒦_P is a homeomorphism." (p. 465: "Remark that so far in this section we have not needed smoothness hypotheses. For the following, smoothness of class at least C² seems to be necessary.")

**Plain-English reading (I infer, for the orchestrator).** The Markov papers do exactly what the Warsaw sentence says and no more: if the leaf lies inside a Markov local minimal set, its ends form a Cantor set whether or not it is semiproper.
