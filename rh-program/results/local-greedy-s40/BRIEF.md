## The object
**S7(ρ): the same integer-level feedback, but the rule may act only at prime powers.** Walk n = 2, 3, …; A(n) = number of representations of n by the g-primes chosen so far; if n = p^k is a prime power, put m_n := max(0, ⌊ρ(n − 1) + 1 − N(n − 1) − A(n) + ½⌋) copies of n into the g-prime list; if n is not a prime power, m_n := 0. Then every g-prime is a power of a rational prime, the coefficients a_n are MULTIPLICATIVE (ζ_P(s) = Π_p f_p(p^{−s}), f_p(u) = Π_k (1 − u^k)^{−m_{p^k}}), and a_n ≪ n^ε as long as the local multiplicities stay small (prove the bound you actually get) — the multiplicity explosion of S5 cannot occur. Writing a = 1 ∗ g (g multiplicative), N(x) = Σ_d g(d)⌊x/d⌋ and ζ_P = ζ·L_g: the class of "pseudo-character twists" of ℕ. ρ = 1 must return the rational primes (control).
