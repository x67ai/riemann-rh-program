**(i) Configuration side — the A4 gate world, unchanged.** A candidate configuration is an N-periodic marked multiset on a circle of circumference N in mean-gap units: on-line atoms at positions θ_z with integer marks m_z ≥ 1, and off-line pairs at positions θ_j with dimensionless depth w_j ∈ [0, 1] (`results/a4-m2-gate/SPEC.md` §1.1 lines 21–33, §1.2 lines 35–58, §1.4 lines 66–77). Its second-order data are the traces tr Ĝ_λ^k of the Gram matrix built from the sampling kernel ψ_λ — the master trace formula of SPEC §1.1 — read in Fourier form through the coefficients c_k = Σ_z m_z e^{−2πi k θ_z/N} (SPEC §1.4, lines 68–73), and the second-order rows of the two-moment LP are the density row tr = N and the Frobenius row tr Ĝ_1² = m₂(1)·N = (4/3)N (SPEC §2.2 lines 98–106; §0 line 13: "min N_d/N = 5/6, attained by the extremal configuration 2/3 simple + 1/6 on-line doubles"). The A4 gate's decided witness for that extremal is a marks-{1, 2} law on the ψ₁-zero grid, where grid-Parseval decouples the bandwidths (zoo IV.7 Session-6 closure, BARRIER-ZOO.md line 377; `results/a4-m2-gate/witness_N64.json`). **(ii) Embedding at a height.** To evaluate a first-order rule the configuration must be placed in the strip. Fix a height T and write ℓ := log(T/2π), so that ℓ/2π is the Riemann–von Mangoldt mean density μ_∞(T) (C2 line 14: μ_∞(τ) = (2π)⁻¹ Re ψ(1/4 + iτ/2) − (log π)/2π, which is (1/2π)log(τ/2π) + O(τ⁻²)). The embedding is τ_z = T + (2π/ℓ)·θ_z for the real parts and y_j = w_j/L′ for the imaginary parts of the pairs, where L′ is SPEC §1.2's second-bandwidth length scale (w = δ·L′, SPEC line 47), L′ ≍ ℓ; the exact O(1) constant in y_j is immaterial below because only y_j² ever enters (§1.3). In the notation of C2 line 14 the embedded configuration is Z = σ + D with σ the on-line integer-atomic measure and D the defect multiset.

**(iii) The prime datum a candidate configuration carries: NONE — and none is needed for the rows.** C2's Sector-I row is derived from the master identity (C2 line 16): for g = w/cosh(u/2) with w ∈ Σ_L := {w ≥ 0, ŵ ≥ 0, supp w ⊂ [−L, L]},

    ∫ (ŵ ∗ μ₀) dσ + 2 Σ_j (ŵ ∗ μ_{y_j})(x_j) + ∫ (w/cosh(u/2)) dπ = B(w) := 2∫ w du + ∫ (ŵ ∗ μ₀)(τ) μ_∞(τ) dτ,

with every term nonnegative. Axiom P (Λ(n) ≥ 0, C2 line 14) is consumed at exactly one place: the prime share ∫ (w/cosh(u/2)) dπ ≥ 0 is DROPPED, leaving the one-sided row

    R_w :  ∫ (ŵ ∗ μ₀) d(σ − μ_∞ dτ) + 2 Σ_j (ŵ ∗ μ_{y_j})(x_j) ≤ 2∫ w du.        (1.1)

The row (1.1) contains no π. It is a statement about the configuration alone; the datum enters only as the archimedean functional A (axiom FE — ζ's own μ_∞ and pole term, C2 line 14) and through the requirement that the configuration be the zero set of SOME datum satisfying P. So the answer to correction C2's first question is: **a candidate configuration carries no prime datum; the cone rows are prime-free upper bounds on the μ₀-smoothed one-level density plus depth-weighted defect terms, with the pole term 2∫w as the allowance.** The existence question "is there a positive Chebyshev-growth π realizing this configuration" (C2 lines 16, 62; zoo I.2) does not have to be answered to write or test the rows — which is what makes the experiment cheap — and it is also why the rows are weak (§1.3).

**(iv) The alternative object — first-order EQUALITIES with ζ's own π — is not an M5 object.** If instead of dropping the prime share one keeps it with ζ's own π, the rule Σ_{γ∈Z} ĝ(γ) = A(g) − ∫ g dπ (C2 line 14) for all even C² g with supp g ⊂ [−L, L], L = α·ℓ, pins the configuration's Fourier coefficients c_k for |k| ≤ αN (2αN real numbers) to ζ's own; at α = 1 this over-determines the N real positions, so the only configuration compatible with the full band is ζ's own zero set at half-gap resolution — "the extremal is excluded" then means only "ζ's zeros at height T are not 1/3 doubly occupied at half-gap resolution," which is a fact about ζ's zeros computed from primes, not a certificate. Evaluating that right-hand side pointwise at height T requires Σ_{n ≤ T^α} Λ(n) n^{−1/2−iT} h(log n) — the M6 detector's quantity (C2 line 48), behind the pointwise-short-Dirichlet-polynomial wall C2 names as its own (line 64; repair 6, line 74) and A4 names as the Lindelöf lock (digest §C row 6; zoo IV.7 Session-6 closure). That is the object priced.**

**(v) Which LP.** The joint system is: OUTER = the A4 configuration primal at bandwidth 1 (SPEC §§1–4, `code/master_lp.py`, `column_gen.py`) over probability laws on dictionary columns; INNER = the cone rows (1.1), which hold configuration-by-configuration (each column must be an admissible zero set), so they act as a FILTER on dictionary columns, not as rows on the law's expectations. ### §1.2 The rows, exactly, in the LP's units — height-T localization and the effective allowance

Write ĝ(τ) := ∫ g(u) e^{−iuτ} du, so that ĝ(i/2) + ĝ(−i/2) = ∫ g(u)(e^{u/2} + e^{−u/2}) du = 2∫ w du for g = w/cosh(u/2) — the pole term of (1.1) in this normalization (C2 line 16: "2 ŵ(0) … precisely = 2∫ w du + …"). Because w ≥ 0 forces ŵ(0) ≥ |ŵ(ξ)| for every ξ, no cone element is localized away from τ = 0: a height-T element is w(u) = h(u)(1 + cos Tu) with h ∈ Σ_L (then w ≥ 0 and ŵ = ĥ + ½[ĥ(·−T) + ĥ(·+T)] ≥ 0), and its transform splits as ĝ = ĝ_c + ĝ_T with

    ĝ_c := (h/cosh(u/2))^ =: k,     ĝ_T(τ) = ½[k(τ − T) + k(τ + T)].

The central component pairs with ζ's low zeros. With ζ's own datum its identity is exact (C2 line 14 at the test h/cosh(u/2)):

    Σ_γ ĝ_c(γ) − ∫ ĝ_c μ_∞ = 2∫ h − P(h),     P(h) := 2 Σ_n Λ(n) n^{−1/2} h(log n)/cosh(½ log n) = 4 Σ_n Λ(n) h(log n)/(n + 1) ≥ 0.

Let Z′ be ζ's zero set with the zeros under ĝ_T's weight replaced by the embedded periodic configuration (the model configuration of the experiment). Applying ζ's own identity to the even test g_T = h(u)cos(Tu)/cosh(u/2) as well — Σ_γ ĝ_T(γ) − ∫ ĝ_T μ_∞ = 2ĥ(T) − P_T(h), P_T(h) := 2 Σ_n Λ(n) n^{−1/2} h(log n) cos(T log n)/cosh(½ log n), ĥ(T) := ∫ h(u) cos(Tu) du — the row R_w for Z′ is EQUIVALENT to

    E_T(h) ≤ P(h) + 2ĥ(T),        (1.2)

    E_T(h) := Σ_{z on-line} m_z ĝ_T(τ_z) + Σ_{pairs} [ĝ_T(x_j + iy_j) + ĝ_T(x_j − iy_j)] − ∫ ĝ_T μ_∞ dτ,

the ĝ_T-smoothed one-level-density excess of the configuration over the Riemann–von Mangoldt mean, plus depth-weighted defect excess. (Derivation: Σ_{Z′} ĝ − ∫ ĝ μ_∞ = [Σ_ζ ĝ − ∫ ĝ μ_∞] − [Σ_ζ ĝ_T − ∫ ĝ_T μ_∞] + E_T(h) = [2∫w − P(h) − P_T(h)] − [2ĥ(T) − P_T(h)] + E_T(h), and 2∫w = 2∫h + 2ĥ(T); the oscillatory prime sum P_T cancels identically. The variation of μ_∞ across the kernel's width contributes O(h(0)/T²) and is dropped; for Fejér-type h, ĥ(T) = O(h(0)/(T²L)) and is kept in the computations for honesty.) **Reading of (1.2): the cone row at height T allows the smoothed density excess to be at most the prime share P(h) of the demodulated element h — which is 0 for L < log 2 (no n ≥ 2 has log n < log 2), and tends to 2∫h (the pole term) as L → ∞ by the prime number theorem (4∫₀^∞ h(u) e^u/(e^u + 1) du → 2∫h for h spread over |u| ≫ 1).** If one instead reads the periodic configuration as the entire zero set of an abstract datum with constant density (no low zeros, no origin), the allowance is the pole term 2∫h ≥ P(h), a weaker row; every conclusion below for (1.2) holds a fortiori for that reading.

**(1.2) in Fourier form — exact for the periodic model.** With the configuration N-periodic on the whole line at mean density ℓ/2π, Poisson summation gives, with u_k := kℓ/N and g(u) := h(u)/cosh(u/2),

    E_T(h) = (ℓ/N) Σ_{k ≥ 1} Re[ c_k^{on} + c_k^{pr} cosh(u_k y) ] · g(u_k),        (1.3)

where c_k^{on} = Σ_{on-line z} m_z e^{−2πi k θ_z/N}, c_k^{pr} = Σ_{pairs} 2 e^{−2πi k θ_j/N} (a pair counts two zeros), the origin θ = 0 is the height T, and the k = 0 term cancels exactly against ∫ ĝ_T μ_∞ = ½ h(0) ℓ. Scanning the height across one period is scanning the rotation θ₀ of the configuration (c_k ↦ c_k e^{−2πi k θ₀/N}). The sum runs over |u_k| ≤ L. This is the formula the sanity computation implements (§1.4, `verify/cone_rows_check.py`).

**(a) What the rows constrain, in the LP's normalized units.** By (1.3): the configuration's density-modulation amplitudes a_k := 2|c_k|/N at the u-frequencies u_k = kℓ/N (wavelength N/k mean gaps), each weighted by g(u_k) = h(u_k)/cosh(u_k/2), summed against the mean density ℓ/2π, plus the depth factor cosh(u_k y) − 1 = O(u_k² y²) on the pair part. Two facts fix everything: (F1) positive-definiteness gives 0 ≤ h(u) ≤ h(0), so |g(u)| ≤ h(0)/cosh(u/2) ≤ 2h(0)e^{−|u|/2} — the cosh division that makes the cone strip-positive (C2 line 16, "the division is exactly the pole weight") is a hard exponential damping of every mode; (F2) the allowance P(h) grows linearly with L for spread-out h (P(Fejér_L) → 2L h(0)). A single mode of relative amplitude a at frequency u is therefore allowed up to a ≤ (2π/ℓ)·P(h)·cosh(u/2)/h(u), i.e. the rows are non-vacuous (bound < 1) only for u ≲ L* with L* solving 8πL* cosh(L*/4) ≈ ℓ, L* ≈ 4 log log T + O(1) for the Fejér family (I infer the constant; the sanity computation exhibits the saturation). Mean-gap scale is u ≍ ℓ = log(T/2π) ≫ L*.

**(b) Are the rows implied by the LP's existing normalization plus trivial bounds? — three regimes, one refutation-shaped answer each.**

* **L < log 2 (P(h) = 0).** Row (1.2) reads E_T(h) ≤ 2ĥ(T) ≈ 0: the ĝ_T-smoothed density may never exceed the mean. Since the smoothed fluctuation has mean zero over a period and is ≤ 0 at every height, it vanishes identically; taking h = Fejér with L → log 2⁻ shows c_k = 0 for every mode with |u_k| < log 2, i.e. k < N log 2/ℓ. This is NOT implied by the two-moment rows: the 256-law's grid form factor is within 3·10⁻⁴⁰ of j/256 for 0 < j < 256 (zoo I.3 (b), BARRIER-ZOO.md line 55), so E|c_1|² > 0, and some configuration in its support has c_1 ≠ 0 — as embedded at any height with ℓ < 256 log 2 (T < 2^{256}) it VIOLATES a prime-free, axiom-P-free first-order identity. This is Berry's number-variance saturation (the shortest "orbit" log 2; Berry 1985/1988, corpus t-03a, image-only), a fact about ζ's long-wavelength rigidity, and it has nothing to do with marks: it constrains modes at wavelength ≥ ℓ/log 2 mean gaps (≈ 17 gaps at T = 10⁶), and zeroing them changes the off-diagonal Frobenius budget by Σ_{0<|k|<α₀N}(N−|k|)|k|/N² ≈ α₀²N against N/3, a relative 3α₀² = 3(log 2/ℓ)² → 0 (0.0076 at T = 10⁶; 0.002 at 10¹²; I infer that the min N_d/N of the two-moment LP moves by at most this order — the execution slot verifies). Witness that the PROPORTION survives: the ψ₁-grid extremal with doubles at sites ≡ 0 and vacancies at sites ≡ 3 (mod 6) — N/6 doubles, N/6 vacancies, 2N/3 simples — has c_k = 0 for every k ∉ (N/6)Z, hence satisfies every L < log 2 row with equality once ℓ/6 > log 2 (T > 2π·64). **So: at L < log 2 the referee's parenthesis ("which the ceiling's adversarial laws already match", C2 line 71) is false in the letter and true in substance — the 256-law's realization is excluded, the 2/3 + 1/6 proportion is not.**
* **log 2 ≤ L ≲ L*.** P(h) > 0 and the row is a genuine, non-vacuous bound on long-wavelength density modulation — the content C2 line 16 identifies with Landau's zero-detection inequality (degeneration (b)) and Littlewood-type S₁ bounds. It is not implied by the two-moment rows (a two-moment adversary may carry a density spike of RvM-allowed size C₁ℓ in a unit τ-window at o(N) Frobenius cost; the cone row excludes spikes above (1 + 2α)× the mean at scale 1 in τ — I infer the constant from (1.2) with Fejér h). But the extremal needs no spike: on the grid its density is the mean at every scale above one gap.
* **L > L* (bandwidth saturation).** Rows at bandwidth L are implied by rows at bandwidth L* plus the RvM density axiom: split h = h·1_{|u|≤L*} + h·1_{|u|>L*}; the tail has ‖g·1_{|u|>L*}‖₁ ≤ 8h(0)e^{−L*/2} by (F1), and pairs against a fluctuation whose ĝ_T-smoothed size is ≤ C₁ℓ·h(0) (axiom RvM, C2 line 14), giving a contribution ≤ 8C₁ℓ h(0)e^{−L*/2} ≤ P(h) − P(h·1_{|u|≤L*}) once L* ≥ 2 log(Cℓ) — while the allowance P(h) only grows. **Hence "the least L at which the extremal is excluded" has no finite answer, and more: the rows at L > L* = O(log log T) add nothing on any RvM-admissible configuration.** [Lemma, to be written and checked in the execution slot; the constants are the slot's work.]

### §1.3 Depth: the cone rows and the double-versus-pair distinction (IV.7 template question, answered here)

For a pair at depth y replacing a double at the same site, (1.3) changes by 2∫₀^L g(u)(cosh(uy) − 1)cos(u(x − T)) du per pair, bounded in absolute value by 2h(0)∫₀^∞ (cosh(uy) − 1)/cosh(u/2) du = 2h(0)·π(1/cos(πy) − 1) = 2π³ y² h(0)(1 + O(y²)), using ∫₀^∞ cosh(yu)/cosh(u/2) du = π/cos(πy) for |y| < 1/2. The bound is INDEPENDENT of L — because h(u) ≤ h(0) caps the edge weight — and saturates as L → ∞. At the LP's depths y = w/L′ ≍ w/ℓ (SPEC §1.2) this is O(h(0)/ℓ²) per pair against an allowance P(h) ≍ L h(0): the cone rows are blind to the double-versus-shallow-pair distinction at every bandwidth to relative order ℓ⁻³, the same affine-plane blindness zoo IV.7 records for the cubic row ("BLIND to pairs at every depth", SPEC §1.2 line 55) and II.4 records for the two-moment certificate. C2's S3 claim (line 29) — separation "of size δ² e^{δL(1−ε)} for edge-weighted tests" — is a Sector-II (signed, edge-weighted) statement; inside the cone the edge weight is capped by h(0) and the growth e^{δL} is absent. The cone sees depth only through 1/cos(πy) → ∞ as y → 1/2, i.e. only near the edge Re s = 1 — the de la Vallée Poussin layer the killer names (C2 line 70). Table in §1.4.
