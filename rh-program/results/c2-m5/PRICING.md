### §1.2 The rows exactly, in the LP's units — and the degeneracy theorem

Write ĝ(τ) := ∫ g(u)e^{−iuτ}du, so ĝ(i/2) + ĝ(−i/2) = 2∫ w du for g = w/cosh(u/2) (C2 line 16). Because w ≥ 0 forces ŵ(0) ≥ |ŵ(ξ)|, no cone element is localized away from τ = 0; a height-T element is w = h(u)(1 + cos Tu), h ∈ Σ_L, with ĝ = ĝ_c + ĝ_T, ĝ_c = (h/cosh(u/2))^ =: k, ĝ_T(τ) = ½[k(τ − T) + k(τ + T)]. With ζ's own datum the central identity is exact, Σ_γ ĝ_c(γ) − ∫ ĝ_c μ_∞ = 2∫h − P(h), P(h) := 2Σ_n Λ(n)n^{−1/2}h(log n)/cosh(½log n) = 4Σ_n Λ(n)h(log n)/(n + 1) ≥ 0, and applying the identity to the even test g_T = h cos(Tu)/cosh(u/2) as well (Σ_γ ĝ_T(γ) − ∫ ĝ_T μ_∞ = 2ĥ(T) − P_T(h), ĥ(T) := ∫h cos(Tu)du), the row R_w for the model configuration Z′ (ζ's zeros with those under ĝ_T's weight replaced by the embedded configuration) is EQUIVALENT to

    E_T(h) ≤ P(h) + 2ĥ(T),   E_T(h) := Σ_{on-line} m_z ĝ_T(τ_z) + Σ_{pairs}[ĝ_T(x_j + iy_j) + ĝ_T(x_j − iy_j)] − ∫ ĝ_T μ_∞ dτ.        (1.2)

(The oscillatory prime sum P_T(h) cancels identically; the variation of μ_∞ across the kernel is O(h(0)/T²) and dropped; ĥ(T) = O(h(0)/T²) for the hat basis and is kept in the code.) **Reading: at height T the cone row allows the ĝ_T-smoothed density excess to be at most the prime share P(h) of the demodulated element — 0 for supp h ⊂ (−log 2, log 2), and → 2∫h (the pole) as h spreads (PNT; table in §1.4: P/2∫h = 0.14, 0.38, 0.60, 0.71, 0.84 at L = 1, 2, 4, 6, 12 for Fejér h).** Reading the periodic configuration instead as the entire zero set of an abstract constant-density datum gives the weaker allowance 2∫h; every conclusion below holds a fortiori for that reading.

**(1.2) in Fourier form — exact for the periodic model (Poisson summation).** With u_k := kℓ/N and g(u) := h(u)/cosh(u/2),

    E_T(h) = (ℓ/N) Σ_{k≥1} Re[c_k^{on} + c_k^{pr} cosh(u_k y)]·g(u_k),        (1.3)

c_k^{on} = Σ_{on-line} m_z e^{−2πikθ_z/N}, c_k^{pr} = Σ_{pairs} 2e^{−2πikθ_j/N}; the k = 0 term cancels exactly against ∫ ĝ_T μ_∞ = ½h(0)ℓ; scanning the height over one period is scanning the rotation θ₀ (c_k ↦ c_k e^{−2πikθ₀/N}). **Consequence: in the periodic model E_T(h) depends on h ONLY through its values at the lattice points u_k, while P(h) depends on h everywhere.**

**(a) What the rows constrain in normalized units.** By (1.3): the configuration's density-modulation amplitudes 2|c_k|/N at the lattice frequencies u_k, each weighted by g(u_k) = h(u_k)/cosh(u_k/2) — the cosh division that makes the cone strip-positive (C2 line 16) is an exponential damping e^{−|u|/2} of every mode — summed against the mean density ℓ/2π, plus the depth factor cosh(u_k y) − 1 = O(u_k²y²) on pairs. For SPREAD tests (h(u) ≤ h(0), Fejér-type) the allowance P(h) grows like L·h(0) and the rows constrain only long-wavelength modulation; this is the content the referee's parenthesis had in mind (C2 line 71), and the Fejér column of §1.4 confirms it (E/P ≤ 0.27 at every L for every extremal arrangement, → 0 as L grows). For SPARSE tests the picture inverts, as follows.

**(b) THEOREM (degeneracy of the periodic world; elementary, five lines; verified numerically in §1.4) `[novelty: single-check]`.** For 0 < d ≤ Δ := ℓ/N and 1 ≤ k ≤ N L/ℓ let hat^{(d)}_v be the triangle of height 1 and half-width d centered at v, and h_{k,d} := hat^{(d)}_0 + ½(hat^{(d)}_{u_k} + hat^{(d)}_{−u_k}). The row (1.2) at every rotation φ therefore gives

    |c_k| ≤ (N/ℓ) cosh(u_k/2) [P(tooth_k^{(d)}) + 4ĥ_{k,d}(T)]  for every 1 ≤ k ≤ NL/ℓ,        (1.4)

and letting d → 0 (P(tooth) → 0 unless some log n equals u_k exactly, which never happens for the lattice u_k = kℓ/N, ℓ = log(T/2π), against log n; ĥ → 0): **c_k = 0 for every 1 ≤ k ≤ NL/ℓ.** At L ≥ ℓ this forces c_k = 0 for all k ≢ 0 (mod N): the configuration is the uniform lattice of N simple zeros.
