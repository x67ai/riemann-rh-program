## §1 The mechanism and the caveat, with the Lean and record lines

The datum is W_Z(f) = Σ_ρ m_ρ·h_f(γ_ρ)·conj(h_f(conj γ_ρ)) over the distinct zeros, f = f_{t,L} = i(B_L)′(u)e^{−itu}, B(v) = Z⁻¹exp(−1/(1 − 4v²)), Z = 0.2219969080840397, B_L(u) = B(u/L)/L (`results/c2-m2/separation-note.md` §0.1). `lean/Zeta23/Separation/Assembly.lean` 346–351, `theorem wsum_real … (hρ : ρ.re = 1 / 2) : wsum mult f ρ = (((mult ρ : ℝ) * ‖paperFT f (gammaOf ρ)‖ ^ 2 : ℝ) : ℂ)`: an on-line zero contributes m_ρ|h_f(γ)|² ≥ 0, so "an on-line configuration has W_Z(f) ≥ 0 for every test, and a defect is the only source of negative terms" (separation-note §0.3, line 31). The identity that puts the datum on the primes is `EF_lit_zetaZeroConfig` with `literatureRHS` (`Zeta23/ExplicitFormula.lean` 70–74, quoted in M6 §1):

  W_ζ(f_{t,L}) = ĝ(i/2) + ĝ(−i/2) + ARCH_ζ(t, L) − P_X(g_t),   P_X(g_t) = Σ_{n≤X} Λ(n)n^{−1/2}(g(log n) + g(−log n)) = Σ_{n≤X} w_n cos(t log n),   X = e^{L},   w_n = 2Λ(n)n^{−1/2}a(log n),   a(x) = L⁻³A(x/L).

**Therefore W_ζ(f_{t,L}) < 0 at any single (t, L) proves that ζ has a zero off the line — somewhere, not necessarily near t** (localizing it needs Lemma G's decay and a box, ranking-read-O §1.5). No constant, no window hypothesis, no density input (M6 §9 line 216).

**The caveat governing every sentence.** The pipeline evaluates the right-hand side in floating point: an exact integer sieve, a double-double phase, Neumaier summation, `mpmath.digamma` at 20 digits, the pole terms bounded by Lemma G — not interval arithmetic. A negative value is a **signal to certify**, with a stated error budget (§3), **not a proof**; the proof is the contingent item of §8. A negative value smaller in size than the point's budget is noise, not a signal. Silence at (t, L) certifies nothing (zoo IV.9; M6 §10 "four points are four points") and says nothing about orbits shallower than δ_vis(t, L) (§7, after the sweep) or about any other height.
