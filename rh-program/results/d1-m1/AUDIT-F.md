### 1.1 The Euler–Maclaurin remainder bound in `zeta_encl.py` — independent re-derivation

Notation: B_j Bernoulli numbers (B₁ = −½, B_{2k+1} = 0 for k ≥ 1), B_j(x) Bernoulli polynomials with B_j′ = j·B_{j−1}, B_j(0) = B_j(1) = B_j for j ≥ 2; B̄_j(x) := B_j({x}). For j ≥ 2, B̄_j is continuous and B̄_j′ = j·B̄_{j−1} on ℝ∖ℤ; for j ≥ 3 the identity extends across integers because both sides are continuous. (`bern_exact`/`bernoulli_poly_coeffs` re-verify the recursion, B_j(0), B_j(1) and B_j′ = jB_{j−1} in exact rationals for every index used — checked by reading the code; they raise on failure.)

**(a) Summation formula.** For f ∈ C^{2m+1}[N, M], integers N < M: integrating (x − n − ½) f′(x) by parts on [n, n+1] and summing gives
Σ_{n=N}^{M} f(n) = ∫_N^M f + ½(f(N) + f(M)) + ∫_N^M B̄₁ f′.
Iterating with the pair of integrations by parts (B̄_{2k+1}/(2k+1)! → B̄_{2k+2}/(2k+2)! gives the boundary term B_{2k+2}/(2k+2)!·[f^{(2k+1)}]_N^M; B̄_{2k+2}/(2k+2)! → B̄_{2k+3}/(2k+3)! gives no boundary term since B_{2k+3} = 0) yields, for every m ≥ 0,
Σ_{n=N}^{M} f(n) = ∫_N^M f + ½(f(N)+f(M)) + Σ_{k=1}^{m} B_{2k}/(2k)!·(f^{(2k−1)}(M) − f^{(2k−1)}(N)) + ∫_N^M B̄_{2m+1}(x)/(2m+1)!·f^{(2m+1)}(x) dx.   (EM)
The boundary terms of the first step telescope even though B̄₁ is discontinuous, because the antiderivative B̄₂/2 is continuous. ✔ matches STEP 1–2 of the file.

**(b) Specialization.** f(x) = x^{−s}, f^{(j)}(x) = (−1)^j (s)_j x^{−s−j} with (s)_j = s(s+1)⋯(s+j−1). For σ > 1 let M → ∞ (all M-terms are O(M^{−σ})): with ∫_N^∞ x^{−s} = N^{1−s}/(s−1) and −f^{(2k−1)}(N) = +(s)_{2k−1}N^{−s−2k+1},
ζ(s) = Σ_{n=1}^{N−1} n^{−s} + N^{1−s}/(s−1) + N^{−s}/2 + Σ_{k=1}^{m} B_{2k}/(2k)!·(s)_{2k−1}·N^{−s−2k+1} + R_{N,m}(s),
R_{N,m}(s) = −(s)_{2m+1}/(2m+1)!·∫_N^∞ B̄_{2m+1}(x) x^{−s−2m−1} dx.   (Z)
The remainder integral converges absolutely and locally uniformly for σ > −2m, so both sides are analytic on {σ > −2m}∖{1}; identity theorem ⇒ (Z) holds there. ✔ STEP 3–4. **First-omitted-term index:** the sum stops at k = m (Bernoulli B_{2m}); the remainder carries B̄_{2m+1} and, after the bound, C_{2m+2}. Code: loop `for k in range(1, m+1)` with `rising = (s)_{2k−1}` (k = 1: s; k ≥ 2: multiplied by (s+2k−3)(s+2k−2), so (s)_3, (s)_5, … ✔), coefficient `bern_exact(2k)/(2k)!/N^{2k−1}` ✔, remainder with `(s)_{2m+1}` (product over j = 0…2m ✔ 2m+1 factors), `c_sup(2m+2)`, `(2m+1)!·(2m+2)` ✔.

**(c) The bound.** Put G(x) := (B̄_{2m+2}(x) − B_{2m+2})/(2m+2). G is continuous, G′ = B̄_{2m+1} across integers, G(N) = 0, |G| ≤ C_{2m+2}/(2m+2) with C_j := sup_{[0,1]}|B_j(x) − B_j|. Integrating by parts on [N, ∞) (boundary term at N vanishes since G(N) = 0; at ∞ since G is bounded and σ + 2m + 1 > 0):
∫_N^∞ B̄_{2m+1} x^{−s−2m−1} dx = (s + 2m + 1) ∫_N^∞ G(x) x^{−s−2m−2} dx,
|R_{N,m}(s)| ≤ |(s)_{2m+1}|/(2m+1)! · |s+2m+1| · C_{2m+2}/(2m+2) · N^{−σ−2m−1}/(σ+2m+1).   (RB)
**σ-condition:** σ + 2m + 1 > 0 for the tail integral and the ∞ boundary term; the code guards σ_lo > 0 (`zeta_encl.py:293`), far inside. The (s−1)⁻¹ term needs 1 ∉ box: `recip` certifies |s−1|² > 0 (raises otherwise); the producers' σ₂ < 1 guarantees it. ✔ STEP 5. Relation to Backlund: (RB) = (C_{2m+2}/|B_{2m+2}|)·|s+2m+1|/(σ+2m+1) × |first omitted term|; the file honestly ships the factor ≈ 2.02 instead of the classical 1 — I confirm the classical constant would need the alternating-remainder argument, which is neither reproduced nor used. ✔

### 3.1 Geometry re-derived

C6 ⇔ 0 ∉ [reLo, reHi] × [imLo, imHi] (a box misses 0 iff one coordinate interval misses 0) ⇔ the box lies in one OPEN coordinate half-plane {Re > 0}, {Re < 0}, {Im > 0} or {Im < 0} (D1 ✔). On such a half-plane H = {Re(e^{−iφ}z) > 0} the function φ + Arg(e^{−iφ}z) is a continuous single-valued argument with values in (φ − π/2, φ + π/2); the image f(γ_k) of the closed segment lies in H (H-ENCL(a) + C6), so θ(t) = that branch ∘ f ∘ γ_k is a continuous branch of arg f along the path and its increment is < π in absolute value (D3 ✔). D2 (Δ_k := Im∫(f′/f)γ′ equals the increment of any continuous branch) follows from (d/dt)[e^{−u(t)}f(γ(t))] = 0 ✔, and two continuous branches along a connected path differ by a constant in 2πℤ, so the endpoint difference is branch-independent — exactly what both producers compute (`producer_mp.py:262-283`, `producer_arb.py` D-P5). Hence C6 (the mesh-admissibility criterion) ⇒ |A·Δ_k/2π| < A/2, which is the clamp C7 — **with the proviso that the integer clamp is only sound for even A (F-2/F-5)**. The checker never needs D2/D3: its chain uses only C6 (nonvanishing) and H-ENCL(b) (the rows) — C7 is a reject-more tripwire, as FORMAT §6.3 says ✔. D4 (width < ½ turn pins m) ✔ (`pin_m` in Lean). **Repair R1 (replacement code for `ball.py`; then use the wrappers at the six call sites above).**
```python
from mpmath.libmp import from_man_exp, mpf_mul, round_floor, round_ceiling

_INFL_BITS = 16   # widen each transcendental endpoint by 2^16 ulps (2^-272 rel. at prec 288)

def _inflate(x):
    """Outward relative inflation of an iv interval by (1 +- 2^-(prec-_INFL_BITS)) --
    mpmath's own mpi_cos_sin recipe (libmpi.py 'Perturb to force interval rounding'),
    applied to the primitives that lack it.  AUDIT F, finding F-1: mpf_exp/log/atan/pi
    directed-round a guard-bit APPROXIMATION and can land on the wrong side of the truth by
    up to ~1 ulp (demonstrated: 11/40,000 exp ceilings below the truth).  After inflation
    the platform assumption is 'transcendental error < 2^16 ulps at prec', which the
    14-30 guard bits guarantee.  Cost: 2^-272 relative, 50 orders below the emission
    scale K = 10^30 and 60 orders below the remainder pad."""
    lo, hi = x._mpi_
    p = iv.prec
    more = from_man_exp((1 << p) + (1 << _INFL_BITS), -p)   # 1 + 2^-(p-16)
    less = from_man_exp((1 << p) - (1 << _INFL_BITS), -p)   # 1 - 2^-(p-16)
    lo = mpf_mul(lo, more if lo[0] else less, p, round_floor)    # lo < 0: more negative; lo >= 0: smaller
    hi = mpf_mul(hi, less if hi[0] else more, p, round_ceiling)  # hi < 0: closer to 0; hi >= 0: larger
    return iv.make_mpf((lo, hi))

def iv_exp(x):  return _inflate(iv.exp(x))
def iv_log(x):  return _inflate(iv.log(x))
def iv_pi():    return _inflate(iv.pi)
def iv_atan(x): return _inflate(iv.make_mpf(_libmpi.mpi_atan(x._mpi_, iv.prec)))
```
(sign logic: for lo ≥ 0 multiply by `less` (smaller), for lo < 0 by `more` (more negative); for hi ≥ 0 by `more`, for hi < 0 by `less` — each is outward; `mpf_mul` with a directed mode is correctly rounded.)
