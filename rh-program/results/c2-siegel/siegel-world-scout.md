### §2.2 The pole cap — why one real zero is uncertifiable, and two are not

**Lemma C (pole cap).** For every w ∈ Σ_∞ and every y ∈ [0, ½): 2(ŵ ∗ μ_y)(0) ≤ 2ŵ(0), with equality only in the limit y → ½. *Proof.* w ≥ 0 gives |ŵ(ξ)| ≤ ŵ(0) for every ξ (note §0.1, first bullet); μ_y ≥ 0 with ∫μ_y = 1 (Lemma P(i)–(ii)); so (ŵ ∗ μ_y)(0) = ∫ŵ(s)μ_y(s)ds ≤ ŵ(0)∫μ_y = ŵ(0). As y → ½, μ_y → δ₀ (C2 line 16) and the share tends to 2ŵ(0). ∎ Consequently, for every cone element,

  margin(δ) = 2(ŵ ∗ μ_y)(0) − B_K(w) = −Arch_K(w) − 2∫μ_y(s)[ŵ(0) − ŵ(s)]ds ≤ −Arch_K(w),  Arch_K(w) := ∫ŵ(s)a_K(s)ds,

so **a cone certificate against a single real zero exists only if the archimedean part of the budget is negative for that element.** The pole term 2ŵ(0) — exactly the share a zero at s = 1 would have — is the ceiling of a real zero's share; the identity says the pole pays for one real zero and no more. That is Landau's argument in cone dress: in the note's own words, divided by 2 the identity for the de la Vallée Poussin element "is the classical partial-fraction identity Σ_ρ Re 1/(s − ρ) − Re ζ′/ζ(s) = Re[1/(s − 1) + 1/s] + …" (note §4, Remark after Lemma E), and a single real zero's term 1/(σ − β) never exceeds the pole's 1/(σ − 1). **Which hypothesis does what** (`check-O.md` item 2): the cap itself uses only w ≥ 0 (through |ŵ| ≤ ŵ(0)) and μ_y ≥ 0 of mass one — no archimedean hypothesis, and not even ŵ ≥ 0; uncertifiability of a single element needs ŵ ≥ 0 together with a_K ≥ 0 on supp ŵ only (a Fejér element with support in |s| ≤ T is uncertifiable as soon as a_K ≥ 0 on [0, T]); the cone-wide statement needs a_K ≥ 0 everywhere, because the cone contains elements whose ŵ concentrates at any chosen point, and by the monotonicity of a_K below that is the single condition a_K(0) ≥ 0, i.e. |D| ≥ D₁. **Printed antecedent.** Goldfeld–Hoffstein–Lieman, "Appendix: An effective zero-free region", Ann. of Math. 140 (1994) 177–181 (`fetched-r2/r-25a-goldfeld-hoffstein-lieman-1994-appendix-effective-zero-free-region-annals140.pdf`, SHA-256 ddcc7a2d5bb1a86e1f5d45bfcdea9935e3821133b2fcb823754deedd0d9a4d05), p. 178, read with pdftotext in the fix pass (the OCR renders φ as "so"; the check read the page image): "LEMMA.
