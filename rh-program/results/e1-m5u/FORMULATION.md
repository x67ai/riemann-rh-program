### §2.1 Clause 1 (positive strip measures have no spectral gap through 0) `[derivation]`, numerical companion `verify/h1_strip_test_check.py` → `_run.log` `[computed]`

**CLAUSE 1.** Let σ ≠ 0 be a positive, locally finite, symmetric (γ ↦ γ̄, γ ↦ −γ) measure on the closed strip S with Σ_γσ({γ})(1 + |γ|)^{−2} < ∞ (every positive configuration of a class 𝒞(C₁) qualifies). Then for every L > 0, E_σ ≠ 0 on (−L, L). Quantitatively: for every real even ψ ∈ C²_c(−L/2, L/2) with ψ ≥ 0, ψ ≢ 0, and g_ψ := (ψ ⋆ ψ̃)/cosh(u/2) as in (0.1),

      ⟨E_σ, g_ψ⟩ = Σ_γ σ({γ})ĝ_ψ(γ) ≥ 0,   with equality only if σ is carried by {|Im γ| = ½, ψ̂(Re γ) = 0};        (2.1)

and there is a ψ (a dilate of any given one) for which (2.1) is strictly positive.

*Proof.* (i) *The orbit sum.* g_ψ is real, even, C²_c(−L, L) (k := ψ ⋆ ψ̃ is C²_c(−L, L), cosh(u/2) is smooth and positive). For z = x + iy, ĝ_ψ(x + iy) = ∫g_ψ(u)cos(xu)cosh(yu)du − i∫g_ψ(u)sin(xu)sinh(yu)du; over an orbit {±x ± iy} the imaginary parts cancel in pairs and the real parts add: Σ_{orbit}ĝ_ψ = 4·Re ĝ_ψ(x + iy) (2·Re for a two-point orbit). (ii) *Positivity of the real part on the strip.* Write h_y(u) := cosh(yu)/cosh(u/2). For |y| < ½, h_y ∈ L¹ and

      ∫_ℝ e^{iux}h_y(u)du = 2π·cosh(πx)cos(πy)/|cosh(π(x − iy))|² =: P_y(x) > 0   for all x ∈ ℝ,        (2.2)

because ∫e^{iux}sech(u/2)du = 2π·sech(πx) and e^{±yu}sech(u/2) shifts x to x ∓ iy, so ∫e^{iux}h_y = π[sech(π(x − iy)) + sech(π(x + iy))] = 2π·Re sech(π(x − iy)), and Re sech(π(x − iy)) = cosh(πx)cos(πy)/|cosh(π(x − iy))|². (2.2) was checked to 10 digits against direct quadrature at (x, y) = (1.3, 0), (1.3, 0.25), (1.3, 0.49) `[computed]`. Hence, for |y| < ½, Re ĝ_ψ(x + iy) = ∫k(u)h_y(u)cos(xu)du = (2π)^{−1}(k̂ ∗ P_y)(x) = (2π)^{−1}∫|ψ̂(ξ)|²P_y(x − ξ)dξ > 0 for every x (|ψ̂|² ≥ 0 is continuous and not identically 0, P_y > 0 and continuous); for |y| = ½, h_{±½} ≡ 1 and Re ĝ_ψ(x ± i/2) = k̂(x) = |ψ̂(x)|² ≥ 0. So every orbit's sum is ≥ 0, strictly positive unless the orbit lies on the boundary lines |Im γ| = ½ at a zero of ψ̂; (2.1) follows by summing (absolute convergence: |ĝ_ψ(γ)| ≤ e^{L/2}‖g_ψ″‖₁/|γ|² for |γ| ≥ 1, §0.1). (iii) *Strictness.* If (2.1) were 0 for every such ψ, then in particular for the dilates ψ_c(u) := ψ(u/c), 0 < c ≤ 1 (ψ̂_c(x) = cψ̂(cx)), σ would be carried by {|Im γ| = ½} ∩ ⋂_c{ψ̂(c·Re γ) = 0}. ### §2.2 Clause 2 (the two parts of a ghost: both nonzero, both infinite, balanced at every scale ≥ 1/L) `[derivation]`
