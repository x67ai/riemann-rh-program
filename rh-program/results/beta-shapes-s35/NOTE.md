### 2.0 Lemma F (finite fibers), used by all three theorems

**Lemma F.** Assume A5 over Z (deg(Γ_1 ∩ Γ_n) = Λ(n), n ≥ 2), A7 (c(Γ_n) = Γ_{φ_n}, φ: M → E a monoid homomorphism) and A9 with a real-valued A11 pairing (L(D) = κ (Δ · D)_Y ∈ R for every D = c(Γ_n), n ≥ 2). Then:
(a) for every D in the image of c, the fiber F_D := {p^k : k ≥ 1, φ_{p^k} = ψ_D} is finite, and L(D) = log N_D with N_D = Π_{p^k ∈ F_D} p a positive integer;
(b) for every prime p the powers φ_p, φ_p², φ_p³, … are pairwise distinct — φ_p has infinite order in E; in particular φ_p ≠ id, φ_p is not an automorphism of finite order, and φ_p is not a constant map;
(c) for every ψ ∈ E the set {(p, k) : φ_p^k = ψ} is finite; the image of φ is infinite; E is infinite.

*Proof.* (a) L(D) = Σ_{p^k ∈ F_D} log p ≥ (#F_D) · log 2, and L(D) = κ (Δ · D)_Y is a real number; so #F_D ≤ L(D)/log 2 < ∞ ([11]). The identity L(D) = log N_D is the additivity of log. (b) If φ_p^a = φ_p^{a+m} with a, m ≥ 1, then φ_p^{a+jm} = φ_p^a for every j ≥ 0 (induction on j: φ_p^{a+(j+1)m} = φ_p^{a+jm} ∘ φ_p^m = φ_p^a ∘ φ_p^m = φ_p^{a+m} = φ_p^a). Then D := c(Γ_{p^a}) has F_D ⊇ {p^{a+jm} : j ≥ 0}, infinite, contradicting (a). The three named cases: φ_p = id is a = 1, m = 1; an automorphism of order m is φ_p^m = id, so φ_p^{m+1} = φ_p; a constant map with value x has φ_p(φ_p(b)) = φ_p(x) = x = φ_p(b) for all b, so φ_p² = φ_p. (c) A fiber of φ on prime powers is F_D for D = c(Γ_n) with n any of its members, finite by (a); the prime powers are infinitely many and each lies in one fiber, so there are infinitely many fibers, hence infinitely many images, hence E is infinite. ∎

*Rung 1 (Lemma F holds there, as it must).* Fr_q has infinite order in End_k(S): Fr_q^k acts on functions by x ↦ x^{q^k} (0906.3146 §7.2 p. 25), and O_S(U) for an affine open U contains an element x transcendental over k (S is one-dimensional), for which the x^{q^k} are pairwise distinct; the fibers of c are the finitely many effective divisors of a given degree (Borger p. 25). `[novelty: single-check]` for Lemma F as a statement on the pair; its rung-1 content is printed.

**PROOF.** H1.2 contradicts Lemma F(b), which needs only H1.1 and H1.3.
