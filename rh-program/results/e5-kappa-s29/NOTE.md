## §2 The extremal problem stated (10(g)); the closed form of a; weak duality in the form the LP uses

**Primal.** κ = inf{2 + ∫ŵa/∫w : w ∈ C²_c, w ≥ 0, ŵ ≥ 0, w ≢ 0}. Two facts used throughout: ŵ(0) = ∫w = sup|ŵ| (w ≥ 0), and the value is unchanged if the class is enlarged as in Lemma A.

**Lemma A1 (closed form of the archimedean density; the writer's derivation).** For all real τ,

  a(τ) = (1/2π)·[ Re{(1 − iτ)ψ(½ + iτ/2) + iτψ(1 + iτ/2)} − 1 − log π ].   (2.1)

*Derivation.* Re ψ(¼ + ir/2) = −γ + Σ_{n≥0}[1/(n + 1) − 2c_n/(c_n² + r²)], c_n := 2n + ½ (the partial-fraction series of ψ, real part). The Fourier transform of sech(πξ) is sech(u/2) and that of c/(c² + r²) is πe^{−c|u|}, so (μ₀ ∗ c/(c² + ·²))(τ) = ∫_0^∞ sech(u/2)e^{−cu}cos(uτ)du = 2Re β(c + ½ + iτ), β(x) := ∫_0^∞ e^{−xu}(1 + e^{−u})⁻¹du = ½[ψ((x + 1)/2) − ψ(x/2)]; with c = c_n this is Re[ψ(n + 1 + z) − ψ(n + ½ + z)], z := iτ/2. Term-by-term convolution gives 2πa(τ) + log π = −γ + lim_N Σ_{n≤N}[1/(n + 1) − 2Re(ψ(n + 1 + z) − ψ(n + ½ + z))]. Expanding ψ(n + 1 + z) − ψ(n + ½ + z) = Σ_k[1/(k + n + ½ + z) − 1/(k + n + 1 + z)] = ½Σ_k 1/((k + n + ½ + z)(k + n + 1 + z)) and regrouping by m = n + k (multiplicity min(m + 1, N + 1) for n ≤ N) gives Σ_{m≤N}[1/(m + 1) − (m + 1)g(m)] − (N + 1)Σ_{m>N}g(m) + o(1), g(m) := 1/((m + ½ + z)(m + 1 + z)); the boundary term tends to 1 (g(m) ~ m⁻²), and Σ_m[1/(m + 1) − (1 − 2z)/(m + ½ + z) − 2z/(m + 1 + z)] = γ + (1 − 2z)ψ(½ + z) + 2zψ(1 + z) by partial fractions ((m + 1)g(m) = (1 − 2z)/(m + ½ + z) + 2z/(m + 1 + z)) and ψ(x) + γ = Σ_m[1/(m + 1) − 1/(m + x)]. Taking real parts: (2.1). *Checks* (`conventions_check_run.log`): (2.1) agrees with direct quadrature of μ₀ ∗ A at 16 points of [0, 1000] to ≤ 7·10⁻¹² and with mpmath at 30 digits to ≤ 4·10⁻¹⁵; a(0) = (ψ(½) − 1 − log π)/2π = −0.653847 (record); a(τ) = (1/2π)log(τ/2π) + O(1/τ) (from ψ(x + ½) − ψ(x) = 1/(2x) + O(x⁻²)), reproducing the record's table to three decimals from τ = 8 on. ∎

**Lemma A2 (a on the u-line: the archimedean term is a negative "hole" measure with a pole-like singularity).** For w ∈ Σ_∞,

  ∫ŵa = −(γ + log π)w(0) + 2∫_0^∞ [ w(0)e^{−2u}/(1 − e^{−2u}) − 2w(u)/((e^u + 1)(1 − e^{−2u})) ] du,   (2.2)

i.e. ∫ŵa = ⟨α, w⟩ with α = c_aδ₀ − fp ρ(|u|)du, ρ(u) := 2e^{2u}/((e^u + 1)²(e^u − 1)) ~ 1/(2u) at 0 and ~ 2e^{−u} at ∞. *Proof.* ψ(z) = −γ + ∫_0^∞(e^{−t} − e^{−zt})/(1 − e^{−t})dt at z = ¼ + ir/2, Fourier inversion (1/2π)∫ĝ(r)cos(rt/2)dr = g(t/2) with g = w/cosh(u/2), and e^{−u/2}/cosh(u/2) = 2/(e^u + 1). **Lemma A3 (a is strictly increasing on (0, ∞)).** A′(r) > 0 for r > 0 because d/dr Re ψ(¼ + ir/2) = −½Im ψ′(¼ + ir/2) and Im ψ′(x + iy) = Σ_{n≥0}Im(n + x + iy)⁻² = −Σ2(n + x)y/|n + x + iy|⁴ < 0 for y > 0; then a′(τ) = ∫_0^∞[μ₀(τ − r) − μ₀(τ + r)]A′(r)dr > 0 for τ > 0 since μ₀ is even and strictly decreasing on (0, ∞). **Lemma A (band-limited squares are admissible primal competitors).** Let f̂ ≥ 0 be real, bounded, supported in a compact interval, w := |f|² (f the inverse transform). Then w ≥ 0, ŵ = (1/2π)(f̂ ⋆ f̂) (autocorrelation) ≥ 0, ŵ is compactly supported, w ∈ L¹, and κ ≤ B(w)/ŵ(0). *Proof.* Take χ := the centered cubic B-spline scaled so that χ(0) = 1 (χ ∈ C²_c, 0 ≤ χ ≤ 1, χ̂ ∝ sinc⁴ ≥ 0). **Dual (the rider's form and the LP form).** The rider: κ ≥ κ₀ whenever there are ψ ≥ 0 on the τ-line and a positive measure φ on the u-line with (2 − κ₀)δ₀ + a = ψ + φ̂/2π as distributions; weak duality in one line: ∫ŵ[(2 − κ₀)δ₀ + a] = B(w) − κ₀ŵ(0) = ∫ŵψ + ∫w dφ ≥ 0 (the last equality: (1/2π)∫ŵφ̂ = ∫w(−v)dφ(v) = ∫w dφ, w even). **φ is any positive measure on the u-line** — "on the prime line" in the rider names where ζ's own certificate lives (φ_ζ), not a constraint. **Why finite-mass φ cannot work** (the rider's sentence, re-derived): if φ is finite, φ̂ is continuous with φ̂(0) = ∫dφ ≥ 0, so the function part of (2 − κ₀)δ₀ + a − φ̂/2π equals a(0) − φ̂(0)/2π ≤ a(0) < 0 at τ = 0 and on a neighborhood — not ≥ 0; the atom's coefficient 2 − κ₀ cannot repair a function inequality. **What can work:** φ with positive mean density d at |u| → ∞: then φ̂ = 2πdδ₀ + (function), the atom at 0 absorbs d of the pole weight, and the function part can be negative near 0 if φ has a deficit near u = 0 (a "hole").
