And [P₀,u] = [F_{r^{-1}}P₀, ru]. Hence **every point of Γ^E_p is [π(x,χ^a), w]** with a a unit and χ^a ∈ E. Two points may be taken over the same x by G-transitivity (p. 32). **CONFIRMED.**
*(Correction 2: the adjudication's §3 normal-form sentence writes "F_ν π(x,χ^a) for a unit a and ν ∈ N"; the group element actually used is q = r^{-1} ∈ Q>0₀. Harmless; refuter F flagged it; I confirm the corrected derivation.)*

**Step 2 — simultaneous approximation.** *There are m_k ∈ N and j_k ∈ Z with m_k → c in Ẑ_(p) and r_k := m_k p^{-j_k} → t in R>0.*
Proof (mine): M_k := ∏_{ℓ ≤ k, ℓ ≠ p} ℓ^k; pick c_k ∈ [0,M_k) with c_k ≡ c (mod M_k) (possible: Ẑ_(p) = lim_{(M,p)=1} Z/M); pick j_k with p^{j_k} > max(M_k/t, k·M_k). Then m_k ≥ t p^{j_k} > M_k > 0 so m_k ∈ N; m_k ≡ c (mod M_k) and every M prime to p divides M_k for large k, so m_k → c in Ẑ_(p); and 0 ≤ r_k − t < M_k p^{-j_k} < 1/k. ∎ **CONFIRMED.** The two constraints live at disjoint places — p is absent from Ẑ_(p) and supplies the free real scale p^{-j_k} — i.e. this is strong approximation for Q with the place **p** deleted. ## 4. FACE (b) — RE-DERIVED IN FULL BY THIS ADJUDICATOR

**(A) The escape weight.** ρ̂ : X̊(C) → [1,∞], ρ̂(P) = |ker(P^×|_μ)| if char κ(x) = 0, ρ̂(P) = +∞ if char κ(x) > 0; extended to X̌(C) by ρ̂(F_ν^{-1}P) := ρ̂(P)/ν.
*Well defined*: if F_ν^{-1}P = F_μ^{-1}Q then F_μP = F_νQ, and (43) with ν_x = ν in char 0 gives μρ(P) = νρ(Q); in char > 0 both sides are ∞ and F preserves x. *Conformal*: ρ̂(F_qQ̌) = q ρ̂(Q̌). *G-invariant*: ker((P∘σ)|_μ) = σ^{-1}ker(P|_μ). Descends to ρ̂₀ on X̌₀(C)_E. Set **W([P₀,u]) := ρ̂₀(P₀)·u**; well defined on Q>0-orbits, **W∘φ^t = e^t W**, **W > 0** everywhere (values in Q>0 ∪ {∞}). **CONFIRMED** at (41)–(43), p. 33.

*Lower semicontinuity, re-derived.* Let P_i → P in X̊(C). For ζ ∈ μ(K) of order n, P_i(ζ)^n = P_i(ζ^n) = 1, so all values lie in the finite set μ_n(ℂ); a net in a finite subset of a Hausdorff space is eventually equal to its limit. (i) char P = 0: ker(P|_μ) is finite, so eventually contained in ker(P_i|_μ), giving ρ(P_i) ≥ ρ(P) when char P_i = 0 and ρ̂(P_i) = ∞ otherwise. (ii) char P = p: for each k, μ_{p^k}(K) ⊆ ker P^× (ζ^{p^k} = 1 ⟹ (ζ̄−1)^{p^k} = 0 ⟹ ζ̄ = 1), so eventually ρ̂(P_i) ≥ p^k; k arbitrary ⟹ lim inf = ∞. So ρ̂ is l.s.c. and **not** continuous (kernels jump up). **CONFIRMED.**
*Transport.* l.s.c. is local and {F_ν^{-1}X̊(C)} is an open cover of X̌(C) on which ρ̂ = (1/ν)·ρ̂∘F_ν with F_ν a homeomorphism ⟹ l.s.c. on X̌(C).
