**The caveats (two, the first substantive):**

The dissipation half (B) survives E-free (W ≡ ∞ on the set), but the identification {W < ∞} = generic locus fails, and with it the finiteness half. qb-kill §10.1 saw that (Tors) is consumed there but characterized the E-free escape as "indiscrete blobs over p with no closed orbits of length log p at all" — that characterization is **refuted**: the closed orbits over p in the witness are genuine, and only the limit set lands in an indiscrete generic blob. Consequently the adjudication's sentence "compactness alone is the exact obstruction" is exact only for X₀^E; the honest statement is **"compactness plus (Tors) at the generic point"**. This is not a refutation of the S4 kill (S4's target carries an admissible E, and [x-06] p. 11 says (Tors) is "known for certain"), but it is a second, much cheaper escape than the adjudication's "named residue" X̄₀, and it should be recorded before the direction-level exhaustion call: the residue is not only the unbuilt Arakelov compactification but also the (Tors)-violating unitary generic locus of Deninger's own printed Y₀. **(C2) Compactness of Y is a ledger specification, not a printed hypothesis of Deninger's question.** [x-03] p. 40 asks for "a sub-dynamical system Y₀ ⊂ X₀ or at least one which maps to X₀ such that dim Y₀ = 2d+1 … a Riemann surface lamination in the sense of [Ghy99]"; the word "compact" is absent, and [Ghy99] is not on disk (whether Ghys's definition includes compactness is [RU] here). ## 1. The objects and the topology, written out from the source (my words, with pages)

**1.1 Points (p. 22–23).** X = Spec ℤ̄, G = Aut(ℚ̄/ℚ). X̊(ℂ) is the set of pairs (x, P^×), x ∈ X, P^×: κ(x)^× → ℂ^× a homomorphism; G acts by (x,P^×)σ = (x^σ, P^×∘σ); the monoid ℕ acts by F_ν(x,P^×) = (x, P^×∘( )^ν), commuting with G (p. 22, verbatim formulas). Remark 3.4 (p. 23): equivalently, multiplicative maps P: ℤ̄ → ℂ with P(0) = 0, P(1) = 1, 𝔭_P := P⁻¹(0) a prime ideal, P factoring through ℤ̄/𝔭_P. Over Spec ℤ the point x is either the generic point η (κ = ℚ̄) or a closed point over a rational prime p (κ = F̄_p, p. 22 "κ(x) is an algebraic closure of κ(x₀)"). **Two elementary facts used everywhere:** (i) for any P and any root of unity ζ ∈ μ(ℚ̄) ⊂ ℤ̄^×, P(ζ) ≠ 0 and P(ζ)^{ord ζ} = P(ζ^{ord ζ}) = P(1) = 1, so P(ζ) ∈ μ_{ord ζ}(ℂ), a finite set; (ii) if x lies over p and r ∈ ℤ̄ ∖ 𝔭_x, then r̄ ∈ F̄_p^× is torsion, so P(r) is a root of unity, |P(r)| = 1; if r ∈ 𝔭_x, P(r) = 0.

**1.2 The colimit (pp. 24–25).** X̌(ℂ) = colim_ℕ X̊(ℂ) along the injections F_ν; every point is F_ν⁻¹P with P ∈ X̊(ℂ), and F_ν⁻¹P = F_{ν′}⁻¹P′ iff F_{ν′}P = F_νP′ in X̊(ℂ) (p. 25, verbatim). ℚ>0 acts by F_q. pr_X(F_ν⁻¹P) = pr_X(P) (p. 25). X̌₀(ℂ) = X̌(ℂ)/G, π̌: X̌(ℂ) → X̌₀(ℂ) ℚ>0-equivariant.

**1.3 Admissibility (p. 27, verbatim).** "(Tors) the group ker(χ)_tors = ker(χ|_{μ(κ)}) is finite and |(ker χ)_tors| ∈ N₀." Prop. 4.2: X̊(ℂ)_E is G-invariant and F-bi-invariant (P ∈ X̊(ℂ)_E iff F_νP ∈ X̊(ℂ)_E); X̌(ℂ)_E = colim X̊(ℂ)_E is G- and ℚ>0-invariant; pr_{X₀}: X̌₀(ℂ)_E → X₀ is ℚ>0-equivariant for the trivial action on X₀.
