*Step 1 — simultaneous approximation (Lemma 5.2, re-derived).* There exist m_k ∈ N and j_k ∈ ℤ with m_k → c in Ẑ_(p) = lim_{(M,p)=1} ℤ/M and r_k := m_k p^{−j_k} → t in R>0. ## 4. FACE (b): dissipation + finiteness — RE-DERIVED, CONFIRMED

**Claim (qb-kill Thms. D/S/Main = qb-build Thms. 1/2/3, Cor. 4).** No continuous flow-equivariant map from a nonempty quasi-compact flow space into X₀ meets infinitely many packets; hence Q-b NO.

**Adjudicator's re-derivation.**

*(A) The escape weight (qb Theorem 1/D).* Define ρ̂: X̊(C) → [1,∞] by ρ̂(P) = |ker(P^×|_μ)| if char P = 0, ρ̂(P) = +∞ if char P > 0; extend to X̌(C) by ρ̂(F_ν⁻¹P) = ρ̂(P)/ν. Well-defined: in char 0, (43) with ν_x = ν gives the ratio invariant; in char > 0 both sides ∞ and F preserves the underlying point x. ρ̂(F_q Q̌) = q·ρ̂(Q̌) (from (43)); G-invariant (ker((P∘σ)|_μ) = σ⁻¹ ker(P|_μ), same order); descends to ρ̂₀. Set **W([P₀,u]) := ρ̂₀(P₀)·u** on X₀. Well-defined: W((P₀,u)·q) = ρ̂₀(F_q P₀)·q⁻¹u = q·ρ̂₀(P₀)·q⁻¹u = W. **W∘φ^t = e^t·W** (φ^t scales u). **W⁻¹(∞) = ⨆_p Γ^E_p** (packets = char-p locus; under (Tors) char-0 points have finite ρ̂ — this and only this consumes admissibility). **CONFIRMED** via (41)–(43) verified at p. 33.

Lower semicontinuity. If P_i → P in X̊(C): for each ζ ∈ μ(ℚ̄) ⊂ ℤ̄, P_i(ζ) → P(ζ) with all values in the finite set μ_{ord ζ}(C), so P_i(ζ) = P(ζ) eventually (a net in a finite subset of a Hausdorff space is eventually equal to its limit). Two cases. (i) char P = 0: take ζ ranging over μ_{ρ(P)} = ker(P^×|_μ); eventually μ_{ρ(P)} ⊆ ker(P_i^×|_μ), so ρ(P_i) ≥ ρ(P) if char P_i = 0, else ρ̂(P_i) = ∞; lim inf ρ̂(P_i) ≥ ρ̂(P). (ii) char P = p: for each k, μ_{p^k} ⊆ ker(P^×) because ζ ∈ μ_{p^k} reduces to 1 in F̄_p (ζ̄^{p^k}=1 ⟹ (ζ̄−1)^{p^k}=0 ⟹ ζ̄=1); so eventually p^k | ρ(P_i), giving ρ̂(P_i) ≥ p^k → ∞ = ρ̂(P). So ρ̂ is l.s.c. on X̊(C), and NOT continuous (kernels jump up in the limit). Transported to X₀ through the open charts and the open quotient q (semicontinuity descends along open surjections — qb-build's chart argument / qb-kill's Cor. 4.4), W is l.s.c. on X₀. **CONFIRMED.**

*(B) Dissipation (qb Theorem 2/5.5).* K ⊆ X₀ nonempty, quasi-compact, flow-invariant. m := inf_K W. If not attained, {W > a}∩K (a > m real) is an open cover with no finite subcover, yet a finite subcover would give K ⊆ {W > a₀}, forcing m ≥ a₀ > m — contradiction; so m is attained at some z₀, and m > 0 (W > 0 everywhere). If m < ∞, then φ^{−t}z₀ ∈ K and W(φ^{−t}z₀) = e^{−t}m → 0 < m, contradiction. So m = ∞: **W ≡ ∞ on K, i.e. K ⊆ ⨆_p Γ^E_p** — no generic point. **CONFIRMED** (l.s.c.-attains-inf needs no separation axiom).
