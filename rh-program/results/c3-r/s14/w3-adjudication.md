## 3. Re-derivation ledger I — the negative results (the source statements are false)

Conventions: U ⊂ ℝⁿ open (n ≥ 0), l ≥ 1; φ, ψ ∈ C_c^∞(ℝ^l) fixed bumps with φ(0) = 1, supp φ ⊂ B(0, r_φ); e₁ the first coordinate vector; for T a parameter space every witness below is constant in the parameter, hence lies in C(T; ·) with the same seminorms — so each refutation lifts verbatim to every parametrized version (both probes; trivially correct).

**3.1 [ÁLKL23] Prop. 3.2 is false; its proof fails at the completion step. — CONFIRMED (F Thm 3.1, O Thm 5/5′).** *Adjudicator's derivation.* Let S′^m be S^m(U × ℝ^l) with the (3.4)+(3.5) topology. Put g_N(x, ξ) := φ(ξ − Ne₁) (O's translates; F uses (1+j)^m φ(ξ − je₁), same mechanism). (i) g_N ∈ C_c^∞ in ξ, x-constant, so g_N ∈ S^{−∞} ⊂ S^m for every m. (ii) For compact Q ⊂ U × ℝ^l, ‖g_N‖_{Q,C^k} = 0 once N > r_φ + max_Q|ξ|; (iii) every (3.5)-seminorm of g_N is 0 (compact ξ-support kills the limsup). So g_N → 0 in S′^m. (iv) ‖g_N‖_{K,0,0,m} ≥ |g_N(x, Ne₁)|(1+N)^{−m} = (1+N)^{−m}, and more generally ‖g_N‖_{K,0,β,m} = sup|∂^βφ(ξ − Ne₁)|(1+|ξ|)^{|β|−m} ≍ N^{|β|−m}; choosing |β| > m (any m ∈ ℝ) with ∂^βφ ≢ 0 (exists: a compactly supported nonzero function is not a polynomial) gives ‖g_N‖_{K,0,β,m} → ∞. So {g_N} is unbounded in S^m while it is a null sequence in S′^m: the identity S^m → S′^m is continuous (each of (3.4), (3.5) is dominated by a (3.1)-seminorm) and not a homeomorphism, for every m ∈ ℝ, every n ≥ 0, l ≥ 1. **Prop. 3.2 is false.** *The failing step.* Fix R > 2r_φ and c_i := (1 + iR)^{m+1}; b_j := Σ_{i≤j} c_i φ(ξ − iRe₁) (disjoint supports). For i < j, b_j − b_i is compactly supported in |ξ| ≥ (i+1)R − r_φ, so its (3.5)-seminorms vanish and its (3.4)-seminorms vanish for i large: (b_j) is Cauchy in S′^m.
