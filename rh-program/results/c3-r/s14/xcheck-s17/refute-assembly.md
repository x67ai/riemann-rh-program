## Item 1. Companion §9.6, the b-collar model

**Change of variable.** x = e^{−ϱ}, so ϱ = −log x, dϱ/dx = −1/x, ∂_x = −(1/x)∂_ϱ, hence x∂_x = −∂_ϱ. x^{−m} = (e^{−ϱ})^{−m} = e^{mϱ}. Both as the companion states. Since (x∂_x)^a = (−1)^a ∂_ϱ^a, |∂_ϱ^a ∂_y^b v| = |(x∂_x)^a ∂_y^b (λ_j u)| at x = e^{−ϱ}, so N^b_m(v;(a,b)) = sup_{U_j∩M̊} x^{−m}|(x∂_x)^a∂_y^b(λ_j u)|: exactly a seminorm of the form (6.41), "‖u‖_{k,m} = ‖P_k u‖_{x^m L^∞} = ess sup_M x^{−m}|P_k u| = sup_{M̊} x^{−m}|P_k u|" (p. 38, read), with P = (x∂_x)^a∂_y^b ∘ λ_j.

**Inclusion direction.** (6.38) p. 38: "A^m(M) ⊂ A^{m′}(M) (m′ < m)" (read; the printed line is garbled by pdftotext but the parenthetical "(m′ < m)" and the preceding "from x^{m−m′} ∈ L^∞(M)" on p. 37 (6.37) fix the direction). **Interpolation inequality with w = e^ϱ, all sides h = w^{−c}.** Write m = −k, m′ = −k′, m″ = −k″ with k < k′ < k″ (so B^{−k} ⊂ B^{−k′} ⊂ B^{−k″}). Claim to check: for γ ≠ 0, c := (k′−k)/(2|γ|), N > |γ| + (k″−k′)/c, R ≥ R_0 := max{1, N^{1/c}}, v ∈ B^{−k″}_K,
  N^b_{−k′}(v;γ) ≤ C[ R^{−(k′−k)/2} N^b_{−k}(v;0) + R^{k″−k′} max_{Γ} N^b_{−k″}(v;γ′) ].

The ϱ-box stays inside [ϱ_0, ∞) because ϱ ≥ ϱ_0 and h > 0; the y-box is unrestricted because v lives on all of ℝ^d (vanishing off K). Hence sup_Q|v| ≤ e^{|k|} w^k N^b_{−k}(v;0) and sup_Q|∂^{Nχ_S}v| ≤ e^{|k″|} w^{k″} N^b_{−k″}(v;Nχ_S). Lemma B (all h_i = h, γ_i ≤ |γ| < N) gives |∂^γ v(ϱ,y)| ≤ C Σ_S h^{N|S|−|γ|} sup_Q|∂^{Nχ_S}v|, because (∏_{i∈S}h^{N−γ_i})(∏_{i∉S}h^{−γ_i}) = h^{N|S| − Σ_i γ_i} = h^{N|S|−|γ|}. Multiply by the weight w^{−k′}:
  · S = ∅: exponent of w is c|γ| + k − k′ = (k′−k)/2 + k − k′ = −(k′−k)/2 < 0, so the term is ≤ C w^{−(k′−k)/2} N^b_{−k}(v;0) ≤ C R^{−(k′−k)/2} N^b_{−k}(v;0). Matches the companion's "c|γ| + k − k′ = −(k′−k)/2".

**Local form of Diff_b(M).** Published p. 35 (read): "the Lie subalgebra and C^∞(M)-submodule X_b(M) ⊂ X(M) of vector fields tangent to ∂M, called b-vector fields. There is a canonical identity X_b(M) ≡ C^∞(M; bTM). Using X_b(M) like in Sect. 2.7, we get the filtered C^∞(M)-submodule and filtered subalgebra Diff_b(M) ⊂ Diff(M) of b-differential operators." Sect. 2.7 (p. 9, read): "Every Diff^m(M) (m ∈ ℕ_0) is spanned as C^∞(M)-module by all compositions of up to m elements of X(M)." Local frame, p. 30 (read): "x∂_x, ∂_{y^1}, …, ∂_{y^{n−1}} and x^{−1}dx, dy^1, …, dy^{n−1} extend to smooth local frames around boundary points." So on an adapted chart U, X_b(U) = C^∞(U)-span{x∂_x, ∂_{y^i}}, and (by the derivation rule and [x∂_x, ∂_{y^i}] = 0) every composition of ≤ k b-vector fields is a C^∞(U)-combination of the monomials (x∂_x)^a∂_y^b, a+|b| ≤ k, with coefficients smooth up to x = 0. The paper also states the codimension-one form explicitly on p. 50 (read): "Diff(U_j, L ∩ U_j) is spanned by x∂_x, ∂^1_j, …, ∂^{n−1}_j using the operations of C^∞(U_j)-module and algebra," and (6.26) p. 35: "Diff(M̆, ∂M)|_M = Diff_b(M)." The companion's "b-vector fields are C^∞-combinations of x∂_x, ∂_y" is therefore supported by the published text (it gives no page; p. 30 + p. 35, or p. 50 + (6.26), would do). Consequently, on supp λ_j (compact in U_j, boundary face included) the coefficients are bounded and sup x^{−m}|P(λ_j u)| ≤ C Σ_{a+|b|≤k} N^b_m(v_j;(a,b)): the (6.41) family over all P ∈ Diff_b(M), restricted to functions supported in the chart, is equivalent to the N^b_m(·;γ) family. One point the companion leaves implicit but which is needed for the converse direction: P := (x∂_x)^a∂_y^b∘λ_j is a global element of Diff_b(M). It is: take λ̃_j ∈ C_c^∞(U_j) with λ̃_j = 1 near supp λ_j; λ̃_j x∂_x and λ̃_j ∂_{y^i} extend by zero to global b-vector fields, and (λ̃_j x∂_x)^a(λ̃_j∂_y)^b(λ_j u) = (x∂_x)^a∂_y^b(λ_j u) because every derivative of λ_j u is supported where λ̃_j ≡ 1. Not a defect, a one-line fill.
