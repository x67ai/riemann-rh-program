## (d)-2. The symbol a_j of u_j from (4.8): normalization and sign

u_j(x′, x″) = j^{n′+m̄′} g(x″) ψ_*(jx′). By (4.8) as printed (sign −i in the exponent, no 2π factor on the forward transform):
a_j(x″, ξ) = ∫_{R^{n′}} e^{−i⟨x′,ξ⟩} j^{n′+m̄′} g(x″) ψ_*(jx′) dx′ = [y = jx′, dx′ = j^{−n′}dy] = j^{m̄′} g(x″) ∫ e^{−i⟨y, ξ/j⟩} ψ_*(y) dy = j^{m̄′} g(x″) ψ̂_*(ξ/j),
with ψ̂_*(η) := ∫ e^{−i⟨y,η⟩} ψ_*(y) dy. The j^{n′} in the prefactor exactly cancels the Jacobian, leaving j^{m̄′}: the note's "a_j(x″,ξ) = j^{m̄′} g(x″) ψ̂_*(ξ/j)" is correct.
ψ_* = Δ^{N_0}ψ: under this convention ∂_{y_k} ↦ iη_k (integration by parts: ∫ e^{−i⟨y,η⟩} ∂_kψ = −∫ ∂_k(e^{−i⟨y,η⟩})ψ = iη_k ψ̂), so Δ ↦ −|η|² and ψ̂_*(η) = (−|η|²)^{N_0} ψ̂(η), as the note says. (The sign is irrelevant; only the factor |η|^{2N_0} matters.) ψ̂ is Schwartz (ψ ∈ C_c^∞), so ψ̂_* is Schwartz. ψ̂_* ≢ 0: if |η|^{2N_0}ψ̂ ≡ 0 then ψ̂ = 0 on η ≠ 0, hence everywhere by continuity, hence ψ = 0.
Vanishing order: |η|^{2N_0} = (Σ η_k²)^{N_0} is a homogeneous polynomial P of degree 2N_0. For |β| ≤ 2N_0, ∂^β(Pψ̂) = Σ_{γ≤β} C_{βγ} ∂^γP · ∂^{β−γ}ψ̂ with ∂^γP homogeneous of degree 2N_0−|γ| ≥ 2N_0−|β|, so on |η| ≤ 1: |∂^βψ̂_*(η)| ≤ C_β |η|^{2N_0−|β|}. This is exactly "∂^βψ̂_* vanishes to order 2N_0 − |β| at 0" (for |β| ≤ 2N_0, the only range in which the note uses it).

## (d)-3. The seminorm identity and the bounds on Φ_{β,m̄_1}(j)

∂^α_{x″}∂^β_ξ a_j = j^{m̄′} ∂^αg(x″) · j^{−|β|} (∂^βψ̂_*)(ξ/j). With ξ = jη: (1+|ξ|)^{|β|−m̄_1} = (1+j|η|)^{|β|−m̄_1} = j^{|β|−m̄_1}(1/j+|η|)^{|β|−m̄_1}. Product: j^{m̄′−|β|+|β|−m̄_1} |∂^αg| |∂^βψ̂_*(η)| (1/j+|η|)^{|β|−m̄_1} = j^{m̄′−m̄_1} |∂^αg(x″)| |∂^βψ̂_*(η)| (1/j+|η|)^{|β|−m̄_1}. Taking sup over x″ ∈ K and η ∈ R^{n′} (η ranges over all of R^{n′} as ξ does):
‖a_j‖_{K,α,β,m̄_1} = j^{m̄′−m̄_1} sup_K|∂^αg| · Φ_{β,m̄_1}(j), Φ_{β,m̄_1}(j) = sup_η |∂^βψ̂_*(η)| (1/j+|η|)^{|β|−m̄_1}. Matches the note exactly.

Upper bound, m̄_1 ≤ 2N_0, j ≥ 1:
(i) |β| ≥ m̄_1: exponent ≥ 0 and 1/j + |η| ≤ 1 + |η|, so Φ ≤ sup_η |∂^βψ̂_*(η)|(1+|η|)^{|β|−m̄_1} < ∞ (Schwartz).
(ii) |β| < m̄_1 (the regime the brief asks about): exponent < 0 and 1/j + |η| ≥ |η|, so (1/j+|η|)^{|β|−m̄_1} ≤ |η|^{|β|−m̄_1} and Φ ≤ sup_η |∂^βψ̂_*(η)| |η|^{|β|−m̄_1}. Is this finite near η = 0? On |η| ≤ 1, by (d)-2: |∂^βψ̂_*(η)| |η|^{|β|−m̄_1} ≤ C_β |η|^{2N_0−|β|+|β|−m̄_1} = C_β |η|^{2N_0−m̄_1} ≤ C_β because 2N_0 − m̄_1 ≥ 0. (Note |β| < m̄_1 ≤ 2N_0 puts β in the range where (d)-2 applies.) On |η| ≥ 1, |η|^{|β|−m̄_1} ≤ 1 and ∂^βψ̂_* is bounded. So yes: the vanishing order 2N_0 − |β| is exactly enough, with equality allowed (m̄_1 = 2N_0 gives the exponent 0). Φ_{β,m̄_1}(j) ≤ C_{β,m̄_1} uniformly in j ≥ 1.
(If m̄_1 < 0 only regime (i) occurs; if N_0 = 0, i.e. m̄″ ≤ 0, regime (ii) never occurs since |β| < m̄_1 ≤ 0 is impossible. No gap.)

Lower bound: pick η_0 with ψ̂_*(η_0) ≠ 0 (exists, ψ̂_* ≢ 0 and continuous; η_0 ≠ 0 can be arranged). Φ_{0,m̄′}(j) ≥ |ψ̂_*(η_0)| (1/j+|η_0|)^{−m̄′}. If m̄′ ≥ 0: 1/j+|η_0| ≤ 1+|η_0| gives (1/j+|η_0|)^{−m̄′} ≥ (1+|η_0|)^{−m̄′}. If m̄′ < 0: (1/j+|η_0|)^{−m̄′} = (1/j+|η_0|)^{|m̄′|} ≥ |η_0|^{|m̄′|} = |η_0|^{−m̄′}. Hence Φ_{0,m̄′}(j) ≥ |ψ̂_*(η_0)| min{(1+|η_0|)^{−m̄′}, |η_0|^{−m̄′}} = c > 0 for all j ≥ 1, as the note says.

Consequences: with m̄_1 = m̄″ (2N_0 ≥ m̄″ by choice of N_0): ‖a_j‖_{K,α,β,m̄″} ≤ C j^{m̄′−m̄″} → 0 for every K, α, β, since m̄′ < m̄″. With m̄_1 = m̄′, α = β = 0, K compact meeting {g ≠ 0}: ‖a_j‖_{K,0,0,m̄′} ≥ c sup_K|g| > 0 for every j. The map u ↦ ‖a_1(u)‖_{K,0,0,m̄′} is a continuous seminorm on I^{m′}(M, L) (composition of the TVS-embedding (4.10) for m′ with the projection to the S^{m̄′}(N*L_1) factor and a (3.1) seminorm), so u_j ↛ 0 in I^{m′}(M, L); all components of (4.10) for m″ tend to 0 (see (d)-4), so u_j → 0 in I^{m″}(M, L); u_j ∈ I^m(M, L). The I^{m′}- and I^{m″}-topologies therefore differ on I^m(M, L) for every m < m′ < m″: Cor. 4.5 is false as printed (its statement quantifies over all m′, m″ > m; the instance m′ < m″ suffices).

## (d)-4. Membership u_j ∈ C_c^∞(U_1) ⊂ I^m(M, L); h u_j = 0, f_i u_j = 0; the modified partition of unity

Support: supp ψ_* ⊂ supp ψ ⊂ {|x′| < 1} (differentiation does not enlarge supports), so supp u_j ⊂ {|x′| ≤ 1/j} × supp g in the chart. Since 0 ∈ U′ (the chart meets L: L_0 = {x′ = 0} ≠ ∅) and supp g ⊂ U″ is compact, {|x′| ≤ 1/j} × supp g is a compact subset of U′ × U″ = x(U_1) for j large, so u_j (extended by zero) is in C_c^∞(U_1) ⊂ C^∞(M) ⊂ I^m(M, L) for every m ((d)-1). Also x^{-1}({|x′| ≤ 1/j} × supp g) shrinks to the compact set x^{-1}({0} × supp g) ⊂ L_0 as j → ∞, so it lies in the neighborhood N for j large. On N: h = 0, f_1 = 1, f_i = 0 (i ≥ 2), hence h u_j = 0, f_1 u_j = u_j, f_i u_j = 0. The (4.10)-image of u_j is (0, (a_j, 0, 0, …)) and the topology of I^{m″}(M, L) is the initial one of (4.10), so u_j → 0 in I^{m″}(M, L) iff a_j → 0 in S^{m̄″}(N*L_1; ΩN*L_1), which (d)-3 gives (the density factor |dξ| is a fixed trivialization in the chart and does not change the seminorms).

Modified partition of unity: given any {h, f_i} subordinate to {M∖L, U_i} (supp h ⊂ M∖L, supp f_i ⊂ U_i) and ρ ∈ C_c^∞(U_1) with ρ = 1 on N: h̃ = (1−ρ)h, f̃_1 = ρ + (1−ρ)f_1, f̃_i = (1−ρ)f_i (i ≥ 2). Sum: (1−ρ)(h + Σ_i f_i) + ρ = (1−ρ) + ρ = 1. Supports: supp h̃ ⊂ supp h ⊂ M∖L; supp f̃_i ⊂ supp f_i ⊂ U_i (i ≥ 2); supp f̃_1 ⊂ supp ρ ∪ supp f_1 ⊂ U_1 (supp ρ compact in U_1). On N: h̃ = 0, f̃_1 = 1, f̃_i = 0. Smoothness is clear. So the modified family is a C^∞ partition of unity subordinate to the same covering {M∖L, U_i} of (4.10), and the paper's definition on p. 22 admits any such family ("Let {h, f_j} be a C^∞ partition of unity of M subordinated to the open covering {M∖L, U_j}"). Cosmetic gap: for nonnegativity of the family the note should say 0 ≤ ρ ≤ 1 (always available); it does not, and neither does the companion (which nevertheless asserts "nonnegative"). This is a one-word repair with no mathematical content.

Choice-independence (the note's closed-graph remark, used only to preempt "you changed the partition of unity"): each admissible choice makes I^m(M, L) a Fréchet space (p. 22, "which becomes a Fréchet space"), and each such topology is finer than the Hausdorff topology induced from C^{−∞}(M): I^m ⊂ I^{(−m−n/4−ε)} continuously by (4.12) ("continuous inclusions", p. 22), I^{(s)} → H^s(M) continuous (projective topology of (4.3) with P = 1), H^s(M) ⊂ C^{−∞}(M) continuous. Two comparable-with-a-Hausdorff-topology Fréchet topologies on the same space coincide: the identity has closed graph (a τ_1-limit and a τ_2-limit of the same sequence are both its C^{−∞}-limit, hence equal), so it is continuous both ways by the closed graph theorem. HOLDS. (Even without this remark the refutation is within the paper's definition, since the paper fixes no particular partition of unity.)

## (f)-1. b_j ∈ S^j ∖ S^m for m < j

## (f)-2. {b_j} is bounded in S^∞(U × R^l)

Legitimacy of the basic neighborhoods. S^∞ = ⋃_m S^m carries the locally convex inductive limit topology (p. 4: "when the inductive/projective spectrum consists of a sequence of continuous inclusions, their union/intersection is endowed with the inductive/projective limit topology"; p. 5 reduces the real index to a sequence). Its absolutely convex 0-neighborhoods form a base, and boundedness means absorption by each of them. For such a W, each inclusion S^k → S^∞ is continuous, so W ∩ S^k is a 0-neighborhood of the Fréchet space S^k and therefore contains a finite intersection of open seminorm balls {a : ‖a‖_{K_i,α_i,β_i,k} < ε_i, i = 1..N}. Because ‖a‖_{K,α,β,k} is monotone in K, this contains W_k := {a ∈ S^k : ‖a‖_{K_k,α,β,k} < ε_k, (α,β) ∈ F_k} with K_k = ⋃_i K_i compact, F_k = {(α_i,β_i)} finite, ε_k = min_i ε_i. So yes: for each k, W ∩ S^k contains a basic neighborhood of the form the note uses, with all seminorms over the single compact K_k. The answer to the brief's question is that the seminorms in W_1 are over K_1 only, and that is legitimate. (Nothing requires the W_k to be compatible across k; the argument uses W ∩ S^1 and W ∩ S^{j+1} separately, and these are 0-neighborhoods for any W of the base, whatever index set defines the inductive limit.)

The split. Fix ρ ∈ C_c^∞(R^l), ρ = 1 on B(0,1), supp ρ ⊂ B(0,2), ρ_R(ξ) = ρ(ξ/R), R ≥ 1. Choose j_0 with supp χ_j ∩ K_1 = ∅ for j ≥ j_0 (local finiteness: K_1 meets only finitely many balls). For j ≥ j_0: b_j = b_jρ_R + b_j(1−ρ_R).
(a) b_jρ_R is smooth with ξ-support in B̄(0,2R), so all its (3.1) seminorms of every order are finite: b_jρ_R ∈ S^{−∞} ⊂ S^1. It vanishes identically on K_1 × R^l because χ_j = 0 on K_1. Hence ‖2b_jρ_R‖_{K_1,α,β,1} = 0 < ε_1 for all (α,β) ∈ F_1: 2b_jρ_R ∈ W_1 ⊂ W ∩ S^1 ⊂ W. The brief's question ("does it vanish on K_1 × R^l? yes if supp χ_j ∩ K_1 = ∅") is answered affirmatively by the choice of j_0.
(b) b_j(1−ρ_R) ∈ S^j ⊂ S^{j+1} (product of a symbol of order j and one of order 0), vanishes for |ξ| < R. Leibniz, computed: ∂^α_x∂^β_ξ[b_j(1−ρ_R)] = ∂^αχ_j(x) Σ_{β′+β″=β} C_{β′β″} ∂^{β′}_ξ(1+|ξ|²)^{j/2} · ∂^{β″}_ξ(1−ρ_R).
   - β″ = 0: supported in |ξ| ≥ R; |∂^αχ_j| |∂^β(1+|ξ|²)^{j/2}| |1−ρ_R| ≤ C(1+|ξ|)^{j−|β|} = C(1+|ξ|)^{j+1−|β|}(1+|ξ|)^{−1} ≤ C(1+|ξ|)^{j+1−|β|}/(1+R) there.
   - β″ ≠ 0: ∂^{β″}(1−ρ_R)(ξ) = −R^{−|β″|}(∂^{β″}ρ)(ξ/R), supported in R ≤ |ξ| ≤ 2R and bounded by C_{β″}R^{−|β″|}. On that region (1+|ξ|)/R ≤ (1+2R)/R ≤ 3, so R^{−|β″|} ≤ 3^{|β″|}(1+|ξ|)^{−|β″|}, and the term is ≤ C(1+|ξ|)^{j−|β′|} · 3^{|β″|}(1+|ξ|)^{−|β″|} = C′(1+|ξ|)^{j−|β|} ≤ C′(1+|ξ|)^{j+1−|β|}/(1+R), using 1+|ξ| ≥ 1+R there.
   Dividing by (1+|ξ|)^{j+1−|β|} and taking sup over K × R^l: ‖b_j(1−ρ_R)‖_{K,α,β,j+1} ≤ C_{j,α,β,K}/(1+R) for every compact K. So the S^{j+1}-seminorms are O(1/R) as the note says (the constant depends on j, which is fixed while R → ∞). Taking R = R_j large, the finitely many seminorms (α,β) ∈ F_{j+1} over K_{j+1} of 2b_j(1−ρ_R) are < ε_{j+1}: 2b_j(1−ρ_{R_j}) ∈ W_{j+1} ⊂ W ∩ S^{j+1} ⊂ W.
(c) Absolute convexity: b_j = ½(2b_jρ_R) + ½(2b_j(1−ρ_R)) ∈ W. So b_j ∈ W for all j ≥ j_0.
(d) The finitely many b_j, j < j_0: W is absorbing (it is a 0-neighborhood), so b_j ∈ λ_jW for some λ_j > 0; with λ = max{1, λ_j : j < j_0} and W ⊂ λW (λ ≥ 1, W absolutely convex), {b_j : j ≥ 1} ⊂ λW.
Since W was an arbitrary member of a base of 0-neighborhoods, {b_j} is bounded in S^∞(U × R^l).

## (f)-3. The conclusion: not regular, not boundedly retractive, not acyclic

Quoted, p. 4: "It is said that (X_k) is regular if any bounded B ⊂ X is contained and bounded in some step X_k. If moreover the topologies of X and X_k coincide on B, then (X_k) is said to be boundedly retractive." Quoted, p. 5: "If the steps X_k are Fréchet spaces, the above properties of (X_k) depend only on the LF-space X [39, Chapter 6, p. 111] … In this case, X is acyclic if and only if it is boundedly/compactly/sequentially retractive [39, Proposition 6.4]. As a consequence, acyclic LF-spaces are complete and regular [39, Corollary 6.5]." The steps S^m are Fréchet (p. 15). By (f)-1/(f)-2 the bounded set {b_j} lies in no step, so the spectrum is not regular; bounded retractivity presupposes regularity ("If moreover"), so it fails; and by the p. 5 sentence (acyclic ⟹ regular) acyclicity fails. This refutes the clauses "acyclic" and "boundedly retractive" of Cor. 3.6 (p. 18: "Corollary 3.6 S^∞(U × R^l) is an acyclic Montel space, and therefore complete, boundedly retractive and reflexive") for every nonempty open U ⊂ R^n with n ≥ 1 (every such U is non-compact) and every l ≥ 1. The note's further sentence "the printed derivations of the other clauses of Cor. 3.6 pass through these properties" is verified on p. 18: "Proof Corollary 3.4 gives the property of being acyclic, and therefore complete and boundedly retractive (Sect. 2.1). … Since S^∞(U × R^l) is boundedly retractive, B is contained and bounded in some S^m(U × R^l), and the topologies of S^∞(U × R^l) and S^m(U × R^l) coincide on B." The note correctly does not claim the completeness and Montel clauses are false.

Ruling: HOLDS.

## Companion §7 item 5 ("direct failure of the criterion (p. 4) for the same spectrum, for completeness of the record")

Not used by the note, but it is in the assigned companion §7 and it is wrong as written. The companion takes a_j := (1+j)^{m′} ψ(x) θ(ξ − je_1), asserts "a_j → 0 in S^{m″} (each seminorm is O(j^{m′−m″}))". False for ξ-derivatives: ∂^β_ξ a_j = (1+j)^{m′}ψ(x)(∂^βθ)(ξ − je_1) gains no decay, and on supp θ(· − je_1) one has 1+|ξ| ≍ j, so ‖a_j‖_{K′,0,β,m″} ≍ (1+j)^{m′+|β|−m″} sup|∂^βθ|, which is bounded away from 0 for |β| = m″ − m′ and → ∞ for |β| > m″ − m′ (with θ compactly supported, ∂^βθ ≢ 0 in every order). This is precisely the mechanism of witness (a) (translated bumps are not small in S^{m} for high ξ-derivatives), so the companion contradicts its own §2. Numerical check (1-D, θ = normalized bump on (−1,1), m′ = 1, m″ = 2, j = 10, 100, 1000): ‖a_j‖_{0,β,2} ≈ 0.092, 0.0099, 0.0010 for β = 0 (→ 0), 0.047, 0.044, 0.043 for β = 1 (constant), 0.093, 0.85, 8.4 for β = 2, 0.53, 42, 4065 for β = 3 (→ ∞). Repair: use a dilated annular bump instead, a_j := ψ(x) j^{m′} φ(ξ/j) with φ ∈ C_c^∞({1/2 < |ξ| < 2}), φ(e_1) = 1: then ∂^β_ξ a_j = ψ j^{m′−|β|}(∂^βφ)(ξ/j), on the support 1+|ξ| ≍ j, so every S^{m″}-seminorm is O(j^{m′−m″}) → 0, while a_j ∈ V for all j (all seminorms over K vanish since supp ψ ∩ K = ∅) and ‖a_j‖_{K′,0,0,m′} ≥ |a_j(x_0, je_1)|(1+j)^{−m′} = j^{m′}(1+j)^{−m′} → 1. With that, the m′- and m″-topologies differ on every 0-neighborhood of S^m, which is the criterion failure the item wanted. The note's (f) rests on (f)-1–(f)-3 only and is unaffected.
