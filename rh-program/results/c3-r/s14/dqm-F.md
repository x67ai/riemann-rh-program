## 0. VERDICT (stated first)

**PARTIAL — decomposing into three decided sub-parts and one reduction. Bottom line for the program: Road 2 (Haar-average the packet) is CLOSED as a route to S4's count; the object DQ-M names computes a Lefschetz index, not a Haar mass.**

Precisely, in the model world (compact metrizable substrates; continuous flows; [Den05]-§7 suspensions; the traces of [x-22] Thm 2.1/3.1, [Den05] Thm 5.3/7.8, [ALKL] Thm 1.3.10, [Lei07] Thm 2):

1. **THEOREM (NO) — the leafwise-cohomology trace does not Haar-average packets.** For every suspension Y = M ×_h R of a diffeomorphism h of a closed manifold M ([Den05] §7.7 with M̄ = M), the trace of φ^* on the leafwise cohomology H̄^•_F(Y) EXISTS with no non-degeneracy hypothesis at all, and
   Σ_j (−1)^j Tr(φ^* | H̄^j_F(Y)) = Σ_{k∈Z} L(h^k) δ_k, L(h^k) the Lefschetz number (Theorem L, §6.3, full proof).
   In the explicit model of §6.4 — M = T², h the time-one map of the vector field f·∂_x with f ≥ 0 vanishing exactly on a Cantor set C that meets every horizontal circle — the periodic set of the flow is exactly the continuum C × S¹ of closed orbits of common length 1, every one of them maximally degenerate (dh^k = id on C), and its contribution at every t = k ≠ 0 is L(h^k) = χ(T²) = 0. The Haar-averaged prescription ∫_C (single-orbit term) dμ = μ(C)·δ_k = δ_k is therefore NOT the orbital side of the leafwise trace, for every Cantor-group structure and every probability measure on C. What replaces the per-orbit term ℓ ε_γ(k) δ_{kℓ} of [ALKL]/[Den05] for a packet is ℓ · ind(P^k, base) · δ_{kℓ}: the fixed-point index of the packet base under the leafwise return map — an integer, insensitive to any measure on the base (§7). Inside the [Den05]-§7.7 class this is the only configuration a packet can have: closed orbits of a §7.7 suspension are in bijection with the finite orbits of f on the manifold M ([Den05] p. 35), so a packet base always lies in the leaf direction (Proposition 6.2); a Cantor base transverse to the leaves can only be manufactured as a product with an external Cantor factor (Lemma 6.1, from [Den05] p. 29).

2. **THEOREM (NO) — the unweighted (type I) trace of a packet diverges.** If the packet base sits transverse to the leaves (products B × X, B a Cantor group), Hörmander's transversal index in the form used by [x-22] Thm 2.1/3.1 does not exist: S_j(α) = 1 ⊗ S_j^X(α) is never trace class when S_j^X(α) ≠ 0 (Theorem D, §5.1). The Guillemin flat-trace regularization diverges at every accumulation point of a fixed set of a C¹ return map — a fortiori at a Cantor fixed set — (Theorem D′, §5.2), and for suspensions the flow's flat trace at t = k is the flat trace of h^k (Corollary D″). The "per-orbit term" of a packet in a type I trace is ∞ × (single-orbit term). Its finite regularizations are not unique: on the §6.4 model the Lefschetz/perturbative value is 0, the Haar/measured value is 1, the unweighted value is +∞ (Proposition R, §6.5).

3. **CONSTRUCTION (YES) — the measured (type II) trace exists, with exactly the Haar identity DQ-M asks for, but it is the wrong object.** For every fixed-point-free continuous flow on a compact metric space with a finite invariant Borel measure ν, the orbit-lamination transverse-measure trace T_ν is a positive Radon measure on R with
   T_ν = ν(Y) δ_0 + Σ_{k≠0} (m_k)_* σ, σ the period measure (Theorem M, §4), and a packet B × R/ℓZ with ν = μ ⊗ ds contributes ∫_B (ℓ Σ_{k≠0} δ_{kℓ}) dμ = ℓ μ(B) Σ_{k≠0} δ_{kℓ}. H4 is replaced by nothing. In the trivial model B × R/ℓZ both sides are computed (leafwise heat operator, Poisson summation; Theorems T1–T3, §3). **But** (Theorem N, §4.3): (a) Σ_ℓ (packet masses) ≤ ν(Y) < ∞, so Haar *probability* on every packet is impossible on a compact substrate (Σ_p log p = ∞); (b) T_ν has mass ≤ (1 + 1/ℓ_min) ν(Y) on every unit interval while the explicit formula's prime side has mass ≥ log p on [⌊log p⌋, ⌊log p⌋+1] — no reweighting reaches it; (c) T_ν is even in t, the prime side is not (weights p^k for k ≤ −1, [x-22] (1)); (d) T_ν is blind to ν-null orbits, i.e. to every isolated orbit of an absolutely continuous invariant measure. The infinite-measure regime has an infinite δ_0-coefficient and no trace-class operator; on the periodic part it yields only the "union of circles" identity Σ_p Σ_ν e^{2πiνt/log p}, with no zeros in it (§4.4).

4. **REDUCTION — the mixed trace is Fubini over selections.** The only trace that assigns μ(B) × (single-orbit term with the correct k ≤ −1 weights) to a packet is a mixed trace: type II in a globally split-off base direction, type I elsewhere. It exists on products, τ = μ(B) · Ind_t(X) (Theorem P, §5.3), and in general is by definition an integral over a measured family of type-I slices, each of which must meet each packet in an isolated set of orbits (Proposition F, §8.2). Road 2 in this form is a Haar average over a family of one-orbit-per-packet substrates — a family of Q-a objects, no easier than Q-a.

**Consequence for Q* (task item 3, §8):** the re-scoped clause "meeting each packet in a Haar-measured orbit family" is (i) unsatisfiable for any finite invariant transverse measure on a compact substrate, (ii) meaningless for the leafwise Lefschetz trace, whose packet term is an index, and (iii) equivalent, in the mixed reading, to Q-a for μ-almost every slice. **Road 2 is closed.** The correct re-scoping of S4's counting demand inside the [Den05]/[ALKL] framework is topological, not measure-theoretic: **each packet must be a compact isolated fixed set of the leafwise return map with fixed-point index 1 for every iterate** (§8.3) — which is Deninger's own printed device for degenerate orbits, "a Ruelle zeta function via Fuller indices" ([x-18] p. 8; [x-19] p. 10), made precise; its first obstacle is that the index needs a leafwise manifold structure around the packet base, which X₀ lacks (ledger W6). Nothing here fires the C3 kill-criterion (S4's mapping face Q-b is untouched; the packet-count obstruction is re-expressed, not removed).

## 2. The three traces, defined — and the model world

DQ-M's phrase "the distributional trace of the flow on leafwise forms" names, in the sources, three inequivalent constructions. The answer splits along this line, so the definitions are fixed first.

**2.1 The model world.** A *foliated space* with d-dimensional leaves is a separable metrizable space with charts U_i ≅ F_i × T_i, F_i ⊂ R^d open, transitions (x, y) ↦ (f_{ij}(x, y), g_{ij}(y)) with all D_x^α f_{ij} continuous in (x, y); a *(generalized) solenoid* of dimension a is a space locally homeomorphic to L_i × T_i with T_i totally disconnected, and then the transition condition is automatic because "continuous functions from connected subsets of R^a into a totally disconnected space are constant" ([Den05] §7.1, pp. 28–29). A codimension-one foliation F inside an a-dimensional solenoid (X, L) is a second foliated-space structure with (a − 1)-dimensional leaves refining L; a flow is a continuous R-action, smooth on L-leaves, F-compatible if it maps F-leaves to F-leaves ([Den05] §7.2–7.3, pp. 29–30). The suspension model ([Den05] §7.7, pp. 34–35): M̄ compact with a leafwise-smooth homeomorphism f̄ (in §7.7, M̄ = lim(… → M → M) for an unramified self-covering f of a closed connected manifold M, and f̄ the shift), Λ = lZ acting on M̄ × R by (m, t)·λ = (f̄^{−λ/l}(m), t + λ), X = M̄ ×_Λ R, F-leaves the images of the leaves of M̄ × {t}, flow φ^t[m, t′] = [m, t + t′] — transverse to F, no fixed points. Its closed orbits are in bijection with the finite orbits of f̄, hence with those of f on M, with l(γ) = |γ_M| l ([Den05] p. 35).

The *packet configuration* DQ-M posits: a compact substrate Y whose periodic set contains a continuum P ≅ B × R/ℓZ of closed orbits of common minimal period ℓ, B a Cantor group (compact, metrizable, totally disconnected, perfect) with Haar probability measure μ, the flow acting on P as rotation on the second factor. Two geometric positions of B relative to the F-leaves are possible: **transverse to F** (B a transversal factor; realized by products B × X, §5) or **inside the F-leaves** (B a Cantor set in a leaf, fixed pointwise by the leafwise return map; realized by suspensions, §6). Inside the [Den05] §7.7 class only the second occurs (Proposition 6.2); the first is the configuration of the "adelic solenoid first" suggestion and of any Cantor-group extension of a connected flow (Lemma 6.1).

**2.2 Trace (I): the Hörmander/Guillemin/Lefschetz trace on leafwise forms (type I).** The object of [x-22] Thm 2.1/3.1, [Den05] Thm 5.3/7.8, [Lei07] Thm 2, and — with its renormalizations — [ALKL] Thm 1.3.10. Ingredients: the leafwise de Rham complex (A^•_F(X), d_F) (forms smooth along F-leaves, continuous transversally: [Den05] §7.2 p. 29); a φ-invariant measure and a leafwise metric making A^•_{F,L²}(X) a Hilbert space; the weak closure d̃_F; Harm^j_{L²}(X) = Ker d̃_F ∩ Ker d̃_F^* (or, on the cohomological side, the Hilbert completion Ĥ^j of the reduced leafwise cohomology H̄^j_F, [Den05] §5.2 p. 21); and for α ∈ C_c^∞(R) the operator S_j(α) = ∫ α(t) φ^{t*} dt on it. The trace *exists* when S_j(α) is of trace class for every α, and then T_j(α) := Tr S_j(α) is a distribution, Ind_t := Σ_j (−1)^j T_j ([x-22] Thm 2.1 p. 5, Thm 3.1 p. 12; [Den05] Thm 5.3 p. 22: "the operator A_ϕ … is of trace class"). The trace is a **Hilbert-space trace**: no transverse measure weights the sum over orbits; a transverse measure enters only through the L²-structure ([x-22] p. 10: μ_ξ inside μ̃; [Lei07] p. 17: the scalar product via the Ruelle–Sullivan current of Λ = μ_L dx, "TR denotes the (usual) trace of trace class operators", p. 3). Its orbital side, whenever proved, has the Lefschetz shape ℓ(γ) Σ_k ε_γ(k) δ_{kℓ(γ)} (with the α-twisted weights on k ≤ −1 in the solenoidal case, [Den05] Thm 7.8; [x-22] Cor. 3.4) and a δ_0-coefficient χ_Co(F, μ). The **hypothesis H4** (ledger §2): closed orbits simple — the leafwise return map has no eigenvalue 1 ([ALKL] §4.1.1 p. 99; [Den05] Thm 5.3 p. 22, 7.5 p. 30, 7.8 p. 35; [x-22] Thm 2.2 p. 6; [Lei07] Thm 2 p. 17; [ALKM] (A1) p. 4). Under H4 the closed orbits are isolated, C_I(φ) is finite for compact I, and the period set is discrete ([ALKL] p. 99; [ALKM] p. 4: "which implies that P is a countable set"). The manifold version of the same trace with the flat-trace (Schwartz-kernel-on-the-diagonal) regularization is Guillemin's, quoted in [Lei07] pp. 3–4 as the Guillemin–Sternberg contribution ℓ(γ) α(±kℓ(γ)) Σ_j (−1)^j Tr(Dφ^{±kℓ})^*|Λ^j T^*_yF / |det(id − Dφ^{±kℓ}|T_yF)|.

**2.3 Trace (II): the transverse-measure trace along the orbit lamination (type II).** Let G be the partition of Y into flow orbits and ν a finite φ-invariant Borel measure (equivalently, a holonomy-invariant transverse measure for G when G is a lamination). For f ∈ C_c(R) the operator φ^f = ∫ f(t) φ^{t*} dt acts on each orbit by convolution along the orbit; its orbitwise Schwartz kernel has a well-defined diagonal value F_f(y) = Σ_{t ∈ Per(y)} f(t), and the type II trace is T_ν(f) := ∫_Y F_f dν (Definition 4.3 below). This is the trace of the von Neumann algebra of the measured lamination (Y, G, ν) evaluated on the leafwise operator φ^f — the trace [Lei07] Prop. 2 p. 16 constructs from the Haar transverse measure for the *surface* lamination (there used to identify the type of W(S, F) ⋊ R as III_{1/q}, **not** for the trace formula, which is type I: [Lei07] Thm 2 p. 17 uses TR). Here it is applied to the *orbit* lamination, where the flow operators are leafwise. No non-degeneracy, no isolation, no smoothness is required: H4 is replaced by ν-measurability. What is given up is recorded in Theorem N.

**2.4 Trace (III): the mixed trace.** A measured decomposition of Y into flow-invariant slices {Y_b}_{b∈Z} with a measure μ on the slice space Z, and a type I trace Tr_b on μ-a.e. slice; τ(f) := ∫_Z Tr_b(φ^f) dμ(b). On a product Y = B × X with slices {b} × X this is the trace of the von Neumann algebra L^∞(B, μ) ⊗̄ B(H) with the trace ∫ dμ ⊗ Tr (Theorem P). It is the only one of the three that returns, for a packet, "μ(B) times the single-orbit term with the [Den05]/[x-22] weights".

**2.5 The single-orbit term, for reference.** For an isolated closed orbit γ of length ℓ transverse to F with leafwise return map P = T_xφ^{ℓ}|T_xF: contribution ℓ Σ_{k≠0} ε_γ(k) δ_{kℓ}, ε_γ(k) = sgn det(1 − P^k) ([x-22] Thm 2.2 p. 6; [Den05] (23) p. 22; [ALKL] Thm 1.3.10 p. 8), with the k ≤ −1 weights ε_γ(|k|) det(−T_xφ^{kℓ}|T_xF) in the solenoidal case ([Den05] Thm 7.8 p. 35) and e^{kℓ(γ)} in the CM example ([x-22] Cor. 3.4 p. 18). The arithmetic target: coefficient 1 on log p · δ_{k log p} for every prime and every k ≥ 1 (ledger T1), p^k on k ≤ −1 (T2). If dim F = 0 (leaves are points), ε ≡ 1 and the term is ℓ Σ_{k≠0} δ_{kℓ}; this is the "single-orbit contribution" of DQ-M's trivial model.

## 3. The trivial model Y = B × R/ℓZ — the honest computation (task item 1)

Throughout §3: B a compact metrizable totally disconnected space with a finite Borel measure μ whose support is infinite (Haar measure of an infinite compact group qualifies: it has full support and B is infinite); S¹_ℓ := R/ℓZ; Y := B × S¹_ℓ with the flow φ^t(b, s) = (b, s + t). Every orbit is closed of minimal period ℓ; the periodic set is all of Y; Λ = Z acts trivially on M̄ = B and Y = B ×_Z R with the §7.7 conventions. Two foliations are relevant: **G**, the foliation by orbits {b} × S¹_ℓ (leaves circles, transversal B); and **F₀**, the [Den05]-§7.7 codimension-one foliation, whose leaves are the images of the leaves of M̄ × {t} — since M̄ = B is 0-dimensional, the F₀-leaves are the points of Y, dim F₀ = 0, and A^•_{F₀}(Y) = C(Y) in degree 0 only. The flow is transverse to F₀, and the single-orbit term for F₀ is ℓ Σ_{k≠0} δ_{kℓ} (§2.5).

**Notation.** For f ∈ C_c^∞(R) put Φ(z) := ∫_R e^{tz} f(t) dt (entire), and note Φ(2πin/ℓ) = ℓ · ĝ(−n) for g(τ) := f(ℓτ), where ĝ(ξ) = ∫ e^{−2πiξτ} g(τ) dτ. **Poisson summation** — Σ_{n∈Z} ĝ(n) = Σ_{k∈Z} g(k) for g ∈ C_c^∞(R) — is used in the exact form Deninger uses it ([x-22] p. 23, "the Poisson summation formula asserts that Σ ψ(n) = Σ ψ̂(n)") [classical; proof: the 1-periodization Σ_k g(τ + k) is smooth and its Fourier series converges at τ = 0]. Hence

   (3.0) Σ_{n∈Z} Φ(2πin/ℓ) = ℓ Σ_{k∈Z} f(kℓ).

**3.1 The G-reading: leafwise circles, leafwise Laplacian, heat operator.** Leafwise forms along G: A^0_G(Y) = C(B; C^∞(S¹_ℓ)), A^1_G(Y) = C(B; C^∞(S¹_ℓ)) ds, d_G a = ∂_s a ds. With the flat metric on each circle, the leafwise Laplacian is Δ = −∂_s² on both degrees, and the leafwise heat operator e^{−uΔ} acts on each circle by the periodic heat kernel. L²-completion with respect to μ ⊗ ds: L²(Y) = L²(B, μ) ⊗ L²(S¹_ℓ), on which φ^{t*} = 1 ⊗ R_t, (R_t a)(s) = a(s + t). Let e_n(s) := ℓ^{−1/2} e^{2πins/ℓ} (n ∈ Z), an orthonormal basis of L²(S¹_ℓ); R_t e_n = e^{2πint/ℓ} e_n and Δ e_n = (2πn/ℓ)² e_n. For u ∈ [0, ∞] and f ∈ C_c^∞(R),

   P_{u,f} := ∫_R f(t) φ^{t*} e^{−uΔ} dt = 1 ⊗ K_{u,f}, K_{u,f} e_n = e^{−u(2πn/ℓ)²} Φ(2πin/ℓ) e_n,

with e^{−∞Δ} := the projection to ker Δ = span(e_0) (this is [ALKL] (1.2.4) p. 2 in the trivial model). K_{u,f} is trace class on L²(S¹_ℓ) for every u ∈ [0, ∞] (|Φ(2πin/ℓ)| = ℓ|ĝ(−n)| is rapidly decreasing), with

   Tr K_{u,f} = Σ_{n∈Z} e^{−u(2πn/ℓ)²} Φ(2πin/ℓ), Tr K_{0,f} = ℓ Σ_{k∈Z} f(kℓ) by (3.0), Tr K_{∞,f} = Φ(0) = ∫ f.

**Theorem T1 (type I: the trace does not exist).** For every u ∈ [0, ∞] and every f with K_{u,f} ≠ 0 (i.e. some e^{−u(2πn/ℓ)²}Φ(2πin/ℓ) ≠ 0), the operator P_{u,f} = 1 ⊗ K_{u,f} on L²(B, μ) ⊗ L²(S¹_ℓ) is **not** of trace class; in particular Hörmander's transversal index ([x-22] Thm 2.1 p. 5) and Deninger's Tr(φ^* | H̄^•) ([Den05] Thm 5.3 p. 22) do not exist for Y in either reading (G or F₀).
*Proof.* Polar decomposition: |1 ⊗ K| = 1 ⊗ |K| (since (1 ⊗ K)^*(1 ⊗ K) = 1 ⊗ K^*K and the square root is taken factorwise). For an orthonormal basis {χ_i} of L²(B, μ) and {e_n} of L²(S¹_ℓ), Tr(1 ⊗ |K|) = Σ_i Σ_n ⟨(1 ⊗ |K|)(χ_i ⊗ e_n), χ_i ⊗ e_n⟩ = Σ_i Σ_n ⟨|K| e_n, e_n⟩ = dim L²(B, μ) · Tr|K|. Since supp μ is infinite, L²(B, μ) is infinite-dimensional (infinitely many disjoint open sets of positive measure give infinitely many orthogonal nonzero indicator functions), and Tr|K| > 0 because K ≠ 0. Hence Tr|1 ⊗ K| = ∞. In the F₀-reading the leafwise complex is C(Y) in degree 0, Harm^0_{L²} = L²(Y), and S_0(f) = ∫ f(t) φ^{t*} dt = 1 ⊗ K_{0,f}: the same operator. In the G-reading, ker(d̃_G) ∩ ker(d̃_G^*) in degree 0 is L²(B, μ) ⊗ span(e_0) and S_0(f) restricted to it is 1 ⊗ K_{∞,f} = Φ(0)·1, not trace class for Φ(0) ≠ 0; in degree 1 likewise. ∎

*Reading.* The whole failure is the factor dim L²(B, μ) = ∞ — the trace of the identity on the functions on the packet base. There is no leafwise ellipticity and no flow transversality in the B-direction to produce decay, and no Hilbert-space trace can be finite there. This is precisely the mechanism Leichtnam names for his p-adic transversal ([Lei07] p. 4: the operator "does not involve any regularizing process along the p-adic transversal Z_p^m. Therefore, unless Assumption (iv) is satisfied we see no reason why … should be trace class") — his Assumption (iv) forces the harmonic forms to be locally constant transversally, i.e. it forces the transversal contribution to be finite-dimensional, which is exactly what a packet base with infinitely many orbits violates.

**Theorem T2 (type II: the μ-trace exists and gives the Haar identity).** Define, for a decomposable operator A = ∫^⊕_B A_b dμ(b) on L²(B, μ) ⊗ L²(S¹_ℓ) = L²(B, μ; L²(S¹_ℓ)) with A_b of trace class and ∫ ‖A_b‖_1 dμ < ∞, the μ-trace τ_μ(A) := ∫_B Tr(A_b) dμ(b). (For A = 1 ⊗ K this is the trace of the von Neumann algebra L^∞(B, μ) ⊗̄ B(L²(S¹_ℓ)) with the trace ∫ dμ ⊗ Tr; for a leafwise operator with continuous kernel k(b; s, s′) it equals ∫_B ∫_{S¹_ℓ} k(b; s, s) ds dμ(b), the transverse-measure trace of the measured lamination (Y, G, μ).) Then for every u ∈ [0, ∞] and f ∈ C_c^∞(R):

   τ_μ(P_{u,f}) = μ(B) Σ_{n∈Z} e^{−u(2πn/ℓ)²} Φ(2πin/ℓ);   lim_{u↓0} τ_μ(P_{u,f}) = τ_μ(P_{0,f}) = μ(B) · ℓ Σ_{k∈Z} f(kℓ) = ∫_B ( ℓ Σ_{k∈Z} f(kℓ) ) dμ(b).

As distributions in t: τ_μ(φ^{t*}) = μ(B) Σ_{n∈Z} e^{2πint/ℓ} = μ(B) ℓ Σ_{k∈Z} δ_{kℓ} — the spectral side (the rotation spectrum {2πin/ℓ} with multiplicity μ(B)) equals the orbital side (the single-orbit term ℓ Σ_k δ_{kℓ} times μ(B)), an identity of distributions on R; for μ a probability measure the packet contributes exactly the single-orbit term. On leafwise 1-forms the same trace results, so the G-Lefschetz supertrace is τ_μ(P^{(0)}_{u,f}) − τ_μ(P^{(1)}_{u,f}) = 0 = χ(S¹) · μ(B) for every u — the [ALKL] (1.2.4) u-independence of the supertrace, here trivially; the non-super trace is u-dependent (u = ∞ gives μ(B) ∫ f, u = 0 gives the orbit sum), which is why only the supertrace carries orbit information in the G-reading, while in the F₀-reading (degree 0 only) the trace itself is the orbit sum.
*Proof.* A = 1 ⊗ K_{u,f} is decomposable with A_b = K_{u,f} for all b, so τ_μ(A) = μ(B) Tr K_{u,f}; the limit u ↓ 0 is dominated convergence against Σ_n |Φ(2πin/ℓ)| < ∞; (3.0) gives the orbit form; the distribution identity Σ_n e^{2πint/ℓ} = ℓ Σ_k δ_{kℓ} is (3.0) read against test functions. ∎

**Theorem T3 (the function spaces and the notion of trace, stated precisely).** *Space side:* L²(Y, μ ⊗ ds) (or the continuous functions C(Y), whose L²-completion it is); leafwise forms along G smooth on circles, continuous in b. *Test side:* C_c(R) suffices — τ_μ(P_{0,f}) = μ(B) Σ_{k} ℓ f(kℓ) is a Radon measure in f of order 0, |τ_μ(P_{0,f})| ≤ μ(B) ℓ (1 + 2R/ℓ) ‖f‖_∞ for supp f ⊂ [−R, R]. *Notion:* the transverse-measure trace τ_μ of the measured orbit lamination (Y, G, μ), i.e. type II in the base direction, evaluated on the leafwise operators P_{u,f}; hypothesis H4 of [ALKL] is replaced by: nothing (the base is not required to be isolated, and no return map is linearized), at the price that the weighting is external — τ_μ depends on μ, and μ is not determined by the dynamics (every finite Borel measure on B gives a flow-invariant measure μ ⊗ ds on Y, and each gives a different τ_μ, all of the form μ(B) × the same distribution). What Theorem T2 establishes is exactly DQ-M's item (1): existence, and orbital side = ∫_B (single-orbit term) dμ = single-orbit term when μ(B) = 1. What Theorem T1 establishes is that this is **not** the [x-22]/[Den05]/[ALKL]/[Lei07] trace, which does not exist on Y.

**Remark 3.4 (the Cantor group structure is invisible).** Nothing in §3 used the group law on B; the flow fixes every point of B, and the only role of "Haar" is to single out one probability measure among uncountably many. In X₀ the group law on B_p = Ẑ×_(p)/p^Ẑ is what makes Haar canonical and Aut(C)-equivariant (9.4 note §7 Road 2, Lemma D(iii)); in the model world that canonicity is an input, not something any trace produces.

## 4. The measured trace in general: existence (Theorem M) and its arithmetic reach (Theorem N)

**Standing hypotheses for §4.** (Y, d) a compact metric space; φ: R × Y → Y a continuous flow with no fixed points; ν a finite φ-invariant Borel measure on Y. No lamination structure, no smoothness, no isolation of orbits is assumed.

**Lemma 4.1 (period gap).** There is ℓ_min > 0 such that every periodic point has minimal period ≥ ℓ_min.
*Proof.* Otherwise there are y_n ∈ Y and periods 0 < t_n → 0 with φ^{t_n} y_n = y_n; pass to a subsequence y_n → y. Fix t ∈ R and write t = m_n t_n + r_n with m_n ∈ Z, 0 ≤ r_n < t_n; then φ^t y_n = φ^{r_n} y_n. Hence d(φ^t y, y) ≤ d(φ^t y, φ^t y_n) + d(φ^{r_n} y_n, y_n) + d(y_n, y). The first and third terms → 0 (continuity of φ^t; y_n → y). For the second, ω(r) := sup_{z∈Y} d(φ^r z, z) is continuous on [0, 1] (φ is uniformly continuous on [0,1] × Y by compactness) with ω(0) = 0, so d(φ^{r_n} y_n, y_n) ≤ ω(r_n) → 0. Thus φ^t y = y for all t: a fixed point, contradiction. ∎

**Lemma 4.2 (measurability).** For y ∈ Y let Per(y) := {t ∈ R : φ^t y = y}, a closed subgroup of R different from R; hence Per(y) = ℓ_y Z with ℓ_y ∈ [ℓ_min, ∞), or Per(y) = {0}, in which case we write ℓ_y = ∞. The function y ↦ ℓ_y is lower semicontinuous, hence Borel; the sets Y_per := {ℓ_y < ∞} and Y_ℓ := {ℓ_y = ℓ} are Borel and φ-invariant.
*Proof.* For T ≥ ℓ_min, C_T := {y : ∃ t ∈ [ℓ_min, T] with φ^t y = y} is the projection to Y of the closed subset {(t, y) ∈ [ℓ_min, T] × Y : φ^t y = y} of a compact space, hence compact. And {ℓ_y ≤ T} = C_T: if ℓ_y ≤ T then ℓ_y ∈ [ℓ_min, T] is a period; conversely a period t ∈ [ℓ_min, T] is a positive multiple of ℓ_y, so ℓ_y ≤ T. Sublevel sets closed ⇒ lower semicontinuous ⇒ Borel. Y_ℓ = {ℓ_y ≤ ℓ} ∖ ∪_m {ℓ_y ≤ ℓ − 1/m}. Invariance is clear. ∎

**Definition 4.3 (orbitwise diagonal; the measured trace).** For f ∈ C_c(R) with supp f ⊂ [−R, R] set F_f(y) := Σ_{t ∈ Per(y)} f(t) = Σ_{k∈Z} f(kℓ_y) (only the term k = 0 if ℓ_y = ∞). F_f is Borel and |F_f| ≤ (1 + 2R/ℓ_min) ‖f‖_∞. Define T_ν(f) := ∫_Y F_f dν. The name: on an orbit through y, identified with R/Per(y) with its Lebesgue coordinate s, the operator φ^f = ∫ f(t) φ^{t*} dt acts by (φ^f a)(s) = ∫ f(t) a(s + t) dt = ∫ k_y(s, s′) a(s′) ds′ with k_y(s, s′) = Σ_{t∈Per(y)} f(s′ − s + t); its diagonal value k_y(s, s) = F_f(y) is constant along the orbit. T_ν integrates this diagonal against ν: it is the transverse-measure trace of the leafwise operator φ^f on the measured orbit lamination, and on a product packet B × S¹_ℓ with ν = μ ⊗ ds it is the τ_μ of Theorem T2.

**Definition 4.4 (period measure).** σ := (ℓ_·)_*(ν|_{Y_per}), a finite Borel measure on [ℓ_min, ∞) with σ([ℓ_min, ∞)) = ν(Y_per) ≤ ν(Y). For k ∈ Z∖{0} let m_k: ℓ ↦ kℓ.

**Theorem M (measured trace formula for continuous flows).** [novelty: single-check — the statement is likely folklore in measured-lamination/flow-Lefschetz form; no source on disk contains it.]
(i) T_ν is a positive Radon measure on R, and as measures
   T_ν = ν(Y) δ_0 + Σ_{k∈Z∖0} (m_k)_* σ.
(ii) For every interval [T, T + 1] with T > 0: T_ν([T, T+1]) ≤ (1 + 1/ℓ_min) ν(Y); and T_ν([−T, T]) ≤ (1 + 2T/ℓ_min) ν(Y).
(iii) (packets) If P ⊂ Y_ℓ is a φ-invariant Borel set with a Borel isomorphism P ≅ B × R/ℓZ conjugating the flow to rotation in the second factor and carrying ν|_P to μ ⊗ ds for a finite Borel measure μ on B, then σ has the atom ℓ μ(B) at ℓ from P, and P contributes to T_ν the term
   ℓ μ(B) Σ_{k≠0} δ_{kℓ} = ∫_B ( ℓ Σ_{k≠0} δ_{kℓ} ) dμ(b).
(iv) T_ν is even: T_ν(f̌) = T_ν(f) for f̌(t) = f(−t).
(v) T_ν does not see periodic orbits of ν-measure zero: if ν(Y_per) = 0 then T_ν = ν(Y) δ_0.
*Proof.* (i) Positivity and the bound |T_ν(f)| ≤ (1 + 2R/ℓ_min)‖f‖_∞ ν(Y) make f ↦ T_ν(f) a positive linear functional on C_c(R) bounded on each C([−R, R]); by the Riesz representation theorem it is a positive Radon measure. For the formula: T_ν(f) = ∫_Y f(0) dν + Σ_{k≠0} ∫_{Y_per} f(kℓ_y) dν(y) (the k-sum has at most 2R/ℓ_min nonzero terms, so it may be exchanged with the integral), and ∫_{Y_per} f(kℓ_y) dν(y) = ∫ f(kℓ) dσ(ℓ) = ∫ f d[(m_k)_*σ] by the change-of-variables formula for the Borel map y ↦ ℓ_y. (ii) For T > 0, T_ν([T, T+1]) = Σ_{k≥1} σ({ℓ : kℓ ∈ [T, T+1]}) = ∫ #{k ≥ 1 : kℓ ∈ [T, T+1]} dσ(ℓ) ≤ ∫ (1 + 1/ℓ) dσ ≤ (1 + 1/ℓ_min) σ([ℓ_min, ∞)) ≤ (1 + 1/ℓ_min) ν(Y); similarly for [−T, T] with the δ_0 mass added. (iii) Under the isomorphism, ℓ_y = ℓ on P and ν(P) = μ(B) · ℓ, so σ ≥ ℓμ(B) δ_ℓ with this atom coming from P, and its image under Σ_{k≠0}(m_k)_* is ℓμ(B) Σ_{k≠0} δ_{kℓ}; the integral form is the identity ∫_B c dμ = c μ(B) for the constant c = ℓ Σ_{k≠0} δ_{kℓ}. (iv) Per(y) = −Per(y). (v) Immediate from (i). ∎

**Remark 4.5 (what H4 bought and what its removal costs).** Theorem M needs no isolation, no non-degeneracy, no linearization, and no leaf structure; it accepts a continuum of periods (σ may have a continuous part, as for a flow on an annulus with continuously varying periods — there T_ν has an absolutely continuous part and no delta terms at all). The costs are (iv) and (v): no sign ε_γ(k), no leafwise Jacobian, no α-twisted weights, and no contribution from an orbit that ν does not charge. In particular for a smooth flow on a manifold with an absolutely continuous invariant measure, every isolated closed orbit is invisible to T_ν, whereas it is the whole content of the type I trace.

**4.3 Theorem N (the measured trace cannot serve T1/T2 on a compact substrate).** [novelty: single-check] Let W := Σ_p log p Σ_{k≥1} δ_{k log p} (the k ≥ 1 part of the prime side of [x-22] (1) p. 1, ledger T1) and W^− := Σ_p log p Σ_{k≤−1} p^k δ_{k log p} (the k ≤ −1 part, ledger T2).
(a) *(finite mass)* Under the hypotheses of §4, if for every prime p the set Y_{log p} contains a packet P_p ≅ B_p × R/(log p)Z with ν|_{P_p} = μ_p ⊗ ds, then Σ_p log p · μ_p(B_p) ≤ ν(Y) < ∞. In particular μ_p(B_p) = 1 for all p — Haar *probability* on every packet, the re-scoped S4 clause — is impossible, since Σ_p log p = ∞ (there are infinitely many primes and each term is ≥ log 2). Any admissible weighting has c_p := μ_p(B_p) → 0 with Σ c_p log p < ∞.
(b) *(growth)* For every (Y, φ, ν) as in §4, T_ν|_{(0,∞)} ≠ W; more strongly, T_ν + ρ_0 ≠ W + ρ_0′ for all measures ρ_0, ρ_0′ supported at {0}. *Proof.* Put C := (1 + 1/ℓ_min) ν(Y). Since the primes are unbounded [classical, Euclid], choose a prime p with log p > C and set T := ⌊log p⌋ ≥ 1. Then T_ν([T, T+1]) ≤ C < log p ≤ W([T, T+1]). ∎
(c) *(parity)* T_ν is even (Theorem M(iv)) while W + W^− is not (its weights are 1 on k ≥ 1 and p^k on k ≤ −1); so even on R∖{0}, and even after any reweighting c_p of packets, no measured trace has the prime side's shape: c_p log p = log p for k ≥ 1 and c_p log p = p^k log p for k ≤ −1 cannot both hold. This is ledger R11 (orbit-weight shape) recurring: the measured trace has leafwise return Jacobian ≡ 1 because it has no leaf direction at all.
(d) *(with fixed points)* If fixed points are allowed (as the archimedean place requires, [Den05] 7.6 (6) p. 33; [x-22] p. 19) and Per(y) = R at a fixed point, define F_f(y) = ∫ f there; then T_ν([T, T+1]) ≤ ν(Fix) + ∫ (1 + 1/ℓ) dσ(ℓ). If the right side is finite, (b) holds with this constant; if ∫ dσ/ℓ = ∞ (periods accumulating at 0 with positive mass), T_ν has infinite mass on every unit interval and is not a Radon measure at all. Either way T_ν ≠ W.

**4.4 The infinite-measure regime (the only residual, and why it is not a road).** Drop finiteness: let ν be a φ-invariant Borel measure that is σ-finite and finite on each Y_ℓ, so that σ is locally finite on [ℓ_min, ∞). Then f ↦ ∫ F_f dν is well defined for f ∈ C_c(R∖{0}) and equals Σ_{k≠0} (m_k)_*σ there; with σ = Σ_p log p δ_{log p} (Haar probability on every packet) this is W + (its mirror with weights 1, not p^k) on R∖{0}. Three facts make this a non-object rather than a trace formula. (i) ν(Y) = ∞, so the δ_0 coefficient is +∞: there is no distribution on R, whereas every trace formula in the sources has a finite δ_0 term (χ_Co(F, μ) in [x-22] Thm 2.2, [Den05] (23), Thm 7.8; ᵇχ in [ALKL] Thm 1.3.10; χ_Λ(F) in [Lei07] Thm 2) and the explicit formula's W_∞ has the finite coefficient α(0) log π ([x-22] p. 1). (ii) No operator φ^f with f(0) ≠ 0 is in the trace ideal of the measured lamination (the positive part of φ^f ∗ φ^{f̌} has diagonal ‖f‖²_2 > 0 on every orbit and ν(Y) = ∞), so there is no spectral side. (iii) On a compact Y the packets P_p, being infinitely many disjoint invariant sets, accumulate on a nonempty closed set A, and every neighborhood of A has infinite ν-measure: ν is not locally finite, i.e. not a Radon measure — outside the transverse-measure framework of [Lei07] Prop. 2, of the S2 axiom (A-v), and of Connes' construction. What the periodic part alone does yield is the identity Σ_p Σ_{n∈Z} e^{2πint/log p} = Σ_p log p Σ_{k≠0} δ_{k log p} on R∖{0} — Theorem T2 summed over packets — whose "spectral side" is the rotation spectrum of a disjoint union of circles of lengths log p with multiplicity one each: no zeros of ζ appear, nor could they, since the aperiodic part of Y contributes nothing away from t = 0. This regime therefore fails a printed requirement (finite δ_0), has no spectral side, and its orbital identity is arithmetic-free. It is recorded as the sole residual of the measured reading and is not counted as a road.

## 5. The unweighted trace on a packet transverse to the leaves: divergence, and the product mixed trace

**5.1 Theorem D (products: the Hörmander/Deninger trace does not exist).** [novelty: single-check] Let (X, L, F, φ, ν_X, g) be a compact smooth solenoid with codimension-one foliation, F-compatible flow, φ-invariant measure and leafwise metric, such that Hörmander's construction of §2.2 applies and yields trace-class operators S_j^X(α) on Harm^j_{L²}(X) for all α ∈ C_c^∞(R) — for instance Deninger's generalized solenoid of [x-22] §3 (Theorem 3.1, p. 12), or any §7.7 suspension covered by [Den05] Thm 7.8. Let B be a compact metrizable space with a finite Borel measure μ of infinite support (a Cantor group with Haar measure), and Y := B × X with the product solenoid structure (L_Y-leaves {b} × L, F_Y-leaves {b} × F-leaves, flow 1 × φ, measure μ ⊗ ν_X, the leafwise metric of X). Then:
(i) A^j_{F_Y, L²}(Y) = L²(B, μ) ⊗ A^j_{F, L²}(X), the weak closure is d̃_{F_Y} = 1 ⊗ d̃_F, and Harm^j_{L²}(Y) = L²(B, μ) ⊗ Harm^j_{L²}(X);
(ii) S_j^Y(α) = 1 ⊗ S_j^X(α), and S_j^Y(α) is of trace class if and only if S_j^X(α) = 0.
Hence the transversal index Ind_t(d_{F_Y}) does not exist: for every α for which some S_j^X(α) ≠ 0 (for Deninger's solenoid: any α with some Φ(2πiν/log q) ≠ 0, by [x-22] Thm 3.1 p. 12), the defining trace is +∞ in absolute value.
*Proof.* (i) Leafwise forms on Y are C(B)-families of leafwise forms on X (the B-direction carries no tangent vectors), and the L²-completion with respect to μ ⊗ ν_X and the fixed leafwise metric is L²(B, μ; A^j_{F,L²}(X)) = L²(B, μ) ⊗ A^j_{F,L²}(X). The formal adjoint is d^†_{F_Y} = 1 ⊗ d^†_F on the algebraic domain. For a densely defined operator D on a separable Hilbert space H, the operator 1 ⊗ D on L²(B, μ; H) with domain the algebraic span of {χ ⊗ h : χ ∈ L²(B, μ), h ∈ dom D} has adjoint (1 ⊗ D)^* = {u ∈ L²(B, μ; H) : u(b) ∈ dom D^* for a.e. b, D^*u(·) ∈ L²(B, μ; H)}, acting pointwise: if ⟨u, (1 ⊗ D)w⟩ = ⟨v, w⟩ for all w in the domain, testing on w = χ ⊗ h gives ∫ χ(b) ⟨u(b), Dh⟩ dμ = ∫ χ(b) ⟨v(b), h⟩ dμ for all χ, hence ⟨u(b), Dh⟩ = ⟨v(b), h⟩ for a.e. b; taking a countable subset of dom D dense for the graph norm and discarding a null set, u(b) ∈ dom D^* with D^*u(b) = v(b) a.e.; the converse inclusion is Fubini. Applying this twice, d̃_{F_Y} = (1 ⊗ d_F^†)^* = 1 ⊗ (d_F^†)^* = 1 ⊗ d̃_F and d̃_{F_Y}^* = 1 ⊗ d̃_F^*, so Harm(Y) = {u : u(b) ∈ ker d̃_F ∩ ker d̃_F^* a.e.} = L²(B, μ) ⊗ Harm(X). (ii) The flow on Y is 1 × φ, so φ_Y^{t*} = 1 ⊗ φ_X^{t*} on L²(B; A_{F,L²}) and the strong integral gives S_j^Y(α) = 1 ⊗ S_j^X(α); trace class fails exactly as in Theorem T1: Tr|1 ⊗ S| = dim L²(B, μ) · Tr|S|. ∎

*Peter–Weyl reading (B a compact group).* L²(B, μ) = ⊕_{χ∈B̂} C χ for abelian B (countably many characters since B is metrizable), and S_j^Y(α) = ⊕_χ S_j^X(α): the type I trace of Y is |B̂| = ∞ copies of the trace of X; every closed orbit γ of X has become the continuum B × γ, and its unweighted contribution is "Σ_{χ∈B̂} 1" times the single-orbit term.

**5.2 Theorem D′ (the flat trace diverges at a non-isolated fixed point).** [novelty: single-check — the phenomenon is surely folklore (degenerate fixed points have no Atiyah–Bott/Guillemin contribution); the statement and proof are given here in full because nothing on disk contains them.] Let U ⊂ R^n be open, P: U → R^n of class C¹, and k ∈ U a fixed point of P that is an accumulation point of Fix(P) (in particular, any point of a Cantor set of fixed points). Let ρ ≥ 0 be a bounded compactly supported function on R^n with ρ ≥ c > 0 on a ball B(0, r_0), and ρ_ε(x) := ε^{−n} ρ(x/ε). Then
   ∫_U ρ_ε(x − P(x)) dx → +∞ as ε ↓ 0,
i.e. the flat-trace regularization "∫ δ(x − P(x)) dx" of Tr(P^*) diverges (for transversal fixed points it converges to Σ 1/|det(1 − dP)|, the Atiyah–Bott/Guillemin value quoted in [Lei07] pp. 3–4).
*Proof.* Put g(x) := x − P(x) ∈ C¹(U; R^n); g(k) = 0. Choose fixed points k_j → k, k_j ≠ k, and pass to a subsequence with (k_j − k)/|k_j − k| → v, |v| = 1. From 0 = g(k_j) = g(k) + dg(k)(k_j − k) + o(|k_j − k|) we get dg(k)v = 0.
