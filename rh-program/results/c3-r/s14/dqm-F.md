## 0. VERDICT (stated first)

**PARTIAL — decomposing into three decided sub-parts and one reduction. Bottom line for the program: Road 2 (Haar-average the packet) is CLOSED as a route to S4's count; the object DQ-M names computes a Lefschetz index, not a Haar mass.**

Precisely, in the model world (compact metrizable substrates; continuous flows; [Den05]-§7 suspensions; the traces of [x-22] Thm 2.1/3.1, [Den05] Thm 5.3/7.8, [ALKL] Thm 1.3.10, [Lei07] Thm 2):

1. **THEOREM (NO) — the leafwise-cohomology trace does not Haar-average packets.** For every suspension Y = M ×_h R of a diffeomorphism h of a closed manifold M ([Den05] §7.7 with M̄ = M), the trace of φ^* on the leafwise cohomology H̄^•_F(Y) EXISTS with no non-degeneracy hypothesis at all, and
   Σ_j (−1)^j Tr(φ^* | H̄^j_F(Y)) = Σ_{k∈Z} L(h^k) δ_k, L(h^k) the Lefschetz number (Theorem L, §6.3, full proof).
   In the explicit model of §6.4 — M = T², h the time-one map of the vector field f·∂_x with f ≥ 0 vanishing exactly on a Cantor set C that meets every horizontal circle — the periodic set of the flow is exactly the continuum C × S¹ of closed orbits of common length 1, every one of them maximally degenerate (dh^k = id on C), and its contribution at every t = k ≠ 0 is L(h^k) = χ(T²) = 0. The Haar-averaged prescription ∫_C (single-orbit term) dμ = μ(C)·δ_k = δ_k is therefore NOT the orbital side of the leafwise trace, for every Cantor-group structure and every probability measure on C. What replaces the per-orbit term ℓ ε_γ(k) δ_{kℓ} of [ALKL]/[Den05] for a packet is ℓ · ind(P^k, base) · δ_{kℓ}: the fixed-point index of the packet base under the leafwise return map — an integer, insensitive to any measure on the base (§7). Inside the [Den05]-§7.7 class this is the only configuration a packet can have: closed orbits of a §7.7 suspension are in bijection with the finite orbits of f on the manifold M ([Den05] p. 35), so a packet base always lies in the leaf direction (Proposition 6.2); a Cantor base transverse to the leaves can only be manufactured as a product with an external Cantor factor (Lemma 6.1, from [Den05] p. 29).

2. **THEOREM (NO) — the unweighted (type I) trace of a packet diverges.** If the packet base sits transverse to the leaves (products B × X, B a Cantor group), Hörmander's transversal index in the form used by [x-22] Thm 2.1/3.1 does not exist: S_j(α) = 1 ⊗ S_j^X(α) is never trace class when S_j^X(α) ≠ 0 (Theorem D, §5.1). The Guillemin flat-trace regularization diverges at every accumulation point of a fixed set of a C¹ return map — a fortiori at a Cantor fixed set — (Theorem D′, §5.2), and for suspensions the flow's flat trace at t = k is the flat trace of h^k (Corollary D″). The "per-orbit term" of a packet in a type I trace is ∞ × (single-orbit term). Its finite regularizations are not unique: on the §6.4 model the Lefschetz/perturbative value is 0, the Haar/measured value is 1, the unweighted value is +∞ (Proposition R, §6.5).

3. **CONSTRUCTION (YES) — the measured (type II) trace exists, with exactly the Haar identity DQ-M asks for, but it is the wrong object.** For every fixed-point-free continuous flow on a compact metric space with a finite invariant Borel measure ν, the orbit-lamination transverse-measure trace T_ν is a positive Radon measure on R with
   T_ν = ν(Y) δ_0 + Σ_{k≠0} (m_k)_* σ, σ the period measure (Theorem M, §4), and a packet B × R/ℓZ with ν = μ ⊗ ds contributes ∫_B (ℓ Σ_{k≠0} δ_{kℓ}) dμ = ℓ μ(B) Σ_{k≠0} δ_{kℓ}. H4 is replaced by nothing. In the trivial model B × R/ℓZ both sides are computed (leafwise heat operator, Poisson summation; Theorems T1–T3, §3). **But** (Theorem N, §4.3): (a) Σ_ℓ (packet masses) ≤ ν(Y) < ∞, so Haar *probability* on every packet is impossible on a compact substrate (Σ_p log p = ∞); (b) T_ν has mass ≤ (1 + 1/ℓ_min) ν(Y) on every unit interval while the explicit formula's prime side has mass ≥ log p on [⌊log p⌋, ⌊log p⌋+1] — no reweighting reaches it; (c) T_ν is even in t, the prime side is not (weights p^k for k ≤ −1, [x-22] (1)); (d) T_ν is blind to ν-null orbits (Theorem M(v)), i.e. to every isolated orbit of an absolutely continuous invariant measure. The infinite-measure regime has an infinite δ_0-coefficient and no trace-class operator; on the periodic part it yields only the "union of circles" identity Σ_p Σ_ν e^{2πiνt/log p}, with no zeros in it (§4.4).

4. **REDUCTION — the mixed trace is Fubini over selections.** The only trace that assigns μ(B) × (single-orbit term with the correct k ≤ −1 weights) to a packet is a mixed trace: type II in a globally split-off base direction, type I elsewhere. It exists on products, τ = μ(B) · Ind_t(X) (Theorem P, §5.3), and in general is by definition an integral over a measured family of type-I slices, each of which must meet each packet in an isolated set of orbits (Proposition F, §8.2). Road 2 in this form is a Haar average over a family of one-orbit-per-packet substrates — a family of Q-a objects, no easier than Q-a.

**Consequence for Q* (task item 3, §8):** the re-scoped clause "meeting each packet in a Haar-measured orbit family" is (i) unsatisfiable for any finite invariant transverse measure on a compact substrate, (ii) meaningless for the leafwise Lefschetz trace, whose packet term is an index, and (iii) equivalent, in the mixed reading, to Q-a for μ-almost every slice. **Road 2 is closed.** The correct re-scoping of S4's counting demand inside the [Den05]/[ALKL] framework is topological, not measure-theoretic: **each packet must be a compact isolated fixed set of the leafwise return map with fixed-point index 1 for every iterate** (§8.3) — which is Deninger's own printed device for degenerate orbits, "a Ruelle zeta function via Fuller indices" ([x-18] p. 8; [x-19] p. 10), made precise; its first obstacle is that the index needs a leafwise manifold structure around the packet base, which X₀ lacks (ledger W6). Nothing here fires the C3 kill-criterion (S4's mapping face Q-b is untouched; the packet-count obstruction is re-expressed, not removed).

## 2. The three traces, defined — and the model world

DQ-M's phrase "the distributional trace of the flow on leafwise forms" names, in the sources, three inequivalent constructions. The answer splits along this line, so the definitions are fixed first.

**2.1 The model world.** A *foliated space* with d-dimensional leaves is a separable metrizable space with charts U_i ≅ F_i × T_i, F_i ⊂ R^d open, transitions (x, y) ↦ (f_{ij}(x, y), g_{ij}(y)) with all D_x^α f_{ij} continuous in (x, y); a *(generalized) solenoid* of dimension a is a space locally homeomorphic to L_i × T_i with T_i totally disconnected, and then the transition condition is automatic because "continuous functions from connected subsets of R^a into a totally disconnected space are constant" ([Den05] §7.1, pp. 28–29). A codimension-one foliation F inside an a-dimensional solenoid (X, L) is a second foliated-space structure with (a − 1)-dimensional leaves refining L; a flow is a continuous R-action, smooth on L-leaves, F-compatible if it maps F-leaves to F-leaves ([Den05] §7.2–7.3, pp. 29–30). The suspension model ([Den05] §7.7, pp. 34–35): M̄ compact with a leafwise-smooth homeomorphism f̄ (in §7.7, M̄ = lim(… → M → M) for an unramified self-covering f of a closed connected manifold M, and f̄ the shift), Λ = lZ acting on M̄ × R by (m, t)·λ = (f̄^{−λ/l}(m), t + λ), X = M̄ ×_Λ R, F-leaves the images of the leaves of M̄ × {t}, flow φ^t[m, t′] = [m, t + t′] — transverse to F, no fixed points. Its closed orbits are in bijection with the finite orbits of f̄, hence with those of f on M, with l(γ) = |γ_M| l ([Den05] p. 35).

The *packet configuration* DQ-M posits: a compact substrate Y whose periodic set contains a continuum P ≅ B × R/ℓZ of closed orbits of common minimal period ℓ, B a Cantor group (compact, metrizable, totally disconnected, perfect) with Haar probability measure μ, the flow acting on P as rotation on the second factor. Two geometric positions of B relative to the F-leaves are possible: **transverse to F** (B a transversal factor; realized by products B × X, §5) or **inside the F-leaves** (B a Cantor set in a leaf, fixed pointwise by the leafwise return map; realized by suspensions, §6). Inside the [Den05] §7.7 class only the second occurs (Proposition 6.2); the first is the configuration of the "adelic solenoid first" suggestion and of any Cantor-group extension of a connected flow (Lemma 6.1).

**2.2 Trace (I): the Hörmander/Guillemin/Lefschetz trace on leafwise forms (type I).** The object of [x-22] Thm 2.1/3.1, [Den05] Thm 5.3/7.8, [Lei07] Thm 2, and — with its renormalizations — [ALKL] Thm 1.3.10. Ingredients: the leafwise de Rham complex (A^•_F(X), d_F) (forms smooth along F-leaves, continuous transversally: [Den05] §7.2 p. 29); a φ-invariant measure and a leafwise metric making A^•_{F,L²}(X) a Hilbert space; the weak closure d̃_F; Harm^j_{L²}(X) = Ker d̃_F ∩ Ker d̃_F^* (or, on the cohomological side, the Hilbert completion Ĥ^j of the reduced leafwise cohomology H̄^j_F, [Den05] §5.2 p. 21); and for α ∈ C_c^∞(R) the operator S_j(α) = ∫ α(t) φ^{t*} dt on it. The trace *exists* when S_j(α) is of trace class for every α, and then T_j(α) := Tr S_j(α) is a distribution, Ind_t := Σ_j (−1)^j T_j ([x-22] Thm 2.1 p. 5, Thm 3.1 p. 12; [Den05] Thm 5.3 p. 22: "the operator A_ϕ … is of trace class"). The trace is a **Hilbert-space trace**: no transverse measure weights the sum over orbits; a transverse measure enters only through the L²-structure ([x-22] p. 10: μ_ξ inside μ̃; [Lei07] p. 17: the scalar product via the Ruelle–Sullivan current of Λ = μ_L dx, "TR denotes the (usual) trace of trace class operators", p. 3). Its orbital side, whenever proved, has the Lefschetz shape ℓ(γ) Σ_k ε_γ(k) δ_{kℓ(γ)} (with the α-twisted weights on k ≤ −1 in the solenoidal case, [Den05] Thm 7.8; [x-22] Cor. 3.4) and a δ_0-coefficient χ_Co(F, μ). The **hypothesis H4** (ledger §2): closed orbits simple — the leafwise return map has no eigenvalue 1 ([ALKL] §4.1.1 p. 99; [Den05] Thm 5.3 p. 22, 7.5 p. 30, 7.8 p. 35; [x-22] Thm 2.2 p. 6; [Lei07] Thm 2 p. 17; [ALKM] (A1) p. 4). Under H4 the closed orbits are isolated, C_I(φ) is finite for compact I, and the period set is discrete ([ALKL] p. 99; [ALKM] p. 4: "which implies that P is a countable set"). The manifold version of the same trace with the flat-trace (Schwartz-kernel-on-the-diagonal) regularization is Guillemin's, quoted in [Lei07] pp. 3–4 as the Guillemin–Sternberg contribution ℓ(γ) α(±kℓ(γ)) Σ_j (−1)^j Tr(Dφ^{±kℓ})^*|Λ^j T^*_yF / |det(id − Dφ^{±kℓ}|T_yF)|.

**2.3 Trace (II): the transverse-measure trace along the orbit lamination (type II).** Let G be the partition of Y into flow orbits and ν a finite φ-invariant Borel measure (equivalently, a holonomy-invariant transverse measure for G when G is a lamination). For f ∈ C_c(R) the operator φ^f = ∫ f(t) φ^{t*} dt acts on each orbit by convolution along the orbit; its orbitwise Schwartz kernel has a well-defined diagonal value F_f(y) = Σ_{t ∈ Per(y)} f(t), and the type II trace is T_ν(f) := ∫_Y F_f dν (Definition 4.3 below). This is the trace of the von Neumann algebra of the measured lamination (Y, G, ν) evaluated on the leafwise operator φ^f — the trace [Lei07] Prop. 2 p. 16 constructs from the Haar transverse measure for the *surface* lamination (there used to identify the type of W(S, F) ⋊ R as III_{1/q}, **not** for the trace formula, which is type I: [Lei07] Thm 2 p. 17 uses TR). Here it is applied to the *orbit* lamination, where the flow operators are leafwise. No non-degeneracy, no isolation, no smoothness is required: H4 is replaced by ν-measurability. What is given up is recorded in Theorem N.

**2.4 Trace (III): the mixed trace.** A measured decomposition of Y into flow-invariant slices {Y_b}_{b∈Z} with a measure μ on the slice space Z, and a type I trace Tr_b on μ-a.e. slice; τ(f) := ∫_Z Tr_b(φ^f) dμ(b). On a product Y = B × X with slices {b} × X this is the trace of the von Neumann algebra L^∞(B, μ) ⊗̄ B(H) with the trace ∫ dμ ⊗ Tr (Theorem P). It is the only one of the three that returns, for a packet, "μ(B) times the single-orbit term with the [Den05]/[x-22] weights".

**2.5 The single-orbit term, for reference.** For an isolated closed orbit γ of length ℓ transverse to F with leafwise return map P = T_xφ^{ℓ}|T_xF: contribution ℓ Σ_{k≠0} ε_γ(k) δ_{kℓ}, ε_γ(k) = sgn det(1 − P^k) ([x-22] Thm 2.2 p. 6; [Den05] (23) p. 22; [ALKL] Thm 1.3.10 p. 8), with the k ≤ −1 weights ε_γ(|k|) det(−T_xφ^{kℓ}|T_xF) in the solenoidal case ([Den05] Thm 7.8 p. 35) and e^{kℓ(γ)} in the CM example ([x-22] Cor. 3.4 p. 18). The arithmetic target: coefficient 1 on log p · δ_{k log p} for every prime and every k ≥ 1 (ledger T1), p^k on k ≤ −1 (T2). If dim F = 0 (leaves are points), ε ≡ 1 and the term is ℓ Σ_{k≠0} δ_{kℓ}; this is the "single-orbit contribution" of DQ-M's trivial model.

## 3. The trivial model Y = B × R/ℓZ — the honest computation (task item 1)

Throughout §3: B a compact metrizable totally disconnected space with a finite Borel measure μ whose support is infinite (Haar measure of an infinite compact group qualifies: it has full support and B is infinite); S¹_ℓ := R/ℓZ; Y := B × S¹_ℓ with the flow φ^t(b, s) = (b, s + t). Every orbit is closed of minimal period ℓ; the periodic set is all of Y; Λ = Z acts trivially on M̄ = B and Y = B ×_Z R with the §7.7 conventions. Two foliations are relevant: **G**, the foliation by orbits {b} × S¹_ℓ (leaves circles, transversal B); and **F₀**, the [Den05]-§7.7 codimension-one foliation, whose leaves are the images of the leaves of M̄ × {t} — since M̄ = B is 0-dimensional, the F₀-leaves are the points of Y, dim F₀ = 0, and A^•_{F₀}(Y) = C(Y) in degree 0 only. The flow is transverse to F₀, and the single-orbit term for F₀ is ℓ Σ_{k≠0} δ_{kℓ} (§2.5).

**Notation.** For f ∈ C_c^∞(R) put Φ(z) := ∫_R e^{tz} f(t) dt (entire), and note Φ(2πin/ℓ) = ℓ · ĝ(−n) for g(τ) := f(ℓτ), where ĝ(ξ) = ∫ e^{−2πiξτ} g(τ) dτ. **Poisson summation** — Σ_{n∈Z} ĝ(n) = Σ_{k∈Z} g(k) for g ∈ C_c^∞(R) — is used in the exact form Deninger uses it ([x-22] p. 23, "the Poisson summation formula asserts that Σ ψ(n) = Σ ψ̂(n)") [classical; proof: the 1-periodization Σ_k g(τ + k) is smooth and its Fourier series converges at τ = 0]. Hence

   (3.0) Σ_{n∈Z} Φ(2πin/ℓ) = ℓ Σ_{k∈Z} f(kℓ).

**3.1 The G-reading: leafwise circles, leafwise Laplacian, heat operator.** Leafwise forms along G: A^0_G(Y) = C(B; C^∞(S¹_ℓ)), A^1_G(Y) = C(B; C^∞(S¹_ℓ)) ds, d_G a = ∂_s a ds. With the flat metric on each circle, the leafwise Laplacian is Δ = −∂_s² on both degrees, and the leafwise heat operator e^{−uΔ} acts on each circle by the periodic heat kernel. L²-completion with respect to μ ⊗ ds: L²(Y) = L²(B, μ) ⊗ L²(S¹_ℓ), on which φ^{t*} = 1 ⊗ R_t, (R_t a)(s) = a(s + t). Let e_n(s) := ℓ^{−1/2} e^{2πins/ℓ} (n ∈ Z), an orthonormal basis of L²(S¹_ℓ); R_t e_n = e^{2πint/ℓ} e_n and Δ e_n = (2πn/ℓ)² e_n. For u ∈ [0, ∞] and f ∈ C_c^∞(R),

   P_{u,f} := ∫_R f(t) φ^{t*} e^{−uΔ} dt = 1 ⊗ K_{u,f}, K_{u,f} e_n = e^{−u(2πn/ℓ)²} Φ(2πin/ℓ) e_n,

with e^{−∞Δ} := the projection to ker Δ = span(e_0) (this is [ALKL] (1.2.4) p. 2 in the trivial model). K_{u,f} is trace class on L²(S¹_ℓ) for every u ∈ [0, ∞] (|Φ(2πin/ℓ)| = ℓ|ĝ(−n)| is rapidly decreasing), with

   Tr K_{u,f} = Σ_{n∈Z} e^{−u(2πn/ℓ)²} Φ(2πin/ℓ), Tr K_{0,f} = ℓ Σ_{k∈Z} f(kℓ) by (3.0), Tr K_{∞,f} = Φ(0) = ∫ f.

**Theorem T1 (type I: the trace does not exist).** For every u ∈ [0, ∞] and every f with K_{u,f} ≠ 0 (i.e. some e^{−u(2πn/ℓ)²}Φ(2πin/ℓ) ≠ 0), the operator P_{u,f} = 1 ⊗ K_{u,f} on L²(B, μ) ⊗ L²(S¹_ℓ) is **not** of trace class; in particular Hörmander's transversal index ([x-22] Thm 2.1 p. 5) and Deninger's Tr(φ^* | H̄^•) ([Den05] Thm 5.3 p. 22) do not exist for Y in either reading (G or F₀).
*Proof.* Polar decomposition: |1 ⊗ K| = 1 ⊗ |K| (since (1 ⊗ K)^*(1 ⊗ K) = 1 ⊗ K^*K and the square root is taken factorwise). For an orthonormal basis {χ_i} of L²(B, μ) and {e_n} of L²(S¹_ℓ), Tr(1 ⊗ |K|) = Σ_i Σ_n ⟨(1 ⊗ |K|)(χ_i ⊗ e_n), χ_i ⊗ e_n⟩ = Σ_i Σ_n ⟨|K| e_n, e_n⟩ = dim L²(B, μ) · Tr|K|. Since supp μ is infinite, L²(B, μ) is infinite-dimensional (infinitely many disjoint open sets of positive measure give infinitely many orthogonal nonzero indicator functions), and Tr|K| > 0 because K ≠ 0. Hence Tr|1 ⊗ K| = ∞. In the F₀-reading the leafwise complex is C(Y) in degree 0, Harm^0_{L²} = L²(Y), and S_0(f) = ∫ f(t) φ^{t*} dt = 1 ⊗ K_{0,f}: the same operator. In the G-reading, ker(d̃_G) ∩ ker(d̃_G^*) in degree 0 is L²(B, μ) ⊗ span(e_0) and S_0(f) restricted to it is 1 ⊗ K_{∞,f} = Φ(0)·1, not trace class for Φ(0) ≠ 0; in degree 1 likewise. ∎

*Reading.* The whole failure is the factor dim L²(B, μ) = ∞ — the trace of the identity on the functions on the packet base. There is no leafwise ellipticity and no flow transversality in the B-direction to produce decay, and no Hilbert-space trace can be finite there. This is precisely the mechanism Leichtnam names for his p-adic transversal ([Lei07] p. 4: the operator "does not involve any regularizing process along the p-adic transversal Z_p^m. Therefore, unless Assumption (iv) is satisfied we see no reason why … should be trace class") — his Assumption (iv) forces the harmonic forms to be locally constant transversally, i.e. it forces the transversal contribution to be finite-dimensional, which is exactly what a packet base with infinitely many orbits violates.

**Theorem T2 (type II: the μ-trace exists and gives the Haar identity).** Define, for a decomposable operator A = ∫^⊕_B A_b dμ(b) on L²(B, μ) ⊗ L²(S¹_ℓ) = L²(B, μ; L²(S¹_ℓ)) with A_b of trace class and ∫ ‖A_b‖_1 dμ < ∞, the μ-trace τ_μ(A) := ∫_B Tr(A_b) dμ(b). (For A = 1 ⊗ K this is the trace of the von Neumann algebra L^∞(B, μ) ⊗̄ B(L²(S¹_ℓ)) with the trace ∫ dμ ⊗ Tr; for a leafwise operator with continuous kernel k(b; s, s′) it equals ∫_B ∫_{S¹_ℓ} k(b; s, s) ds dμ(b), the transverse-measure trace of the measured lamination (Y, G, μ).) Then for every u ∈ [0, ∞] and f ∈ C_c^∞(R):

   τ_μ(P_{u,f}) = μ(B) Σ_{n∈Z} e^{−u(2πn/ℓ)²} Φ(2πin/ℓ);   lim_{u↓0} τ_μ(P_{u,f}) = τ_μ(P_{0,f}) = μ(B) · ℓ Σ_{k∈Z} f(kℓ) = ∫_B ( ℓ Σ_{k∈Z} f(kℓ) ) dμ(b).

As distributions in t: τ_μ(φ^{t*}) = μ(B) Σ_{n∈Z} e^{2πint/ℓ} = μ(B) ℓ Σ_{k∈Z} δ_{kℓ} — the spectral side (the rotation spectrum {2πin/ℓ} with multiplicity μ(B)) equals the orbital side (the single-orbit term ℓ Σ_k δ_{kℓ} times μ(B)), an identity of distributions on R; for μ a probability measure the packet contributes exactly the single-orbit term. On leafwise 1-forms the same trace results, so the G-Lefschetz supertrace is τ_μ(P^{(0)}_{u,f}) − τ_μ(P^{(1)}_{u,f}) = 0 = χ(S¹) · μ(B) for every u — the [ALKL] (1.2.4) u-independence of the supertrace, here trivially; the non-super trace is u-dependent (u = ∞ gives μ(B) ∫ f, u = 0 gives the orbit sum), which is why only the supertrace carries orbit information in the G-reading, while in the F₀-reading (degree 0 only) the trace itself is the orbit sum.
*Proof.* A = 1 ⊗ K_{u,f} is decomposable with A_b = K_{u,f} for all b, so τ_μ(A) = μ(B) Tr K_{u,f}; the limit u ↓ 0 is dominated convergence against Σ_n |Φ(2πin/ℓ)| < ∞; (3.0) gives the orbit form; the distribution identity Σ_n e^{2πint/ℓ} = ℓ Σ_k δ_{kℓ} is (3.0) read against test functions. ∎

**Theorem T3 (the function spaces and the notion of trace, stated precisely).** *Space side:* L²(Y, μ ⊗ ds) (or the continuous functions C(Y), whose L²-completion it is); leafwise forms along G smooth on circles, continuous in b. *Test side:* C_c(R) suffices — τ_μ(P_{0,f}) = μ(B) Σ_{k} ℓ f(kℓ) is a Radon measure in f of order 0, |τ_μ(P_{0,f})| ≤ μ(B) ℓ (1 + 2R/ℓ) ‖f‖_∞ for supp f ⊂ [−R, R]. *Notion:* the transverse-measure trace τ_μ of the measured orbit lamination (Y, G, μ), i.e. type II in the base direction, evaluated on the leafwise operators P_{u,f}; hypothesis H4 of [ALKL] is replaced by: nothing (the base is not required to be isolated, and no return map is linearized), at the price that the weighting is external — τ_μ depends on μ, and μ is not determined by the dynamics (every finite Borel measure on B gives a flow-invariant measure μ ⊗ ds on Y, and each gives a different τ_μ, all of the form μ(B) × the same distribution). What Theorem T2 establishes is exactly DQ-M's item (1): existence, and orbital side = ∫_B (single-orbit term) dμ = single-orbit term when μ(B) = 1. What Theorem T1 establishes is that this is **not** the [x-22]/[Den05]/[ALKL]/[Lei07] trace, which does not exist on Y.

**Remark 3.4 (the Cantor group structure is invisible).** Nothing in §3 used the group law on B; the flow fixes every point of B, and the only role of "Haar" is to single out one probability measure among uncountably many. In X₀ the group law on B_p = Ẑ×_(p)/p^Ẑ is what makes Haar canonical and Aut(C)-equivariant (9.4 note §7 Road 2, Lemma D(iii)); in the model world that canonicity is an input, not something any trace produces.

## 4. The measured trace in general: existence (Theorem M) and its arithmetic reach (Theorem N)

**Standing hypotheses for §4.** (Y, d) a compact metric space; φ: R × Y → Y a continuous flow with no fixed points; ν a finite φ-invariant Borel measure on Y. No lamination structure, no smoothness, no isolation of orbits is assumed.

**Lemma 4.1 (period gap).** There is ℓ_min > 0 such that every periodic point has minimal period ≥ ℓ_min.
*Proof.* Otherwise there are y_n ∈ Y and periods 0 < t_n → 0 with φ^{t_n} y_n = y_n; pass to a subsequence y_n → y. Fix t ∈ R and write t = m_n t_n + r_n with m_n ∈ Z, 0 ≤ r_n < t_n; then φ^t y_n = φ^{r_n} y_n. Hence d(φ^t y, y) ≤ d(φ^t y, φ^t y_n) + d(φ^{r_n} y_n, y_n) + d(y_n, y). The first and third terms → 0 (continuity of φ^t; y_n → y). For the second, ω(r) := sup_{z∈Y} d(φ^r z, z) is continuous on [0, 1] (φ is uniformly continuous on [0,1] × Y by compactness) with ω(0) = 0, so d(φ^{r_n} y_n, y_n) ≤ ω(r_n) → 0. Thus φ^t y = y for all t: a fixed point, contradiction. ∎

**Lemma 4.2 (measurability).** For y ∈ Y let Per(y) := {t ∈ R : φ^t y = y}, a closed subgroup of R different from R; hence Per(y) = ℓ_y Z with ℓ_y ∈ [ℓ_min, ∞), or Per(y) = {0}, in which case we write ℓ_y = ∞. The function y ↦ ℓ_y is lower semicontinuous, hence Borel; the sets Y_per := {ℓ_y < ∞} and Y_ℓ := {ℓ_y = ℓ} are Borel and φ-invariant.
*Proof.* For T ≥ ℓ_min, C_T := {y : ∃ t ∈ [ℓ_min, T] with φ^t y = y} is the projection to Y of the closed subset {(t, y) ∈ [ℓ_min, T] × Y : φ^t y = y} of a compact space, hence compact. And {ℓ_y ≤ T} = C_T: if ℓ_y ≤ T then ℓ_y ∈ [ℓ_min, T] is a period; conversely a period t ∈ [ℓ_min, T] is a positive multiple of ℓ_y, so ℓ_y ≤ T. Sublevel sets closed ⇒ lower semicontinuous ⇒ Borel. Y_ℓ = {ℓ_y ≤ ℓ} ∖ ∪_m {ℓ_y ≤ ℓ − 1/m}. Invariance is clear. ∎

**Definition 4.3 (orbitwise diagonal; the measured trace).** For f ∈ C_c(R) with supp f ⊂ [−R, R] set F_f(y) := Σ_{t ∈ Per(y)} f(t) = Σ_{k∈Z} f(kℓ_y) (only the term k = 0 if ℓ_y = ∞). F_f is Borel and |F_f| ≤ (1 + 2R/ℓ_min) ‖f‖_∞. Define T_ν(f) := ∫_Y F_f dν. The name: on an orbit through y, identified with R/Per(y) with its Lebesgue coordinate s, the operator φ^f = ∫ f(t) φ^{t*} dt acts by (φ^f a)(s) = ∫ f(t) a(s + t) dt = ∫ k_y(s, s′) a(s′) ds′ with k_y(s, s′) = Σ_{t∈Per(y)} f(s′ − s + t); its diagonal value k_y(s, s) = F_f(y) is constant along the orbit. T_ν integrates this diagonal against ν: it is the transverse-measure trace of the leafwise operator φ^f on the measured orbit lamination, and on a product packet B × S¹_ℓ with ν = μ ⊗ ds it is the τ_μ of Theorem T2.

**Definition 4.4 (period measure).** σ := (ℓ_·)_*(ν|_{Y_per}), a finite Borel measure on [ℓ_min, ∞) with σ([ℓ_min, ∞)) = ν(Y_per) ≤ ν(Y). For k ∈ Z∖{0} let m_k: ℓ ↦ kℓ.

**Theorem M (measured trace formula for continuous flows).** [novelty: single-check — the statement is likely folklore in measured-lamination/flow-Lefschetz form; no source on disk contains it.]
(i) T_ν is a positive Radon measure on R, and as measures
   T_ν = ν(Y) δ_0 + Σ_{k∈Z∖0} (m_k)_* σ.
(ii) For every interval [T, T + 1] with T > 0: T_ν([T, T+1]) ≤ (1 + 1/ℓ_min) ν(Y); and T_ν([−T, T]) ≤ (1 + 2T/ℓ_min) ν(Y).
(iii) (packets) If P ⊂ Y_ℓ is a φ-invariant Borel set with a Borel isomorphism P ≅ B × R/ℓZ conjugating the flow to rotation in the second factor and carrying ν|_P to μ ⊗ ds for a finite Borel measure μ on B, then σ has the atom ℓ μ(B) at ℓ from P, and P contributes to T_ν the term
   ℓ μ(B) Σ_{k≠0} δ_{kℓ} = ∫_B ( ℓ Σ_{k≠0} δ_{kℓ} ) dμ(b).
(iv) T_ν is even: T_ν(f̌) = T_ν(f) for f̌(t) = f(−t).
(v) T_ν does not see periodic orbits of ν-measure zero: if ν(Y_per) = 0 then T_ν = ν(Y) δ_0.
*Proof.* (i) Positivity and the bound |T_ν(f)| ≤ (1 + 2R/ℓ_min)‖f‖_∞ ν(Y) make f ↦ T_ν(f) a positive linear functional on C_c(R) bounded on each C([−R, R]); by the Riesz representation theorem it is a positive Radon measure. For the formula: T_ν(f) = ∫_Y f(0) dν + Σ_{k≠0} ∫_{Y_per} f(kℓ_y) dν(y) (the k-sum has at most 2R/ℓ_min nonzero terms, so it may be exchanged with the integral), and ∫_{Y_per} f(kℓ_y) dν(y) = ∫ f(kℓ) dσ(ℓ) = ∫ f d[(m_k)_*σ] by the change-of-variables formula for the Borel map y ↦ ℓ_y. (ii) For T > 0, T_ν([T, T+1]) = Σ_{k≥1} σ({ℓ : kℓ ∈ [T, T+1]}) = ∫ #{k ≥ 1 : kℓ ∈ [T, T+1]} dσ(ℓ) ≤ ∫ (1 + 1/ℓ) dσ ≤ (1 + 1/ℓ_min) σ([ℓ_min, ∞)) ≤ (1 + 1/ℓ_min) ν(Y); similarly for [−T, T] with the δ_0 mass added. (iii) Under the isomorphism, ℓ_y = ℓ on P and ν(P) = μ(B) · ℓ, so σ ≥ ℓμ(B) δ_ℓ with this atom coming from P, and its image under Σ_{k≠0}(m_k)_* is ℓμ(B) Σ_{k≠0} δ_{kℓ}; the integral form is the identity ∫_B c dμ = c μ(B) for the constant c = ℓ Σ_{k≠0} δ_{kℓ}. (iv) Per(y) = −Per(y). (v) Immediate from (i). ∎

**Remark 4.5 (what H4 bought and what its removal costs).** Theorem M needs no isolation, no non-degeneracy, no linearization, and no leaf structure; it accepts a continuum of periods (σ may have a continuous part, as for a flow on an annulus with continuously varying periods — there T_ν has an absolutely continuous part and no delta terms at all). The costs are (iv) and (v): no sign ε_γ(k), no leafwise Jacobian, no α-twisted weights, and no contribution from an orbit that ν does not charge. In particular for a smooth flow on a manifold with an absolutely continuous invariant measure, every isolated closed orbit is invisible to T_ν, whereas it is the whole content of the type I trace.

**4.3 Theorem N (the measured trace cannot serve T1/T2 on a compact substrate).** [novelty: single-check] Let W := Σ_p log p Σ_{k≥1} δ_{k log p} (the k ≥ 1 part of the prime side of [x-22] (1) p. 1, ledger T1) and W^− := Σ_p log p Σ_{k≤−1} p^k δ_{k log p} (the k ≤ −1 part, ledger T2).
(a) *(finite mass)* Under the hypotheses of §4, if for every prime p the set Y_{log p} contains a packet P_p ≅ B_p × R/(log p)Z with ν|_{P_p} = μ_p ⊗ ds, then Σ_p log p · μ_p(B_p) ≤ ν(Y) < ∞. In particular μ_p(B_p) = 1 for all p — Haar *probability* on every packet, the re-scoped S4 clause — is impossible, since Σ_p log p = ∞ (there are infinitely many primes and each term is ≥ log 2). Any admissible weighting has c_p := μ_p(B_p) → 0 with Σ c_p log p < ∞.
(b) *(growth)* For every (Y, φ, ν) as in §4, T_ν|_{(0,∞)} ≠ W; more strongly, T_ν + ρ_0 ≠ W + ρ_0′ for all measures ρ_0, ρ_0′ supported at {0}. *Proof.* Put C := (1 + 1/ℓ_min) ν(Y). Since the primes are unbounded [classical, Euclid], choose a prime p with log p > max(C, 1) and set T := ⌊log p⌋ ≥ 1. Then T_ν([T, T+1]) ≤ C < log p ≤ W([T, T+1]). ∎
(c) *(parity)* T_ν is even (Theorem M(iv)) while W + W^− is not (its weights are 1 on k ≥ 1 and p^k on k ≤ −1); so even on R∖{0}, and even after any reweighting c_p of packets, no measured trace has the prime side's shape: c_p log p = log p for k ≥ 1 and c_p log p = p^k log p for k ≤ −1 cannot both hold. This is ledger R11 (orbit-weight shape) recurring: the measured trace has leafwise return Jacobian ≡ 1 because it has no leaf direction at all.
(d) *(with fixed points)* If fixed points are allowed (as the archimedean place requires, [Den05] 7.6 (6) p. 33; [x-22] p. 19) and Per(y) = R at a fixed point, define F_f(y) = ∫ f there; then T_ν([T, T+1]) ≤ ν(Fix) + ∫ (1 + 1/ℓ) dσ(ℓ). If the right side is finite, (b) holds with this constant; if ∫ dσ/ℓ = ∞ (periods accumulating at 0 with positive mass), T_ν has infinite mass on every unit interval and is not a Radon measure at all. Either way T_ν ≠ W.

**4.4 The infinite-measure regime (the only residual, and why it is not a road).** Drop finiteness: let ν be a φ-invariant Borel measure that is σ-finite and finite on each Y_ℓ, so that σ is locally finite on [ℓ_min, ∞). Then f ↦ ∫ F_f dν is well defined for f ∈ C_c(R∖{0}) and equals Σ_{k≠0} (m_k)_*σ there; with σ = Σ_p log p δ_{log p} (Haar probability on every packet) this is W + (its mirror with weights 1, not p^k) on R∖{0}. Three facts make this a non-object rather than a trace formula. (i) ν(Y) = ∞, so the δ_0 coefficient is +∞: there is no distribution on R, whereas every trace formula in the sources has a finite δ_0 term (χ_Co(F, μ) in [x-22] Thm 2.2, [Den05] (23), Thm 7.8; ᵇχ in [ALKL] Thm 1.3.10; χ_Λ(F) in [Lei07] Thm 2) and the explicit formula's W_∞ has the finite coefficient α(0) log π ([x-22] p. 1). (ii) No operator φ^f with f ≠ 0 is in the trace ideal of the measured lamination: the positive operator φ^f(φ^f)^* = φ^{f∗f̃} (f̃(t) = \overline{f(−t)}) has, on a packet of length ℓ = log p and base mass 1, trace Σ_{n∈Z} |f̂(n/log p)|² (Theorem T2 with Poisson summation of period ℓ), and Σ_n |f̂(n/ℓ)|² ~ ℓ ‖f‖²_2 → ∞ as ℓ → ∞ by Riemann sums, so the sum over p diverges; hence there is no spectral side. (iii) On a compact Y the packets P_p, being infinitely many disjoint invariant sets, accumulate on a nonempty closed set A, and every neighborhood of A has infinite ν-measure: ν is not locally finite, i.e. not a Radon measure — outside the transverse-measure framework of [Lei07] Prop. 2, of the S2 axiom (A-v), and of Connes' construction. What the periodic part alone does yield is the identity Σ_p Σ_{n∈Z} e^{2πint/log p} = Σ_p log p Σ_{k≠0} δ_{k log p} on R∖{0} — Theorem T2 summed over packets — whose "spectral side" is the rotation spectrum of a disjoint union of circles of lengths log p with multiplicity one each: no zeros of ζ appear, nor could they, since the aperiodic part of Y contributes nothing away from t = 0. This regime therefore fails a printed requirement (finite δ_0), has no spectral side, and its orbital identity is arithmetic-free. It is recorded as the sole residual of the measured reading and is not counted as a road.

## 5. The unweighted trace on a packet transverse to the leaves: divergence, and the product mixed trace

**5.1 Theorem D (products: the Hörmander/Deninger trace does not exist).** [novelty: single-check] Let (X, L, F, φ, ν_X, g) be a compact smooth solenoid with codimension-one foliation, F-compatible flow, φ-invariant measure and leafwise metric, such that Hörmander's construction of §2.2 applies and yields trace-class operators S_j^X(α) on Harm^j_{L²}(X) for all α ∈ C_c^∞(R) — for instance Deninger's generalized solenoid of [x-22] §3 (Theorem 3.1, p. 12), or any §7.7 suspension covered by [Den05] Thm 7.8. Let B be a compact metrizable space with a finite Borel measure μ of infinite support (a Cantor group with Haar measure), and Y := B × X with the product solenoid structure (L_Y-leaves {b} × L, F_Y-leaves {b} × F-leaves, flow 1 × φ, measure μ ⊗ ν_X, the leafwise metric of X). Then:
(i) A^j_{F_Y, L²}(Y) = L²(B, μ) ⊗ A^j_{F, L²}(X), the weak closure is d̃_{F_Y} = 1 ⊗ d̃_F, and Harm^j_{L²}(Y) = L²(B, μ) ⊗ Harm^j_{L²}(X);
(ii) S_j^Y(α) = 1 ⊗ S_j^X(α), and S_j^Y(α) is of trace class if and only if S_j^X(α) = 0.
Hence the transversal index Ind_t(d_{F_Y}) does not exist: for every α for which some S_j^X(α) ≠ 0 (for Deninger's solenoid: any α with some Φ(2πiν/log q) ≠ 0, by [x-22] Thm 3.1 p. 12), the defining trace is +∞ in absolute value.
*Proof.* (i) Leafwise forms on Y are C(B)-families of leafwise forms on X (the B-direction carries no tangent vectors), and the L²-completion with respect to μ ⊗ ν_X and the fixed leafwise metric is L²(B, μ; A^j_{F,L²}(X)) = L²(B, μ) ⊗ A^j_{F,L²}(X). The formal adjoint is d^†_{F_Y} = 1 ⊗ d^†_F on the algebraic domain. For a densely defined operator D on a separable Hilbert space H, the operator 1 ⊗ D on L²(B, μ; H) with domain the algebraic span of {χ ⊗ h : χ ∈ L²(B, μ), h ∈ dom D} has adjoint (1 ⊗ D)^* = {u ∈ L²(B, μ; H) : u(b) ∈ dom D^* for a.e. b, D^*u(·) ∈ L²(B, μ; H)}, acting pointwise: if ⟨u, (1 ⊗ D)w⟩ = ⟨v, w⟩ for all w in the domain, testing on w = χ ⊗ h gives ∫ χ(b) ⟨u(b), Dh⟩ dμ = ∫ χ(b) ⟨v(b), h⟩ dμ for all χ, hence ⟨u(b), Dh⟩ = ⟨v(b), h⟩ for a.e. b; taking a countable subset of dom D dense for the graph norm and discarding a null set, u(b) ∈ dom D^* with D^*u(b) = v(b) a.e.; the converse inclusion is Fubini. Applying this twice, d̃_{F_Y} = (1 ⊗ d_F^†)^* = 1 ⊗ (d_F^†)^* = 1 ⊗ d̃_F and d̃_{F_Y}^* = 1 ⊗ d̃_F^*, so Harm(Y) = {u : u(b) ∈ ker d̃_F ∩ ker d̃_F^* a.e.} = L²(B, μ) ⊗ Harm(X). (ii) The flow on Y is 1 × φ, so φ_Y^{t*} = 1 ⊗ φ_X^{t*} on L²(B; A_{F,L²}) and the strong integral gives S_j^Y(α) = 1 ⊗ S_j^X(α); trace class fails exactly as in Theorem T1: Tr|1 ⊗ S| = dim L²(B, μ) · Tr|S|. ∎

*Peter–Weyl reading (B a compact group).* L²(B, μ) = ⊕_{χ∈B̂} C χ for abelian B (countably many characters since B is metrizable), and S_j^Y(α) = ⊕_χ S_j^X(α): the type I trace of Y is |B̂| = ∞ copies of the trace of X; every closed orbit γ of X has become the continuum B × γ, and its unweighted contribution is "Σ_{χ∈B̂} 1" times the single-orbit term.

**5.2 Theorem D′ (the flat trace diverges at a non-isolated fixed point).** [novelty: single-check — the phenomenon is surely folklore (degenerate fixed points have no Atiyah–Bott/Guillemin contribution); the statement and proof are given here in full because nothing on disk contains them.] Let U ⊂ R^n be open, P: U → R^n of class C¹, and k ∈ U a fixed point of P that is an accumulation point of Fix(P) (in particular, any point of a Cantor set of fixed points). Let ρ ≥ 0 be a bounded compactly supported function on R^n with ρ ≥ c > 0 on a ball B(0, r_0), and ρ_ε(x) := ε^{−n} ρ(x/ε). Then
   ∫_U ρ_ε(x − P(x)) dx → +∞ as ε ↓ 0,
i.e. the flat-trace regularization "∫ δ(x − P(x)) dx" of Tr(P^*) diverges (for transversal fixed points it converges to Σ 1/|det(1 − dP)|, the Atiyah–Bott/Guillemin value quoted in [Lei07] pp. 3–4).
*Proof.* Put g(x) := x − P(x) ∈ C¹(U; R^n); g(k) = 0. Choose fixed points k_j → k, k_j ≠ k, and pass to a subsequence with (k_j − k)/|k_j − k| → v, |v| = 1. From 0 = g(k_j) = g(k) + dg(k)(k_j − k) + o(|k_j − k|) we get dg(k)v = 0. Let δ_0 > 0 with B̄(k, δ_0) ⊂ U and ω(δ) := sup_{|x − k| ≤ δ} ‖dg(x) − dg(k)‖, a nondecreasing continuous function with ω(0) = 0 (uniform continuity of dg on the closed ball). For |s| ≤ δ_0: g(k + sv) = ∫_0^s dg(k + uv) v du = ∫_0^s (dg(k + uv) − dg(k)) v du, so |g(k + sv)| ≤ ω(|s|)|s|. For any w with |sv + w| ≤ δ_0: |g(k + sv + w) − g(k + sv)| ≤ K|w| with K := sup_{B̄(k,δ_0)} ‖dg‖. Hence, for ε small, the set E_ε := {k + sv + w : |s| ≤ δ(ε), w ⊥ v, |w| ≤ r_0 ε/(2K + 1)} satisfies |g(x)| ≤ ω(δ(ε))δ(ε) + r_0 ε/2 on E_ε, where δ(ε) := max{δ ∈ [0, δ_0] : ω(δ)δ ≤ r_0 ε/2} (the set is a closed interval containing 0, since ω(δ)δ is continuous and nondecreasing). By the definition of δ(ε) (the set {δ : ω(δ)δ ≤ r_0ε/2} is closed and contains 0), ω(δ(ε))δ(ε) ≤ r_0 ε/2, so on E_ε we have |g| ≤ r_0ε/2 + K r_0 ε/(2K+1) < r_0 ε, i.e. E_ε ⊂ {ρ_ε(g) ≥ c ε^{−n}} (and E_ε ⊂ B̄(k, δ_0) for ε small). Moreover δ(ε)/ε → ∞: if ω(δ̄) = 0 for some δ̄ > 0 then δ(ε) ≥ δ̄ for all ε; otherwise ω(δ) > 0 for all δ > 0, so δ(ε) → 0, δ(ε) < δ_0 for ε small, and by continuity ω(δ(ε))δ(ε) = r_0 ε/2, whence δ(ε)/ε = r_0/(2ω(δ(ε))) → ∞. Therefore ∫ ρ_ε(g(x)) dx ≥ c ε^{−n} vol(E_ε) = c ε^{−n} · 2δ(ε) · c_{n−1} (r_0 ε/(2K+1))^{n−1} = c′ δ(ε)/ε → ∞. ∎

*Remark.* Only one fixed point with one degenerate direction is needed; every accumulation point of Fix(P) is such a point. The divergence rate is governed by the modulus of continuity of dP along the accumulation direction; for the §6.4 model (dP = id on the Cantor set, P a C^∞ time-one map) it is at least ε^{−1/2}. The result is insensitive to ρ: any two regularizations give +∞. So there is no "value" to be regularized in a ρ-independent way; whatever finite number one assigns to a packet is an external choice (Proposition R).

## 6. The real model: a packet in the leaf direction of a [Den05]-§7.7 suspension (task item 2)

**6.1 Lemma (Cantor-group extensions of connected flows are products).** [novelty: single-check — it is [Den05] p. 29's own remark applied.] Let (Y₀, ψ) be a continuous flow on a connected space, B a totally disconnected topological group, and c: Y₀ × R → B a continuous cocycle (c(y, t + s) = c(y, t) c(ψ^t y, s), c(y, 0) = e). Then c ≡ e, and the skew-product flow φ^t(b, y) = (b · c(y, t), ψ^t y) on B × Y₀ is the product flow 1 × ψ. *Proof.* Y₀ × R is connected and B totally disconnected, so c is constant ([Den05] §7.1, p. 29: "continuous functions from connected subsets of R^a into a totally disconnected space are constant" — the same argument applies to any connected domain: the image is connected, hence a point); c(y, 0) = e forces the constant to be e. ∎
*Consequence.* "A Cantor-group extension of a hyperbolic/linear flow" and "a packet sitting inside the adelic solenoid" (the two ambient suggestions of the 9.4 note §8) are, whenever the ambient is connected and the extension continuous, products B × X — the configuration of §5: type I diverges (Theorem D), the mixed trace exists (Theorem P), and the packet term is Fubini over the slices {b} × X. Deninger's solenoid of [x-22] §3 is connected (its C-leaves are dense, p. 13: V is dense in V_ξΓ), so it admits no nontrivial continuous B-cocycle.

**6.2 Proposition (in the [Den05]-§7.7 class, packet bases lie in the leaves).** [novelty: single-check — a reading of [Den05] p. 35.] In a suspension X = M̄ ×_Λ R of §7.7, the closed orbits are in bijection with the finite orbits of f on the manifold M, with l(γ) = |γ_M| l ([Den05] p. 35, quoted in §1). Hence a continuum of closed orbits of common length nl in X corresponds to a continuum of f-orbits of exact length n in M, i.e. to an infinite compact subset of Fix(f^n) ⊂ M, which is contained in the F-leaf direction (the F-leaves of X are the images of M̃ × {γ} × {t}, p. 35, i.e. copies of M̃). A packet base transverse to F does not occur in the §7.7 class; it arises only by a product with an external factor (Lemma 6.1). This matches the position of B_p in X₀ ("the packet base B_p lies in the leaf direction of X₀", novelty-adjudication R3) and singles out the leafwise configuration as the one to decide.

**6.3 Theorem L (the leafwise-cohomology trace of a suspension, without non-degeneracy).** [novelty: single-check — the statement is the Lefschetz trace formula for mapping tori and is very likely known; [Den05] Thm 7.8 p. 35 states it for M̄ = M under non-degeneracy with the orbital side written through ε_γ(k); nothing on disk states it without that hypothesis. Full proof given.]

*Setting.* M a closed smooth manifold, h ∈ Diff(M), Z acting on M × R by the generator g(x, s) = (h^{−1}(x), s + 1), Y := (M × R)/Z (this is [Den05] §7.7 with M̄ = M, f = h, l = 1), F the foliation by the images of M × {s}, φ^t[x, s] = [x, s + t]. A leafwise j-form on Y is a Z-invariant form ω̃ on M × R along the M-direction, smooth in (x, s) ([Den05] Warning p. 29: on a manifold, smooth transversally); writing ω(s) := ω̃(·, s) ∈ Ω^j(M), invariance g^*ω̃ = ω̃ reads (h^{−1})^*ω(s + 1) = ω(s), i.e.
   A^j_F(Y) ≅ Ω^j_tw := { ω ∈ C^∞(R; Ω^j(M)) : ω(s + 1) = h^*ω(s) },   d_F = d_M pointwise in s,   (φ^{t*}ω)(s) = ω(s + t).
(With continuity in s instead of smoothness — the foliated-space convention — the same proof goes through verbatim with C^0 in place of C^∞.) Fix a Riemannian metric on M and let H, G be the harmonic projection and Green operator of the Hodge decomposition Ω^j(M) = ℋ^j ⊕ dΩ^{j−1} ⊕ d^*Ω^{j+1}, ℋ^j ≅ H^j(M; R) finite-dimensional; a closed form ω is exact iff Hω = 0, in which case ω = d(d^*Gω); H and d^*G are continuous for the C^∞ topology [classical: Hodge theory on closed manifolds; for M = T² it is elementary: in Fourier series, H is the projection onto the constant-coefficient forms and d^*G divides Fourier coefficients by |2πn|², preserving rapid decay]. Let C^∞_tw(R; H^j(M)) := { c ∈ C^∞(R; H^j(M)) : c(s + 1) = h^*c(s) }.

**(L1)** The map [ω] ↦ (s ↦ [ω(s)]) is an isomorphism H^j_F(Y) ≅ C^∞_tw(R; H^j(M)); Im d_F is closed in A^j_F(Y), so the reduced cohomology H̄^j_F(Y) equals H^j_F(Y) and is Hausdorff.
*Proof.* Well-defined and twisted: h^* on forms induces h^* on cohomology. Smooth in s: s ↦ [ω(s)] equals s ↦ Hω(s) under ℋ^j ≅ H^j(M), and H is continuous. Surjective: given c, let η(s) := the harmonic representative of c(s) (smooth in s), choose ψ ∈ C_c^∞(R) with supp ψ ⊂ (−1, 1) and Σ_{j∈Z} ψ(s − j) ≡ 1, and put ω(s) := Σ_j ψ(s − j) (h^j)^* η(s − j) (a locally finite sum of closed forms, smooth in s). Then ω(s + 1) = Σ_j ψ(s + 1 − j)(h^j)^*η(s + 1 − j) = Σ_i ψ(s − i)(h^{i+1})^*η(s − i) = h^*ω(s), and [ω(s)] = Σ_j ψ(s − j)(h^*)^j c(s − j) = Σ_j ψ(s − j) c(s) = c(s), using c(s − j) = (h^*)^{−j}c(s). Kernel = Im d_F: if ω is closed, twisted, and [ω(s)] = 0 for all s, then ω(s) = dβ(s) with β(s) := d^*Gω(s) smooth in s; β̃(s) := Σ_j ψ(s − j)(h^j)^*β(s − j) is twisted by the same computation, and dβ̃(s) = Σ_j ψ(s − j)(h^j)^*ω(s − j) = Σ_j ψ(s − j) ω(s) = ω(s) (ω twisted). Conversely d_F of a twisted form has zero classes. Closedness: Im d_F is the kernel of the continuous linear map ω ↦ (s ↦ Hω(s)) on the Fréchet space of closed twisted forms. ∎

**(L2)** Let V := H^j(M) ⊗ C with any inner product, and Ĥ^j := L²_tw := { c ∈ L²_loc(R; V) : c(s + 1) = h^*c(s) } with ‖c‖² := ∫_0^1 |c(s)|² ds — the Hilbert completion of C^∞_tw(R; H^j(M)); different inner products on V give the same space with equivalent norms, and Deninger's pre-Hilbert structure (15) on H̄^j ([Den05] §5.2 p. 21: the L²-inner product of harmonic representatives with respect to the transverse measure ds) is one of them. The flow acts by (φ^{t*}c)(s) = c(s + t), a strongly continuous group of bounded operators; for ϕ ∈ C_c^∞(R) put A_ϕ := ∫ ϕ(t) φ^{t*} dt. Then **A_ϕ is of trace class on Ĥ^j and**
   Tr(A_ϕ | Ĥ^j) = Σ_{k∈Z} ϕ(k) · tr( (h^*)^k | H^j(M) ).
*Proof.* Choose L ∈ End(V) with e^L = h^* (a logarithm of an invertible matrix exists [classical, Jordan form]). The map J: c ↦ a, a(s) := e^{−sL}c(s), is a bounded operator with bounded inverse from L²_tw onto L²(R/Z; V) (a(s + 1) = e^{−(s+1)L}h^*c(s) = e^{−sL}c(s) = a(s); ‖e^{±sL}‖ is bounded on [0, 1]). It conjugates A_ϕ to (Ã_ϕ a)(s) = e^{−sL} ∫ ϕ(t) e^{(s+t)L} a(s + t) dt = ∫ ϕ(t) e^{tL} a(s + t) dt. In the orthogonal decomposition L²(R/Z; V) = ⊕_{ν∈Z} e^{2πiνs} ⊗ V, Ã_ϕ is block-diagonal: Ã_ϕ(e^{2πiνs} v) = e^{2πiνs} Φ_ν v with Φ_ν := ∫ ϕ(t) e^{2πiνt} e^{tL} dt ∈ End(V). Φ_ν is the Fourier coefficient at −ν of the smooth compactly supported End(V)-valued function t ↦ ϕ(t)e^{tL}, so ‖Φ_ν‖ = O(|ν|^{−N}) for every N (integrate by parts N times). Hence Σ_ν ‖Φ_ν‖_1 ≤ dim V · Σ_ν ‖Φ_ν‖ < ∞: Ã_ϕ is of trace class with Tr Ã_ϕ = Σ_ν tr Φ_ν. Trace class and trace are invariant under conjugation by bounded invertible operators, so A_ϕ is of trace class with the same trace. Finally Σ_ν tr Φ_ν = Σ_ν ∫ ϕ(t) tr(e^{tL}) e^{2πiνt} dt = Σ_ν ĝ(−ν) for g(t) := ϕ(t) tr(e^{tL}) ∈ C_c^∞(R), and Poisson summation (§3, [x-22] p. 23) gives Σ_ν ĝ(−ν) = Σ_k g(k) = Σ_k ϕ(k) tr(e^{kL}) = Σ_k ϕ(k) tr((h^*)^k). ∎

**(L3) Theorem L.** For every closed manifold M and every h ∈ Diff(M), with no hypothesis on the fixed points of the iterates h^k, the Lefschetz supertrace of the flow on the leafwise cohomology of Y = M ×_h R exists and equals, in D′(R),
   Σ_{j=0}^{dim M} (−1)^j Tr(φ^* | H̄^j_F(Y)) = Σ_{k∈Z} L(h^k) δ_k,   L(h^k) := Σ_j (−1)^j tr((h^k)^* | H^j(M; R)).
*Proof.* (L1) + (L2), summed with signs; the trace of a real operator equals that of its complexification. ∎
*Consistency.* (a) When every h^k has only non-degenerate fixed points, the Lefschetz fixed point theorem [classical: Lefschetz–Hopf] gives L(h^k) = Σ_{x∈Fix(h^k)} sgn det(1 − dh^k_x), and grouping the fixed points of h^k into h-orbits of exact period n | k, each orbit of period n contributes n·ε at t = k: this is [Den05] Thm 7.8 p. 35 for M̄ = M, l = 1, with χ_Co(F, μ)·δ_0 = χ(M)·δ_0 = L(h^0)δ_0 — the δ_0 term is the k = 0 Lefschetz number, as Thm 7.8's χ(M)·l says. (b) The k ≤ −1 terms carry L(h^{−|k|}) here, with no Jacobian factor; Thm 7.8's det(−T_xφ^{kℓ}|T_xF) weight concerns the L²-completion built from an α-conformal leafwise metric on a solenoid; for a manifold suspension of a diffeomorphism the two coincide when |det dh| = 1. Not used below. (c) [x-22] Thm 3.1 (p. 12) is the same mechanism in the solenoidal CM case: the spectral side is Fourier modes ⊗ the eigenvalues ξ, ξ̄ of the return map on H¹(E(C)), and the orbital side (Cor. 3.4 p. 18, derived on p. 23) comes from the Lefschetz numbers L([ξ]^n) = |1 − ξ^n|² = card E_0(F_{q^n}).

**6.4 The model: a Cantor packet in the leaf direction, with the leafwise trace computable.** [novelty: single-check]
*Data.* M = T² = R²/Z² with coordinates (x, y). K ⊂ [0, 1] the middle-thirds Cantor set, F: K → [0, 1] the Cantor function restricted to K (continuous, surjective) [classical]. C := { (1/4 + x/2, F(x)) : x ∈ K } ⊂ [1/4, 3/4] × [0, 1] ⊂ T² (the x-coordinates stay inside (0, 1), so the passage to the torus identifies no two points of C). Then: C is compact; x ↦ (1/4 + x/2, F(x)) is a continuous injection of the compact K, hence a homeomorphism onto C, so C is a Cantor set; and π_y(C) = F(K) = [0, 1] = the whole y-circle, so **C meets every horizontal circle {y = y₀}**. Let f: T² → [0, ∞) be smooth with f^{−1}(0) = C [classical: every closed subset of a manifold is the zero set of a smooth nonnegative function — T² ∖ C is a countable union of open balls B_j; take f = Σ_j 2^{−j} ψ_j/(1 + ‖ψ_j‖_{C^j}) with ψ_j ≥ 0 a smooth bump supported in B_j, positive at its center; the series converges in every C^m]. Put V := f·∂_x and h := Fl^1_V, the time-one map of the flow of V (complete, T² compact); h ∈ Diff^∞(T²) and h is isotopic to the identity through Fl^s_V.
*Facts.*
(i) **Fix(h^k) = C for every k ≠ 0.** V vanishes on C, so C ⊂ Fix(h^k). If x₀ = (x, y) ∉ C, its V-trajectory stays on the circle {y}; the set C ∩ {y} is nonempty and consists of stationary points, so by uniqueness the trajectory stays in the open arc of {y} ∖ C containing x₀, where f > 0: its x-coordinate (lifted to R) is a strictly increasing function of time confined to a bounded open interval (the lift of the arc), so it never takes the same value twice and Fl^k_V(x₀) ≠ x₀ for all k ≠ 0.
(ii) **dh^k = id on C** (maximal degeneracy). At a zero x of V, d(Fl^t_V)_x = exp(t·DV(x)) [classical: linearization of a flow at a zero], and DV(x) = df(x) ⊗ ∂_x + f(x)·D(∂_x) = 0, because f ≥ 0 attains its minimum 0 at x ∈ C, so df(x) = 0.
(iii) **h^* = id on H^•(T²; R)**, since h ≃ id [classical: homotopy invariance of de Rham cohomology]; hence L(h^k) = χ(T²) = 0 for all k ∈ Z.
(iv) **Y := T² ×_h R** is a compact connected 3-manifold with the fibration F by tori and a flow transverse to F without fixed points: a [Den05] §7.7 suspension with f = h (a degree-one covering) and l = 1. By (i) and [Den05] p. 35, its closed orbits are the suspensions of the points of C: **the periodic set of (Y, φ) is exactly P := C × S¹ = { [x, s] : x ∈ C }, a continuum of closed orbits of common minimal period 1, on which the flow is rotation**, and the packet base C lies in the F-leaf T² × {0}. C carries Cantor-group structures (every Cantor set is homeomorphic to every other [classical, Brouwer]; transport the group law of Z₂, or of Ẑ×_(p)/p^Ẑ) and their Haar probability measures μ — external data invisible to (Y, φ).
(v) **H4 fails at every orbit of P**: N_pφ ≅ T_xF = T_xT² and φ_*^{k} = dh^k_x = id has eigenvalue 1 (ledger H4; [ALKL] p. 99). None of [Den05] Thm 5.3/7.8, [x-22] Thm 2.2, [ALKL] Thm 1.3.10, [Lei07] Thm 2, [ALKM] (A1) applies.
(vi) **Invariant measures.** Every point x ∉ C is wandering for h: on a small closed ball U around x disjoint from C one has f ≥ f_min > 0, so every V-trajectory crosses U monotonically in the x-direction in time at most diam(U)/f_min and — being confined to the arc of its horizontal circle between consecutive points of C, of which U ∩ {y′} is a sub-interval — never returns to U; hence h^n(U) ∩ U = ∅ for n > diam(U)/f_min. So the non-wandering set of φ is P and every φ-invariant Borel probability measure ν on Y is supported on P [classical: supp ν ⊂ Ω(φ), by Poincaré recurrence]; disintegrating along the projection P → C, the conditional measures on the circles are rotation-invariant, hence Lebesgue, so ν = μ_ν ⊗ ds with μ_ν := (projection)_*ν a probability measure on C [classical: disintegration].

**6.5 Corollary (the leafwise trace assigns the packet its Lefschetz index, 0, not its Haar mass, 1).** [novelty: single-check] On the model Y of 6.4:
(a) By Theorem L and (iii), Σ_j (−1)^j Tr(φ^* | H̄^j_F(Y)) = Σ_{k∈Z} χ(T²) δ_k = 0: the trace of Deninger's Theorem 5.3/7.8 EXISTS — as a trace of trace-class operators on the Hilbert completions of the leafwise cohomologies, which here are H̄^0_F = H̄^2_F = C^∞(R/Z), H̄^1_F = C^∞(R/Z)² — and vanishes identically.
(b) For every k ≠ 0 the period-k set of (Y, φ) is exactly P (fact (i)), so **the total contribution of the packet P at t = k is 0.**
(c) The Haar-averaged prescription of Road 2 / DQ-M assigns P at t = k the value ∫_C (single-orbit term) dμ = μ(C)·1 = 1, for every probability measure μ on C and every Cantor-group structure. **The identity "orbital side = ∫_B (single-orbit contribution) dμ" is false for the leafwise-cohomology trace.**
(d) The value 0 is the fixed-point index of C under h^k: for any C¹-small perturbation h′ of h with finitely many non-degenerate fixed points (which exists by transversality [classical]; nothing below depends on this sentence), Σ_{x∈Fix(h′^k)} sgn det(1 − dh′^k_x) = L(h′^k) = L(h^k) = 0, since h′ ≃ h acts identically on cohomology. Equivalently, the index of C is the Poincaré–Hopf index of f·∂_x near C, which is homotopic through fields nonvanishing on the boundary of a neighborhood to ∂_x, a field without zeros. So the packet's term in the [ALKL]-shaped formula is what the ε-signed orbit terms of nearby non-degenerate flows add up to, and that is a topological index [the local statement is Lefschetz–Hopf, classical; only the global total is used].
(e) By Theorem M and fact (vi), for every invariant probability measure ν on Y, T_ν = δ_0 + μ_ν(C) Σ_{k≠0} δ_k = Σ_{k∈Z} δ_k: the measured trace sees P as a single orbit of length 1 (its spectral side is the rotation spectrum Σ_ν e^{2πiνt} with multiplicity μ_ν(C) = 1), and every choice of μ_ν gives the same answer — the "Haar" choice plays no role.
(f) By Corollary D″, the unweighted flat trace of φ^f diverges at every integer k ≠ 0 with f(k) ≠ 0.

**6.6 Proposition R (regularization dependence).** [novelty: single-check] On the model Y the periodic continuum P receives, at each t = k ≠ 0, three different values from the three frameworks of §2: **0** from the leafwise-cohomology (Lefschetz) trace, from its non-degenerate perturbations, and from any topological index; **μ(C) = 1** from the type II trace with respect to any invariant probability measure (and c for a measure of total mass c); **+∞** from the unweighted type I trace. The frameworks are pairwise inconsistent on P, so "the regularized per-orbit term of an orbit continuum" is not a property of the flow but of the framework; among the three only the Lefschetz value is produced by a spectral side that exists on Y (Corollary 6.5(a)). *Profinite reading.* For a profinite base B = lim B/U_n, the finite-level quotient of a transverse packet, (B/U_n) × S¹_ℓ, has |B/U_n| isolated orbits of length ℓ; the type I count at level n is |B/U_n| × (single-orbit term), and its normalization by |B/U_n| converges to the single-orbit term — the Haar value is the normalized limit of finite-level type I counts (Peter–Weyl: (1/|B/U_n|) Σ_{χ ∈ (B/U_n)^} χ(e) = 1). This realizes Haar regularization as a limit of honest traces only where the whole substrate admits the finite-level quotients — a global compact-group action — and says nothing about the leafwise configuration of 6.4, where the index, not a count, is what the spectral side computes.

*Scope of the model.* The model is a compact connected 3-manifold, so every framework on disk is available on it verbatim (no S2 transplant is needed), and it satisfies DQ-M's specification literally: a [Den05]-§7-type suspension whose periodic set is a continuum B × S¹ of closed orbits of common length, B a Cantor group with Haar measure. What it does not model is X₀'s absence of leaf structure (W6), its non-Hausdorff packets (W12), and the p → ∞ accumulation of packets (Q*); these are not needed to decide DQ-M, which is a question about what a trace assigns to one packet.

## 7. The [ALKL]/[Den05] trace formula's structure, and what replaces the per-orbit term for a packet (task item 2, synthesis)

**7.1 The structure of the formula on disk.** All published versions have the shape
   (spectral side) = (δ_0-term) + Σ_c ℓ(c) Σ_{k∈Z^×} ε_c(k) δ_{kℓ(c)} + (fixed-leaf / fixed-point terms),
with: the spectral side a Hilbert-space trace of trace-class operators built from the flow acting on leafwise (reduced) cohomology or L²-harmonic leafwise forms ([x-22] Thm 2.1 p. 5 and Thm 3.1 p. 12; [Den05] Thm 5.3 p. 22; [Lei07] Thm 2 p. 17 with "TR"; [ALKL] Thm 1.3.7–1.3.10 pp. 6–8 with the b-trace renormalization at preserved leaves); the δ_0-term a Connes–Euler characteristic with respect to a transverse measure of F ([x-22] Thm 2.2 p. 6; [Den05] (23) p. 22 and 7.8 p. 35: χ_Co(F, μ) = χ(M)·l; [ALKL] ᵇχ_{|ω¹|}(F¹); [Lei07] χ_Λ(F)); the per-orbit term ℓ(c) ε_c(k) δ_{kℓ(c)} with ε_c(k) = sgn det(id − φ_*^{kℓ(c)} | N_pφ), N_pφ ≅ T_pF ([ALKL] p. 99; [x-22] p. 6), the k ≤ −1 weights twisted by the leafwise Jacobian in the solenoidal/conformal setting ([Den05] Thm 7.8; [x-22] Cor. 3.4); and the hypothesis H4 that every closed orbit is simple, which makes the closed orbits isolated and their period set discrete ([ALKL] p. 99; [ALKM] p. 4). Two facts about this structure decide DQ-M.

*The orbit term is a Lefschetz index in the leaf direction times the transverse (dt-) measure of the orbit.* The factor ℓ(c) is the length — the Haar measure dt of R restricted to the orbit, i.e. the F-transverse measure of the closed orbit (for the suspension, the transverse measure of Thm 7.8 is ds on R/Λ, and χ_Co = χ(M)·l is "index × transverse mass"). The factor ε_c(k) is the fixed-point index of the leafwise return map at an isolated non-degenerate fixed point. Theorem L makes this exact for suspensions without any hypothesis: the coefficient of δ_k is L(h^k), the global Lefschetz number, which for non-degenerate iterates is the sum of local indices and for a compact isolated fixed set — a packet base — is that set's fixed-point index [Lefschetz–Hopf, classical, for the local decomposition; the global total is Theorem L]. **So the per-orbit term of a packet in the leafwise trace is ℓ · ind(P^k, base) · δ_{kℓ}, an integer-valued topological quantity.** There is no slot in this structure for a measure on the base: the base is in the leaf direction, where the trace is of Lefschetz (type I) kind.

*The Haar-weighted term lives in the transverse (type II) direction only.* A transverse measure enters the formula either as the F-transverse measure (giving ℓ(c) and χ_Co) or, in Theorem M / Theorem P, as a measure on a direction that has been declared transverse to the slices on which a type I trace is taken. To Haar-average a packet is to declare its base a measured transversal; inside a §7.7 suspension the base is leafwise (Proposition 6.2), so this can only be done by re-slicing the space so that the base becomes transverse — which is the product/mixed configuration, i.e. a family of one-orbit-per-packet slices.

**7.2 Answer to "what replaces the per-orbit term when the closed orbits form a continuum with a transverse Haar measure."**
- Leafwise (Lefschetz) trace, base in the leaf direction: the term becomes ℓ · ind(P^k, B) · δ_{kℓ} — exists (Theorem L for suspensions), equals 0 in the natural slowed-flow model (Corollary 6.5), can be any integer for other return maps, and never depends on μ. The Haar identity fails (Corollary 6.5(c)).
- Unweighted type I trace, base transverse: the term becomes ∞ · (single-orbit term) — the trace does not exist (Theorems D, D′, D″; [Lei07] p. 4's mechanism).
- Type II trace along orbits: the term becomes ℓ μ(B) Σ_{k≠0} δ_{kℓ} — exists always (Theorem M), but the framework is even in t, blind to null orbits, and mass-limited (Theorem N); it cannot carry T1 or T2 on a compact substrate, and in the infinite-mass regime it is not a trace (§4.4).
- Mixed trace, base globally split off: the term becomes μ(B) × (single-orbit term with its k ≤ −1 weights) — exists on products (Theorem P) and is by construction a Fubini integral over slices each meeting the packet in one isolated orbit (§8.2).

**7.3 Where the clean-family / measured-fixed-set lineages sit (novelty-adjudication R3).** The Duistermaat–Guillemin "clean" case (families of periodic orbits filling invariant tori; Deninger's simile "reminiscient of invariant tori", [x-03] p. 2) integrates over the family with the *canonical density* that the symplectic/manifold structure of the family provides [RU — not on disk; not used]. A Cantor base has no manifold structure and no canonical density: Theorem D′ shows the type I density diverges, and Proposition R shows that the finite values one can assign are framework choices. The measured-fixed-set lineage (Heitsch–Lazarov; Álvarez López–Kordyukov's Lefschetz distribution of Lie foliations) measures a fixed set *transverse to F* by the holonomy-invariant transverse measure [RU — not on disk; the R3 description is used only as orientation]; in the packet configuration of §7.7 the base is not transverse to F. The common refinement DQ-M asked for — a Cantor–Haar measure on the orbital side of the clean case — does not exist as a property of the flow: in the leafwise configuration the spectral side already determines the packet's coefficient, and it is an index.

## 8. Consequence for Q* and for S4 (task item 3)

**8.1 The re-scoped clause, read three ways.** The 9.4 note proposed to replace Q*'s "meeting each packet in exactly one orbit" by "meeting each packet in a Haar-measured orbit family," and DQ-M was to decide whether a trace formula supports the replacement. The decisions:
(i) *As a measured (type II) trace on a compact substrate with a finite invariant transverse measure:* the clause is unsatisfiable (Theorem N(a): Haar probability on every packet forces Σ_p log p ≤ ν(Y)), and even with summable reweightings the trace has bounded mass per unit interval (N(b)), is even in t (N(c)), and ignores every ν-null orbit (Theorem M(v)). The S2 axiom (A-v) (a Radon invariant transverse measure of full support) and [Lei07] Prop. 2's Haar-induced Λ are of this Radon kind; the infinite-mass alternative is outside every framework and has no spectral side (§4.4).
(ii) *As the leafwise Lefschetz trace (the object of [Den05] Thm 5.3/7.8, [x-22], [ALKL], [Lei07]):* the clause has no meaning. The packet's coefficient is its fixed-point index under the leafwise return map (Theorem L, Corollary 6.5), determined by the spectral side, and equal to 0 in the natural model where Haar would say 1.
(iii) *As a mixed trace:* the clause is equivalent to "μ-almost every slice meets each packet in (on average) exactly one isolated orbit" — Proposition F below — i.e. to a measured family of Q-a-type substrates.
**Road 2 is therefore closed** as a route that dissolves S4's counting demand. It survives only in the product form "Q-a object × Cantor group," which presupposes the Q-a object.

**8.2 Proposition F (the mixed trace is Fubini over selections).** [novelty: single-check] Let Y be a compact substrate, {Y_b}_{b∈Z} a measurable partition into flow-invariant Borel sets with a finite measure μ on Z, and suppose a type I distributional trace Tr_b (Hörmander/Guillemin/Lefschetz, §2.2) exists on μ-a.e. slice; define τ(f) := ∫_Z Tr_b(φ^f) dμ(b) when absolutely convergent. Let P ≅ B × S¹_ℓ ⊂ Y be a packet. Then: (a) for μ-a.e. b, P ∩ Y_b contains no accumulation point of closed orbits of period ℓ (otherwise the type I trace of the slice diverges at t = ℓ — Theorem D′/D″ in the smooth case, Theorem T1/D in the Hilbert-space case), so each slice meets P in an isolated, hence countable, set of orbits, finite if the slice is compact; (b) the coefficient of δ_{kℓ} in τ contributed by P is ∫_Z Σ_{orbits γ ⊂ P ∩ Y_b} ℓ ε_γ(k) dμ(b); (c) the Haar identity "P contributes μ(B) × (single-orbit term)" holds iff the μ-average over slices of the ε-weighted number of P-orbits in a slice equals μ(B) — for ε ≡ 1 and μ(B) = 1, iff the average slice meets P in exactly one orbit. In the product Y = B × X with slices {b} × X every slice meets every packet B × γ in exactly one orbit (Theorem P). *Proof.* (a) is Theorem D′/D″ or T1 applied inside the slice; (b) is the definition of τ and the single-orbit term of a type I trace; (c) is (b) with the average computed. ∎
*Reading for S4.* A mixed trace with the Haar identity on every packet is a μ-family of substrates each of which "meets each packet in exactly one orbit" — Q-a's clause, slice by slice. The family is Aut(C)-equivariant as a family (Aut(C) acts on the packet bases by translations, 9.4 Lemma D(iii), referee-pending), which is how it escapes 9.4 Proposition 1's obstruction against single Aut(C)-stable selections; but each member is a selection, and its existence is Q-a. Nothing is gained on Q-a itself; the measure is a Fubini bookkeeping device on top of it.

**8.3 The correct re-scoping of S4's counting demand (topological, not measured).** [novelty: single-check — Deninger's Fuller-index remark ([x-18] p. 8, [x-19] p. 10) made precise in the model world; the adjudication R2 names that remark as the printed predecessor.] Inside the [Den05]/[ALKL] framework the coefficient of log p · δ_{k log p} produced by a compact isolated periodic set P_p of period log p is log p · ind(P_p^k, base), Theorem L. Hence T1 (coefficient 1 for every k ≥ 1) reads:
   **(S4-index)** each packet Γ_p^Y ⊂ Y is a compact isolated fixed set of the leafwise return map with fixed-point index 1 for every iterate k ≥ 1.
For an isolated non-degenerate orbit this is ε_γ(k) = +1 for all k ≥ 1 (the ledger's ε ≡ +1); for a packet it is a condition on the base as a fixed set, compatible with the full packet being present, and requiring no selection. What (S4-index) demands, and where it stands: (α) a leafwise manifold structure on a neighborhood of each packet base, in which "fixed-point index" is defined — X₀ has none (ledger W6: not a foliated space; W12: non-Hausdorff along packets), so the demand lives entirely in the S4 object Y and the map f: Y → X₀ of Q-b, not in X₀; (β) the global Lefschetz–Hopf constraint on a §7.7 suspension over a surface M: the sum of the indices of all period-k sets equals L(h^k), so a lone packet of index 1 with no other periodic points needs L(h^k) = 1 for all k ≥ 1, which for h isotopic to the identity means χ(M) = 1 — impossible for a closed orientable surface (on T² with h ≃ id the lone-packet index is forced to be 0, Corollary 6.5(d)) — arithmetic substrates must in any case have orbits of all lengths log p, which a single §7.7 suspension over a manifold cannot ([Den05] Cor. 5.5 remark 3 p. 24; ledger R14), so this constraint bites only on the model, not on Q-b; (γ) the p → ∞ accumulation core of Q* is untouched, and so are the archimedean rows (S3, R12–R13) and the k ≤ −1 weights (R11/T2), which the index does not address. (S4-index) is strictly weaker than Q-b's "exactly one closed orbit of length log p per prime" (an index-1 non-degenerate orbit is a special case), so a NO to Q-b(index) kills more than a NO to Q-b, and a YES would be new; it is the honest replacement of the 9.4 note's Road 2 clause, and it is recorded here as a re-scoping for the orchestrator, not as a road with any positive evidence.

**8.4 Kill-criterion status.** Nothing here fires the C3 kill-criterion: Q-b is not decided, S2 is not affected, and the packet-count obstruction (R4/R15) is re-expressed (as an index demand) rather than removed or confirmed. What is decided is that the measured route to removing it does not exist.
