## §1. Definitions as printed (page anchors; vision-verified unless marked OCR)

**1.1 Proper leaf, lim L, asymptotic** — Candel–Conlon I §4.3 p. 115 (PDF 121, vision). Setting: "Let L be a leaf of a compact, foliated manifold (M, 𝓕). Recall that {K_α}_{α∈𝔄} denotes the family of all compact subsets of L. Let W_α = L ∖ K_α and let W̄_α denote the closure of W_α in M." **Definition 4.3.1.** "The *limit set* of L is the set lim L = ⋂_{α∈𝔄} W̄_α. This is also called the *asymptote* of L." **Lemma 4.3.2.** "For each noncompact leaf L of 𝓕, lim L is a compact, nonempty, 𝓕-saturated set." **Definition 4.3.3.** "The leaf L is asymptotic to a leaf F if F ⊆ lim L. The leaf L is *proper* if it is not asymptotic to itself." Gloss printed right after: "More intuitively, in a foliation 𝓕 of codimension q, a leaf L is asymptotic to a leaf L′ if and only if, for each x ∈ L′ and each q-manifold N through x transverse to 𝓕, N ∩ L clusters at x. Thus, L′ is proper if N can be chosen so that N ∩ L′ = {x}." (Same page: Definition 4.3.4 lim_e L, the e-limit set of an end e ∈ ℰ(L); Lemma 4.3.5: lim_e L is compact, nonempty, 𝓕-saturated.)

**1.2 Semiproper leaf** — three printed definitions, consistent with one another.

## §2. The printed theorems bearing on (S), quoted at the page

**2.1 Duminy's theorem and its corollary** — Cantwell–Conlon, Warsaw 2002 (vision, PDF 234–235 = pp. 225–226). Standing hypotheses (p. 225): "Let (M, 𝓕) be a transversely oriented, C²-foliated manifold of codimension one, with M compact and oriented. We assume each component of ∂M, if any, is a leaf of 𝓕. Remark that each leaf of 𝓕 is oriented." **Theorem 1.1 (Duminy)** (p. 225): "If the leaf F of 𝓕 is semiproper and if it accumulates on the exceptional LMS X, then ℰ^X(F) is homeomorphic to the Cantor set." **Corollary 1.2** (p. 226): "If X is an exceptional minimal set of 𝓕 and if F ⊂ X is a semiproper leaf, then ℰ(F) is homeomorphic to the Cantor set." — "Indeed, since X is minimal, ℰ^X(F) = ℰ(F)." **Theorem 1.4 (Duminy)** (p. 226): "If e ∈ ℰ^X(F), then every neighbourhood of e in F contains a complete submanifold that spirals on L with juncture H. Consequently, e is a cluster point of ℰ^X(F) and this set is a Cantor set." (L is "any semiproper leaf of 𝓕 that is approached by a possibly different semiproper leaf F", p. 226.)

**2.2 The conjecture printed right after** (pp. 226–227, vision): "It is natural to conjecture that, if F ⊂ X, the requirement in Theorem 1.1 that F be semiproper can be dropped. This is true for *Markov LMS* [4] but is unknown in general. A weaker conjecture would be that the generic leaf of an exceptional minimal set X have a Cantor set of ends. Here generic can be taken either in the sense of [5] or [7]. It is not hard to show that the generic leaf has one end or a Cantor set of ends." — The last sentence is the one printed sentence on disk that admits **one end** for a (generic, hence non-semiproper) leaf of an exceptional minimal set as an undecided possibility.

**2.3 Lemma 2.1 and its proof** — Warsaw p. 228 (vision, PDF 237). Setting: "Let X ⊂ M be an exceptional LMS of 𝓕, let F be a semiproper leaf that accumulates on X, L a semiproper leaf lying in X." **Lemma 2.1**: "The leaf L lies at finite level and the closure F̄ of F in M accumulates on F from at most one side." **Proof** (verbatim): "No leaf at infinite level can have a proper side [1, Lemma 8.3.23], so F and L each lie at finite level. This means that F lies in a unique LMS Q and Q must either reduce to F itself (and F is a *proper* leaf) or it must be exceptional. In either case, F̄ is a compact, nowhere dense, 𝓕-saturated set containing X. Further, by [1, Corollary 8.3.12], F̄ is a finite union of LMS, each of which is either a proper leaf or an exceptional LMS and none of which, except for Q, can accumulate on F. If Q reduces to F itself, F̄ does not accumulate on F. Alternatively, Q is exceptional and accumulates on F only from the nonproper side of that leaf." Then: "The leaf F accumulates on the semiproper leaf L ⊂ X. Since L accumulates on itself, F accumulates on L from the nonproper side. If F ⊄ X, it is possible that F also accumulates on L from the proper side, but this is immaterial for our purposes." ([1] = Candel–Conlon, *Foliations I*.)

**2.4 The two Candel–Conlon I results Lemma 2.1 rests on** (vision, PDF 193 = p. 191; PDF 197 = p. 195).

**2.5 Sacksteder and resilience; Duminy restated** — Candel–Conlon I §8.2 (vision, PDF 186 = p. 184). "Corollary 8.2.2. Let Y ⊆ M be a local minimal set with more than one leaf. If each leaf in Y has trivial linear holonomy group, then Y ∈ 𝒪(𝓕)." "We emphasize that this corollary, like Theorem 8.2.1 itself, is only true in the presence of smoothness of class at least C²." **Definition 8.2.4**: "The leaf L of 𝓕 is *resilient* if there is a transverse arc J = [x, y), x ∈ L, and a loop σ on L, based at x, such that h_σ : [x, y) → [x, y) is a contraction to x, and L ∩ (x, y) ≠ ∅." **Corollary 8.2.5**: "An exceptional local minimal set X contains a resilient leaf." **Remark** (p. 184): "Another unpublished theorem of Duminy asserts that a semiproper leaf L in an exceptional minimal set has a Cantor set of ends. **2.6 The open question, printed a second time, with the analytic and Markov cases** — Candel–Conlon I §8.4 Remark, p. 199 (vision, PDF 201): "Let L be a semiproper leaf in an exceptional minimal set. By an extremely delicate application of Lemma 8.1.6, analyzing the way that L approaches itself on the nonproper side, Duminy has shown that every end e of L is periodic of period L. Exactly as above, it follows that e has a fundamental neighborhood system {B(j) = ⋃_{i≥j} B_i}_{j=1}^∞, where ℰ(B_i) ≅ ℰ(L), ∀i ≥ 1. Thus, every e ∈ ℰ(L) is a cluster point, implying that ℰ(L) is a Cantor set. For real analytic foliations, the proof is much easier and extends to *every* leaf of the exceptional minimal set. For C² foliations, it is an open question whether every leaf of an exceptional minimal set has a Cantor set of ends, although this is true for *Markov* minimal sets [25] (cf. Exercise 4.1.8). Unfortunately, Duminy has never made available an account of this proof (but, cf. [22])." — Note the two printed decided sub-cases: **real-analytic** (every leaf of an exceptional minimal set has a Cantor set of ends — stated as a remark, no proof or reference printed) and **Markov** ([25]; = Warsaw's [4] = Hurder's [80, 83]: Cantwell–Conlon, Publ. **2.8 A one-ended, non-semiproper leaf is printed as realizable** — Candel–Conlon I Example 8.3.20, p. 194 (vision, PDF 196): "By contrast, every noncompact, orientable surface occurs as a leaf of a C^∞ foliation in every compact 3-manifold, orientable or not, and every noncompact, nonorientable surface occurs as such a leaf L in every compact, nonorientable 3-manifold [21]. For this, one constructs a sequence {𝓕_k}_{k=1}^∞ of foliations converging to a limit foliation 𝓕. The foliation 𝓕_k contains a leaf L_k at level k + 1 that agrees with L in a compact region B_k. These regions exhaust L and, although the topology of L_k becomes progressively more horrible outside B_k as k ↑ ∞, these pathologies are 'pushed out of the universe' in the limit. The leaf L appears at infinite level in 𝓕; so it is basically impossible to 'see' this leaf. In this construction, it turns out that one can find a Riemannian metric on M relative to which L has constant curvature −1. In particular, the hyperbolic plane can be realized as a leaf at infinite level in a suitable C^∞ foliation in every compact 3-manifold." With Lemma 8.3.23, such a leaf has no proper side. Whether its closure contains an exceptional minimal set is not stated on the page (Lemma 8.3.21, p. 194: "If there is no finite upper bound to the levels of the totally proper leaves in X_*, then all leaves in X_* are totally proper" — the alternative that the page leaves open).
