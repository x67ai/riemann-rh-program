## §1. PER CLAIM

### N-A — Theorem A (A)+(B)

**Claim as bound** (IV.14; `f1-check-O.md` §1–§2). X a compact metrizable foliated space with 2-dimensional (Riemann-surface) leaves, φ a jointly continuous foliated flow, N the union of the leaves preserved by φ. **(A)** every positive holonomy-invariant transverse measure µ concentrated on N is flow-invariant, φ^t_*µ = µ (the transverse map induced by φ^t agrees with plaque-chain holonomy on N). **(B)** if φ^{t*}[λ_g] = e^t[λ_g] in H̄²_F(X) (Deninger's α = 1) there is no nonzero FLOW-INVARIANT holonomy-invariant transverse measure (Ruelle–Sullivan current paired with the class of the leafwise area form; (e^t − 1)m = 0 with 0 < m < ∞).
