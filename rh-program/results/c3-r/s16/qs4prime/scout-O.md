### A. DIRECT — has anyone built a foliated dynamical system whose primitive closed orbits are the primes with lengths log p?

**A1. Deninger, *Arithmetic geometry and analysis on foliated spaces*, Arizona Winter School / [Den05]
= on disk `fetched/x-20-…pdf`. READ pp. 19–35.** This is the source of the S4′ desideratum and of
three of its four clauses.

- p. 26 (the desideratum, verbatim): "In order to understand number theory more deeply in geometric
  terms it would be very desirable to find a system (X, φ^t, F) which actually realizes this
  correspondence. For this the class of compact 3-manifolds as phase spaces has to be generalized as
  will become clear from the following discussion."
- p. 26, the dictionary the system must realize: "finite place p ≙ closed orbit γ = γ_p not contained
  in a leaf and hence transversal to F such that l(γ_p) = log N p and ε_{γ_p}(k) = 1 for all k ≥ 1";
  "infinite place p ≙ fixed point x_p such that κ_{x_p} = κ_p and ε_{x_p} = 1."  **This is clause (i)
  plus clause (iii) in Deninger's own words.**
- p. 32–33 (clause (ii), verbatim, the "Fact"): "In the situation of the preceeding remark, ε_k(γ) = +1
  for all k ∈ Z∖0 if and only if on T_xF we have: T_xφ^{k l(γ)} = e^{(k/2) l(γ)}·O_k for O_k ∈ SO(T_xF).
  For fixed points, ε_x = 1 is automatic and we have: T_xφ^t = e^{t/2} O_t for O_t ∈ SO(T_xF)." And:
  "In the number theoretical case the eigenvalues of T_xφ^{log N p} on T_xF for x ∈ γ_p would therefore
  be complex conjugate numbers of absolute value N p^{1/2}."  **Clause (ii) is Deninger's, verbatim,
  and it applies to the archimedean fixed point too (rate 1/2 there as well).**
- p. 27 (the manifold no-go, verbatim): "Further comparison of formulas (5) and (24) shows that in a
  dynamical system corresponding to number theory we must have α = 1. … However as mentioned before,
  this is not possible in the manifold setting of corollary 5.5 which actually implies α = 0."
- p. 23, **Corollary 5.5 Remark 3 (verbatim) — the printed length-group obstruction**: "One can show
  that the group generated by the lengths of closed orbits is a finitely generated subgroup of R under
  the assumptions of the corollary. In order to achieve an infinitely generated group the flow must
  have fixed points."  Cor. 5.5's assumptions, read at p. 23: *X a compact 3-manifold, F a foliation
  by surfaces with a dense leaf, φ^t a non-degenerate F-compatible flow everywhere transversal to F,
  conformal in the sense (20).*
- p. 23, Remark 2 (verbatim): "Actually the conditions of the corollary force α = 0 i.e. the flow must
  be isometric with respect to g. We have chosen to leave the α in the fomulation since there are good
  reasons to expect the corollary to generalize to more general phase spaces X than manifolds, where
  α ≠ 0 becomes possible i.e. to Sullivan's generalized solenoids."
- p. 33, Remark 7) — **a printed constraint on the leaves for K = Q**: "If there does exist a foliated
  dynamical system attached to spec o_K … we would expect in particular that for a preferred transverse
  measure µ we have: χ_Co(F, µ) = − log |d_{K/Q}|. … In the unramified case, |d_{K/Q}| = 1 we must have
  χ_Co(F, ν) = 0 for all transverse measures by the above argument. Hence there is an F-leaf which is
  either a plane, a torus or a cylinder c.f. [9]." ([9] = Candel.)  For K = Q, d = 1, so **the S4′
  object must have χ_Co(F, ν) = 0 for every transverse measure and must contain a leaf that is a plane,
  a torus or a cylinder.** Of those three, only the plane has χ ≠ 0 — so clause (iii)'s archimedean
  leaf, if it is one of Candel's three, is a **plane** (χ = 1). *(The identification of the χ ≠ 0 leaf
  with the plane is my inference from Deninger's printed sentence, not printed.)*
- p. 26, Fact 6.1 (Connes, printed here): "Let F be a foliation of a compact 3-manifold by surfaces such
  that the union of the compact leaves has µ-measure zero, then χ_Co(F, µ) ≤ 0", with the printed proof
  χ_Co = −β_1(F, µ).
- pp. 34–36, §7.7 and **Theorem 7.8** — the one solved case: X = M̄ ×_Λ R for an unramified covering
  f : M → M, Λ = lZ; closed orbits ↔ finite f-orbits, l(γ) = |γ_M| l; χ_Co(F, µ) = χ(M)·l. Example
  p. 36: E/F_p ordinary elliptic curve, l = log p, X ≅ (C ×_Γ T_πΓ) ×_{p^Z} R^*_+, and "the metric g on
  TF given by g_{[z,y,t]}(ξ, η) = e^t Re(ξη̄) … satisfies the conformality condition (20) for α = 1."
  **What it gives:** clause (ii) is realized (α = 1) on a genuine non-manifold solenoid; clause (iv) is
  realized (canonical transverse measure µ, and χ_Co(F,µ) = χ(M)·l). **What it does not give:** the
  length group is (log p)Z — rank 1, one prime — so clause (i) fails by an infinite margin, and there
  are no fixed points, so clause (iii) fails. Deninger's own verdict, p. 36: "The construction of
  (X, φ^t) that we made for ordinary elliptic curves is misleading however, since it almost never
  happens that a variety in characteristic p can be lifted to characteristic zero together with its
  Frobenius endomorphism."

**A2. Deninger, *Analogies between analysis on foliated spaces and arithmetic geometry*, arXiv:0709.2801
= [x-18], LMS Lecture Notes 354 (2008). READ pp. 1–4.**  p. 3, Construction 3 defines the period group
Λ ⊂ R as the image of ψ = [ω_φ] : π_1^{ab}(X) → R, where ω_φ|TF = 0, ⟨ω_φ, Y_φ⟩ = 1; "One checks that
dω_φ = 0". Then, verbatim: "It is known that F is a fibration if and only if rank Λ = 1." p. 4,
verbatim: "So the foliation setting allows for a product formula where the Nγ are not all powers of the
same number. If one wants an infinitely generated Λ, one must allow the flow to have fixed points
(≙ infinite places)." p. 4, Dictionary 4: "|char(X)| ≙ rank of period group Λ"; "X(C)/F_∞ ≙ set of fixed
points of φ^t. Note that the leaf of F containing a fixed point is φ-invariant."
**What it gives:** the precise instrument for clause (i)+(iii): Λ ⊇ ⟨log p : p⟩, which has infinite rank,
so F is not a fibration and the flow must have fixed points. **What it does not give:** any construction,
and no proof of the quoted "one must allow fixed points" sentence (it is asserted, not derived, here).

**A3. Deninger, *Primes, knots and periodic orbits*, arXiv:2301.11643 = [x-06] (2024). READ pp. 6–13.**
p. 7, verbatim: "Incidentally, note that if we had a bijection p ↔ γ with log p = l(γ), then the Riemann
zeta function would be a Ruelle zeta function ζ(s) = Π_γ (1 − e^{−s l(γ)})^{−1} for Re s > 1. **The question
whether a natural dynamical system with this property exists is quite old and we will discuss our progress
in this direction in the last section.**"  — 2024, the problem is stated as open, by name.
p. 8, verbatim: "One can show that the conformal factor e^{αt} for a metric g_F as above necessarily has to
be 1, i.e. α = 0 … By comparison with the Riemann hypothesis, we would obviously want α = 1 to be a
possibility in the geometric analogue (X, F, φ^t). This is only one instance which shows that the class of
smooth compact manifolds is too restrictive to actually rewrite the explicit formulas of analytic number
theory as a transversal index theorem."
p. 9, verbatim — **the one printed positive existence statement for clause (ii)**: "One can show that α = 1
can be achieved if for X we allow the local structure (totally disconnected) × (3-dimensional ball),
c.f. [Lei07]."
pp. 11–12: Theorem 4.2 (closed points ↔ **packets** Γ_{x_0} of periodic orbits of length log N x_0, not
single orbits) and, verbatim, "In general, the dynamical system (X_0, φ^t) has too many periodic orbits,
since the N-space W_rat(X_0)(C) does not know enough about the addition in O_{X_0}."  **What it gives:**
the state of the art as of 2024 in Deninger's own words — his construction gives packets, not clause (i),
and he says so. **What it does not give:** clause (i), (iii) (X_0 has no fixed points at all) or (iv).

**A4. Leichtnam, *Scaling group flow and Lefschetz trace formula for laminated spaces with p-adic
transversal*, arXiv:math/0603576v2 = Bull. Sci. Math. 131 (2007) 638–669, on disk `fetched-r3/r3s-21-…pdf`.
READ abstract, pp. 2–3, pp. 13–14 (axioms (i)–(iv)), p. 17 (Open Question 2).**
This is **S4′ in print, essentially clause for clause**, as a conjectural object. p. 2, verbatim:
"Several papers … of Deninger lead to suggest that to the Riemann zeta function ζ̂(s) one could possibly
associate the following two data: 1) A Riemannian foliated space of the form (S_Q = L×R^{+*}/Q^{+*} ∪
L/Q^{+*}, F, g) where L is a σ-compact complex 1-dimensional laminated space on which Q^{+*} acts. The path
connected components of L induce a foliation of L×R^{+*}/Q^{+*} by Riemann surfaces and g is a leafwise
kaehler metric. 2) A flow φ^t acting on (S_Q …, F) whose primitive closed orbits correspond to the primes
of Q and admitting a fixed point in L/Q^{+*}. … Moreover (φ^t)_*[λ_g] = e^t[λ_g] where [λ_g] denotes the
reduced leafwise cohomology class of the leafwise kaehler form associated to g."  p. 2, verbatim: "Notice
that the existence of such a quadruple (S_Q, F, g, φ^t) is still unknown."  Abstract, verbatim: "The
existence of such a foliated space and flow φ^t is still unknown except when Y is an elliptic curve (see
Deninger [De02])."
p. 13, **axioms (i) and (ii) of his laminated model** — the mechanism that makes α = 1 possible:
"(i) … f_i ∘ q ∘ f_j^{-1}(z, θ) = (Z(z), L(θ) = M_q θ + b_q) … where Z(·) is holomorphic, b_q ∈ Z_p^m, and
M_q ∈ M_m(Z_p) ∩ GL_m(Q_p) is such that **Jac M_q = 1/q**. (ii) There exists a smooth leafwise kaehler metric
g̃ … Second, for any l ∈ L one has: ∀u ∈ T_lL, **g̃(q_*(u)) = q g̃(u)**."  **What it gives:** the printed
proof-of-concept that clause (ii) (leafwise expansion) is compatible with a transverse measure (clause (iv))
provided the transverse measure is **scaled by 1/q**, on a p-adic (totally disconnected) transversal. **What
it does not give:** the length group here is (log q)Z, rank 1 — one residue characteristic. Clause (i) is out
of reach of this class by construction; his Open Question 2 asks only for the function-field case
(all closed points of a curve over F_q, lengths in (log q)Z).
p. 17, **Open Question 2 (verbatim)**: "1] Let Y be a smooth projective absolutely irreducible curve over F_q
admitting a rational point. Does there exist a laminated foliated space (S_Y = L_Y ×_{q^Z} R^{+*}, F, g, φ^t)
satisfying all the assumptions of Proposition 2 and Theorem 2 and the following assumption: (A) One has a
natural bijection w ↦ γ_w between the set of closed points of Y and the set of primitive closed orbits of
(S_Y, φ^t) satisfying log Nw = l(γ_w). If the answer is yes, one should obtain, via Theorem 2, a new proof of
Weil's Theorem." And: "Of course, when Y is an elliptic curve over F_q, Deninger has shown ([De02]) that the
answer to part 1] of the previous open question is yes."

### E. FOLIATED TRACE FORMULAS — exactly what [ÁLKL23]/[ALKL24] requires, and what that does to clauses (iii) and (iv)

**E1. Álvarez López–Kordyukov–Leichtnam, *A trace formula for foliated flows*, arXiv:2402.06671v1
(v2 dated 2024-02-07 per the arXiv listing fetched this session), on disk `fetched-r3/r3s-17-…pdf`.
READ: Abstract, Ch. 1 §§1.1–1.3.2 (memoir pp. 1–8), the statement of Theorem 1.3.10 (memoir p. 8),
§4.1.2 (memoir pp. 99–101).**

- **Standing hypotheses, verbatim (Abstract, memoir p. vii):** "Let F be a transversely oriented
  foliation of codimension one on **a closed manifold M**, and let φ = {φ^t} be a foliated flow on
  (M, F). Assume the closed orbits of φ are simple and its preserved leaves are transversely simple.
  In this case, **there are finitely many preserved leaves, which are compact.**"
- §4.1.2, verbatim (memoir p. 100): "Suppose φ is transversely simple … Then M^0 is a finite union of
  compact leaves because every fixed point of φ̄ is isolated." And the four Hector cases from
  [ÁLKL22] (= *Simple foliated flows*, arXiv:1906.06753, abstract fetched this session: "We describe
  transversely oriented foliations of codimension one on closed manifolds that admit simple foliated
  flows."): "(c) F is given by a fiber bundle M → S^1 with connected fibers. (d) F is an R-Lie
  foliation with dense leaves. (e) M^0 ≠ ∅, Hol L ≅ Z for all leaves L ⊂ M^0, and the foliations F_l^1
  are given by fiber bundles M_l^1 → S^1 with connected fibers. (f) M^0 ≠ ∅, Hol L is a finitely
  generated abelian group of rank > 1 for all leaves L ⊂ M^0, and all foliations F_l^1 are minimal
  R-Lie foliations."
- §1.3.1, verbatim (memoir p. 3): "By cutting M along M^0, we get a compact manifold with boundary M̄
  with a foliation F̄ tangent to ∂M̄."
- **Theorem 1.3.10, verbatim (memoir p. 8):** "Using the preserved leaves L and the closed orbits c,
  we have  L_dis(φ) = Σ_L χ(L) W_L + ^bχ_{|ω^1|}(F^1) δ_0 + Σ_c ℓ(c) Σ_{k∈Z^×} ε_c(k) δ_{kℓ(c)}."
  And the definition of the preserved-leaf term, memoir p. 7, verbatim: "L_dis,K,K′(φ) = Σ_L
  χ(L)/|e^{κ_L t} − 1|", extended over t = 0 by the Barlet-type regularization
  "⟨W_L, f⟩ = ∫_0^∞ ( (f(t)+f(−t))/|e^{κ_L t} − 1| − 2f(0)/(|κ_L| t) ) dt."
- §1.1, verbatim (memoir p. 1): "It became clear that more generality is needed to draw arithmetic
  consequences (perhaps foliated flows on possibly singular foliated spaces of arithmetic nature)."

**What E1 gives.** (a) Clause (iv) is *not* "there is a transverse measure" in the memoir's own
hypotheses: what the memoir uses is the transverse density |ω^1| of F^1 — "The transverse density |ω^1|
can be considered as an invariant transverse measure of F^1" (memoir p. 3) — built from the flow itself,
and the number that enters the δ_0 coefficient is the **b-Connes–Euler characteristic** ^bχ_{|ω^1|}(F^1),
not an arbitrary transverse measure. (b) Clause (iii) is exactly the χ(L) weight of Theorem 1.3.10:
a preserved leaf with χ(L) = 0 contributes **nothing**, so an archimedean term is impossible without a
preserved leaf of nonzero Euler characteristic. Clause (iii) is therefore not a program invention — it
is the printed weight in the only proved trace formula. (c) The memoir's class is **closed smooth
manifolds only**; the authors say so and say more generality is needed.

**What E1 does NOT give, and two obstructions it creates for S4′ as posed (my derivations, from printed
statements; see §2 rows L1 and L5).** Within the memoir's own hypotheses S4′ is *unsatisfiable*, for two
independent reasons — the length group is finitely generated, and the archimedean weight has the wrong
parity. Both are written out in §2.

**E4. Deninger, *There is no Weil-cohomology theory with real coefficients for arithmetic curves*,
arXiv:2204.02714 = Ann. SNS Pisa, DOI 10.2422/2036-2145.202204_005 [x-04].** Bears on S4′ only

existence.
