## §2 Theorems

Notation: s = ½ + it on the line; Ξ(t) = ξ(½+it); P_w(t) := ξ_w(½+it) − Ξ(t).

**Theorem D (Pólya positivity; the chain decreases to Ξ).** For every n ≥ 1 and real t, g_n(½+it) > 0. Consequently, for weights 0 ≤ w_n ≤ 1,
  P_w(t) = ½(¼+t²) Σ_n (1 − w_n) g_n(½+it) ≥ 0,
with equality for all t only if w ≡ 1; in particular ξ₁(½+it) > ξ₂(½+it) > … > Ξ(t) for every real t.
*Proof.* With x = e^{2u}, g_n(½+it) = ∫₁^∞ e^{−Xx} 2x^{1/4}cos((t/2)log x) dx/x = 4∫₀^∞ k(u)cos(tu) du, k(u) = exp(u/2 − Xe^{2u}). With y = Xe^{2u} ≥ X ≥ π: k′ = k(½ − 2y) < 0 and k″ = k(4y² − 6y + ¼) > 0 (the larger root of 4y² − 6y + ¼ is (3 + 2√2)/4 = 1.457… < π). So k is positive, strictly decreasing, strictly convex on [0, ∞) and → 0. For t ≠ 0, ∫₀^∞ k cos(tu) du = t^{−1}∫₀^∞(−k′(u)) sin(tu) du; −k′ is positive and strictly decreasing, so the half-period pieces of the sine integral alternate in sign with strictly decreasing sizes and the first is positive: the integral is > 0 (Pólya's criterion). At t = 0 the integral is ∫k > 0. The formula for P_w is Riemann's identity minus the chain member, with ½s(s−1) = −½(¼+t²). ∎

**Corollary D1 (lobe law).** Every zero of ξ_w on the line (0 ≤ w ≤ 1, w ≢ 1) lies in an open negative lobe of Ξ (an interval between consecutive zeros of Ξ on which Ξ < 0), and each negative lobe contains an even number of them, counted with multiplicity. (At the ends of a lobe ξ_w = P_w > 0; on positive lobes ξ_w ≥ Ξ > 0.) The real-zero count of every C1 member is even — observed: 2, 6, 16, 32, 52, 80 for N = 1…6.

**Theorem D′ (sandwich; Haglund's approximants rise to Ξ from below).** Haglund's Ξ_N = ξ_N − c_N (§7). For every N ≥ 1 and real t,
  Ξ_N^{Hag}(t) = Ξ(t) − Q_N(t) < Ξ(t) < Ξ(t) + P_N(t) = ξ_N(½+it),  Q_N(t) = c_N − P_N(t) = 2∫₀^∞ Σ_{n>N} φ̃_n(u)cos(tu) du > 0,
where φ̃_n = k_n″ − k_n/4 = 2y(2y − 3)e^{u/2−y}, y = πn²e^{2u} (Riemann's kernel term, up to a factor).
*Proof.* Integrating by parts twice, ½(¼+t²)g_n(½+it) = 2(¼+t²)∫₀^∞k_n cos(tu)du = −2k_n′(0) − 2∫₀^∞(k_n″ − k_n/4)cos(tu)du, and −2k_n′(0) = (4πn² − 1)e^{−πn²}; sum over n > N. For n ≥ 2 (y ≥ 4π): φ̃_n > 0; φ̃_n′ = e^{u/2−y}·y(−8y² + 30y − 15) < 0; φ̃_n″ = e^{u/2−y}·y(16y³ − 112y² + 165y − 37.5) > 0 (16y²(y − 7) > 0 and 165y > 37.5). Pólya's criterion as in Theorem D. ∎ (For n = 1 the kernel is not monotone at u = 0 — the factor −8y² + 30y − 15 is +0.9 at y = π — which is why the statement needs N ≥ 1.)
*Consequences.* (1) Haglund's real zeros lie in POSITIVE lobes of Ξ, an even number per lobe, plus one in the central lobe (0, γ₁): his real-zero count in t > 0 is ODD for every N. His table (p. 4) reads 1, 7, 15, 32, 53, 79, 113, 155, 207, 263 for N = 1…10 — the entry 32 (N = 4) is inconsistent with the theorem [checked by census, §5]. **Theorem A (no member is real-rooted).** Let w ≢ 0, and either (i) 0 ≤ w_n ≤ 1 with some w_m < 1 (covers C1 for every N, C2 for every finite S, every smooth cutoff with 0 ≤ φ ≤ 1), or (ii) w finitely supported with arbitrary real values. Then ξ_w has only finitely many zeros on Re s = ½ and infinitely many zeros off it.
*Proof.* (a) Order ≤ 1 and super-exponential growth: |g_n(s)| ≤ g_n(Re s) (since |Γ(a, X)| ≤ Γ(Re a, X)), so |ξ_w(s)| ≤ ½ + ½|s|²Σ_n|w_n|g_n(Re s) = exp(O(|s|log|s|)). (b) Finitely many on the line. Case (i): by Theorem D, ξ_w(½+it) ≥ Ξ(t) + (1 − w_m)·½(¼+t²)g_m(½+it). Case (ii): integrating by parts twice in the cosine representation,
  ξ_w(½+it) = C_w + 2∫₀^∞ Φ_w(u)cos(tu) du,  Φ_w = K_w″ − K_w/4,  K_w(u) = e^{u/2}Σ_n w_n e^{−πn²e^{2u}},  C_w = ½ + 2K_w′(0),

**Theorem B (the only real-rooted member is ξ).** Let |w_n| ≤ Cn^A, w ≢ 0. If every zero of ξ_w lies on Re s = ½, then w ≡ 1.
*Proof.* Real-rooted + infinitely many zeros (part (a) above, which holds for polynomially bounded w) forces infinitely many real zeros, so every coefficient of the expansion in (b) vanishes (the expansion holds for such w: Φ_w is real-analytic on ℝ and all its derivatives decay double-exponentially on [0, ∞)). Then Φ_w is even; D(u) := K_w(u) − K_w(−u) is odd with D″ = D/4, so D = 2α sinh(u/2), i.e. ψ_w(1/x) = √x ψ_w(x) − α(√x − 1) for ψ_w(x) = Σ w_n e^{−πn²x}; differentiating at x = 1 gives K_w′(0) = α/2, and C_w = 0 gives α = −½: ψ_w satisfies Riemann's theta relation exactly. By Hamburger's theorem the Dirichlet series f(s) = Σ(w_n − 1)n^{−s} is a constant multiple of ζ; it is entire, so the constant is 0 and w ≡ 1. ∎ Citation, read at the page on disk (`lit/PRIOR-ART.md` §5): for bounded w, Hamburger's theorem as stated by Nakamura, arXiv:2008.02570 p. 4 (Theorem D: F = Σa(n)n^{−s} absolutely convergent for σ > 1, P(s)F(s) entire of finite order, ξ_F(1 − s) = ξ_F(s) ⟹ F = Cζ) — here F = f is entire of finite order (f = π^{s/2}M(s)/Γ(s/2), M the Mellin transform above); for polynomially bounded w, Burnol, arXiv:1106.4749 pp. 2–3 (convergence for Re s large, finitely many poles, g(s) = χ(s)f(1 − s) = f(s) = O(m^{−s}) with m ≥ 1 > ½; Corollaire 2 with g(σ) = (w₁ − 1) + O(2^{−σ}) gives f = cζ). **Proposition E (the windowed chain is a height filtration of RH).** Let W_N := sup{T : every zero of ξ_N with |Im s| < T lies on the line}. (a) If W_N → ∞ then RH holds (Hurwitz: ξ_N → ξ locally uniformly and zeros of ξ are limits of zeros of ξ_N). (b) If RH holds and every zero of ξ is simple, then W_N → ∞ (on a compact rectangle ξ_N has, for N large, exactly one zero near each zero of ξ and no others; a single zero near the line must lie on it, by the symmetry s ↦ 1 − s̄). (c) If RH holds and Ξ has a zero of order k ≥ 3, or a double zero at which Ξ has a local minimum, then W_N stays below that zero's height for every N: near it ξ_N = Ξ + P_N with P_N > 0 (Theorem D), and c(t − γ)^k + P_N has at most two real roots, so the other roots are an off-line cluster. So "real-rootedness in a window growing with N" is RH plus a non-degeneracy condition on the zeros — it contributes no mechanism of its own.

**Proposition F (approximation staircases are height filtrations).** Let F_N be entire with F_N(1 − s) = F_N(s), F_N(s̄) = conj F_N(s), and suppose that for each T there is N₀(T) such that for N ≥ N₀(T): (i) sup_{R_T}|F_N − ξ| < min_{∂D}|ξ| for a finite family D of small discs about the zeros of ξ in R_T = [−1, 2] × [−T, T] and for ∂R_T, and (ii) F_N has no zeros with |Im s| ≤ T outside R_T. Then (Rouché on each disc and on R_T minus the discs) the zeros of F_N in R_T are the zeros of ξ there, moved by less than the disc radii, with multiplicity; a zero of multiplicity one near the line lies on it by symmetry. Hence, when the zeros of ξ are simple: F_N is real-rooted on R_T for all large N ⟺ RH holds on R_T. For C1: sup_{R_T}|ξ_N − ξ| ≤ ½(T² + 4) max_{−1≤σ≤2} Σ_{n>N} g_n(σ) ≈ T²e^{−π(N+1)²}/(π(N+1)²) (using |g_n(s)| ≤ g_n(Re s) and g_n(σ) ≈ 2e^{−πn²}/(πn²)), so (i) holds up to T ≈ 4(N+1)² (the departure law of §3), and (ii) holds by the exclusion counts of §3. **Consequence:** in any induction "members real-rooted up to T_N ⟹ up to T_{N+1}", the only content is RH on the new window T_N < |Im s| ≤ T_{N+1}; what the chain proves by itself (Theorem D: real zeros are never lost, ξ_{N+1} < ξ_N on the line) is the easy half. The step's missing lemma is literally "no zero of ξ off the line with T_N < γ ≤ T_{N+1}".
